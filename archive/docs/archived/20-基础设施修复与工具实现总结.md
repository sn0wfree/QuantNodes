## 二、详细变更说明

### 2.1 Agent 门面类 (P0)

**文件**: `QuantNodes/agent/__init__.py`

重写为完整的 Agent 类，提供简洁的对外 API：

```python
from QuantNodes.agent import Agent

agent = Agent(model="deepseek-v3")
result = await agent.run("帮我回测这个策略")
```

**内部组合**:
- AgentLoop - 消息循环
- ToolRegistry - 工具注册表
- 6 个工具 - sandbox/pipeline/strategy/backtest/factor/echo
- LLMProvider - LLM 适配层
- MemoryStore - 会话记忆（本次接入）

---

### 2.2 接入 MemoryStore 到 AgentLoop (P0)

**文件**: `QuantNodes/agent/core/loop.py`

**变更**:
1. 导入 `MemoryStore` 和 `truncate_history`
2. 构造函数创建 `self.memory = MemoryStore(self.workspace)`
3. `_process_message` 中注入记忆上下文到 system message
4. `save_session` 前调用 `self.memory.append_history()`
5. 添加 `tool_registry` 参数支持

---

### 2.3 接入 autocompact (P1)

**文件**: `QuantNodes/agent/core/loop.py`, `runner.py`

**变更**:
- `loop.py`: history 构建后调用 `truncate_history(history, max_messages=20)`
- `runner.py`: 每次迭代前调用 `truncate_history(messages, max_messages=30)` + `microcompact()`

### 2.4 BacktestTool 真实回测 (P0)

**文件**: `QuantNodes/agent/tools/backtest.py`

**从占位符升级为真实实现**:

```python
# 之前: 仅返回 {"status": "success", "summary": {}}
# 现在: 
1. 使用 CodeSandbox 安全执行代码
2. 从 namespace 提取 StrategyNode / RiskNode / BrokerNode
3. 手动串联 strategy.execute() → risk.execute() → broker.execute()
4. 返回真实回测结果
```

**支持的流程**:
- StrategyNode.execute(quote_data) → OrdersResult
- RiskNode.execute((orders, {})) → 过滤后的 OrdersResult
- SimulatedBrokerNode.execute((orders, quote_data)) → TradeResult

### 2.5 FactorTool IC 分析 (P1)

**文件**: `QuantNodes/agent/tools/factor.py`

**从占位符升级为真实实现**:

```python
# 之前: 返回 {"ic_mean": None}
# 现在:
1. 使用 CodeSandbox 安全执行因子代码
2. 要求代码创建 result 变量 (Polars DataFrame)
3. 计算 IC 分析:
   - ic_mean: 日度 IC 均值
   - ic_std: 日度 IC 标准差
   - icir: IC 信息比率 (mean/std)
   - rank_ic_mean: 秩 IC 均值
4. 计算相关性分析
```

**代码要求**:
```python
import polars as pl

result = pl.DataFrame({
    "date": ["2024-01-01", ...],
    "code": ["A", ...],
    "factor_value": [0.1, ...],
    "forward_return": [0.05, ...],
})
```

### 2.6 统一注册表 (P0)

**文件**: `QuantNodes/agent/config/loader.py`

**删除假注册表** (30个静态条目):
```python
# 之前:
_OPERATOR_REGISTRY = {
    "add": {"func": "add", "module": "QuantNodes.factor_node.factor_functions", ...},
    "sub": {"func": "sub", "module": "QuantNodes.factor_node.factor_functions", ...},
    ... # 30 个硬编码条目
}

# 现在:
from QuantNodes.factor_node.factor_functions import list_operators as _list_operators

def _get_operator_registry():
    return {op["name"]: op for op in _list_operators()}
```

**结果**: 从 30 个静态算子 → 137 个真实算子

### 2.8 Web UI 修复 (P0)

**文件**: `QuantNodes/agent/web/app.py`

**修复**: 使用 `asyncio.new_event_loop()` 处理 Agent.run() 的 async 调用

```python
# 之前: 直接调用 (会报错)
result = agent.run(query)

# 现在:
loop = asyncio.new_event_loop()
result = loop.run_until_complete(agent.run(query))
loop.close()
```
