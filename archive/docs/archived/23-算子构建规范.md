# 23 - 算子构建规范

## 1. 概述

QuantNodes 的算子系统已统一为 **factor_functions.py**（注册表）+ **operators/**（实现）两层架构。

| 层级 | 文件 | 职责 |
|------|------|------|
| 注册层 | `factor_node/factor_functions.py` | 公开 API，装饰器注册表，工厂封装 |
| 实现层 | `operators/{time_series,section,math,composite}.py` | 纯 Polars 静态方法 |
| TA-Lib 层 | `operators/talib.py` | TA-Lib 0.6.x 技术分析指标包装（56 个指标） |

旧系统（`factor_nodes.py`、`factor_operation.py` 中的 DerivativeFactor）已废弃或仅保留内部执行引擎。

---

## 2. 命名约定

### 2.1 总体规则

- **全部使用 snake_case**，禁止 camelCase
- 已有的 camelCase 算子（如 `standardizeZScore`）添加 snake_case 别名
- 名称必须清晰表达语义

### 2.2 前缀规则

| 前缀 | 分类 | 示例 |
|------|------|------|
| `rolling_` | time | `rolling_mean`, `rolling_std`, `rolling_quantile` |
| `expanding_` | time | `expanding_sum`, `expanding_max` |
| `ewm_` | time | `ewm_mean`, `ewm_std`, `ewm_corr` |
| `ts_` | time（别名前缀） | `ts_mean` (= `rolling_mean`), `ts_delta` |
| `decay_` | time | `decay_linear`, `decay_exp` |
| `group_` | section | `group_norm`, `group_winsorize` |
| `aggr_` | multi_section | `aggr_sum`, `aggr_mean` |
| `talib_` | talib (TA-Lib) | `talib_rsi`, `talib_sma`, `talib_macd_line` |
| `custom_` | custom（用户自定义） | `custom_momentum_zscore` |
| 无前缀 | point / section | `abs`, `log`, `rank`, `zscore` |

### 2.3 禁止事项

- 禁止单字母变量名作为算子名（`f`、`x` 除外，它们是参数名）
- 禁止缩写（如 `avg` 应写为 `average` 或使用已有 `mean`）
- 禁止与 Polars 内置方法完全同名的算子名（如 `shift`、`diff`）

## 3. 签名约定

### 3.1 标准签名模板

```python
@register_operator(OperatorCategory.TIME)
def rolling_mean(
    f: Union[Expr, str],           # 首参：输入表达式或列名
    window: int = 20,              # 领域参数，带默认值
    min_periods: Optional[int] = None,
    **kwargs                        # 末参：必须，吸收 YAML 未知参数
) -> Expr:                          # 返回：polars.Expr
    """滚动窗口均值"""
    return TimeSeriesOperators.ts_mean(f, window, min_periods)
```

### 3.2 签名规则

| 规则 | 说明 |
|------|------|
| **首参** | `f`（单输入）或 `f1, f2`（双输入），类型 `Union[Expr, str]` |
| **末参** | `**kwargs` 必须存在，吸收 YAML `params` 中的未知参数 |
| **返回类型** | `polars.Expr` |
| **类型注解** | 所有参数必须有类型注解 |
| **默认值** | 所有非首参参数必须有默认值 |

### 3.3 operators/ 实现层签名

```python
@staticmethod
def ts_mean(
    expr: Union[Expr, str],
    window: int = 20,
    min_periods: Optional[int] = None
) -> Expr:
    if isinstance(expr, str):
        expr = pl.col(expr)
    # ... 实现
```

实现层**不接受** `**kwargs`，参数更严格。

### 3.4 双输入算子签名

```python
@register_operator(OperatorCategory.TIME)
def rolling_corr(
    f1: Union[Expr, str],
    f2: Union[Expr, str],
    window: int = 20,
    min_periods: Optional[int] = None,
    **kwargs
) -> Expr:
    """滚动相关系数"""
    return TimeSeriesOperators.ts_corr(f1, f2, window, min_periods)
```

## 4. 参数命名标准

### 4.1 标准参数名表

| 参数名 | 类型 | 默认值 | 用途 | 适用分类 |
|--------|------|--------|------|----------|
| `window` | `int` | `20` | 滚动窗口大小 | time |
| `min_periods` | `Optional[int]` | `None` | 最小观测数 | time |
| `alpha` | `float` | `0.5` | EWM 平滑因子 | time (ewm) |
| `periods` | `int` | `1` | 偏移/差分周期 | time (shift/diff) |
| `quantile` | `float` | `0.5` | 分位数值 | time (quantile) |
| `group` | `str` | - | 分组列名 | section |
| `method` | `str` | - | 算法变体 | section/composite |
| `lower` | `float` | `0.01` | 下界比例 | section (winsorize) |
| `upper` | `float` | `0.01` | 上界比例 | section (winsorize) |
| `eps` | `float` | `1e-8` | 数值稳定常数 | section (zscore) |
| `value` | `float` | `1.0` | 标量值 | math |
| `exponent` | `float` | `2.0` | 幂次 | math (pow) |
| `decimals` | `int` | `0` | 小数位数 | math (round) |
| `weights` | `List[float]` | - | 权重列表 | composite |
| `threshold` | `float` | `0.0` | 过滤阈值 | composite |
| `n` | `int` | `10` | 选取数量 | composite (select_top) |
| `ascending` | `bool` | `False` | 升降序 | composite (select_top) |
| `halflife` | `float` | - | 衰减半衰期 | time (decay_exp) |
| `ddof` | `int` | `1` | 自由度 | time (std/var) |
| `group_by` | `str` | - | 分组列名（别名） | section |

### 4.2 禁止非标准缩写

| 错误 | 正确 |
|------|------|
| `win` | `window` |
| `alph` | `alpha` |
| `per` | `periods` |
| `grp` | `group` |
| `lb` / `lb_w` | `lower` / `lower_bound` |
| `ub` / `ub_w` | `upper` / `upper_bound` |

## 5. 分类规则

### 5.1 四个分类

| 分类 | registry category | executor type | 语义 |
|------|-------------------|---------------|------|
| **point** | `point` | `math` | 行级数学运算，无时间/截面上下文 |
| **time** | `time` | `time_series` | 时间序列操作（滚动/扩张/EWM/偏移） |
| **section** | `section` | `section` | 截面操作（单时间点内 rank/zscore/winsorize） |
| **multi_section** | `multi_section` | `composite` | 分组聚合（group_by + agg） |

### 5.2 分类判断流程

```
算子需要什么上下文？
├── 无上下文，逐行计算 → point (math)
├── 需要历史数据窗口 → time (time_series)
│   ├── 固定窗口 → rolling_*
│   ├── 累积窗口 → expanding_*
│   ├── 指数加权 → ewm_*
│   └── 偏移/差分 → ts_delta, ts_lag, ts_pct_change
├── 需要同一时间点的其他标的 → section
│   ├── 全截面 → rank, zscore, winsorize
│   └── 分组内 → group_norm, group_winsorize
└── 需要分组聚合 → multi_section (composite)
    ├── 聚合计算 → aggr_sum, aggr_mean
    └── 多列组合 → weighted_sum, combine
```

### 5.3 分类冲突处理

当一个算子同时涉及时间和截面时：
- **时间优先**：如 `ts_rank`（滚动窗口内 rank），分类为 `time`
- **截面优先**：如 `group_norm`（分组内 zscore），分类为 `section`

## 6. 注册流程

### 6.1 完整注册清单

添加一个新算子的标准步骤：

**Step 1: 在 `operators/` 添加实现**

```python
# operators/time_series.py
@staticmethod
def my_new_op(
    expr: Union[Expr, str],
    window: int = 20,
    min_periods: Optional[int] = None
) -> Expr:
    """新算子说明"""
    if isinstance(expr, str):
        expr = pl.col(expr)
    # ... Polars 实现
```

**Step 2: 在 `factor_functions.py` 注册**

```python
@register_operator(OperatorCategory.TIME)
def my_new_op(
    f: Union[Expr, str],
    window: int = 20,
    min_periods: Optional[int] = None,
    **kwargs
) -> Expr:
    """新算子说明"""
    return TimeSeriesOperators.my_new_op(f, window, min_periods)
```

**Step 3: 加入 `__all__`**

```python
# factor_functions.py 末尾
__all__ = [
    ...,
    "my_new_op",
]
```

**Step 4: （可选）添加 YAML 硬编码 dispatch**

仅当需要优化性能或有特殊参数映射时才需要。大多数情况下 registry fallback 已足够。

### 6.2 注册后验证

```python
# 验证注册成功
from QuantNodes.factor_node.factor_functions import get_operator, list_operators
assert "my_new_op" in list_operators()
assert get_operator("my_new_op") is not None
```

## 8. 测试规范

### 8.1 单元测试

每个新算子必须有对应的单元测试，放在 `tests/agent/test_config_executor.py` 的相应 Test 类中：

```python
class TestTimeOperators:
    def test_my_new_op(self):
        executor = ConfigExecutor()
        config = StrategyConfig(
            name="test",
            operations=[
                OperationConfig(
                    type="time_series", name="result",
                    category="my_new_op", inputs=["close"],
                    params={"window": 5}
                )
            ]
        )
        result = executor.run(config, self._make_data())
        assert result.status == "success"
        assert "result" in result.factors
```

### 8.2 测试覆盖要求

| 场景 | 必须测试 |
|------|----------|
| 正常输入 | 基本功能验证 |
| 边界条件 | 窗口 > 数据长度、空输入 |
| 双输入算子 | 两个输入列都正确使用 |
| 参数默认值 | 不传参数时使用默认值 |

### 8.3 运行测试

```bash
# 运行所有 agent 测试
python3 -m pytest tests/agent/ -v

# 运行特定测试类
python3 -m pytest tests/agent/test_config_executor.py::TestTimeOperators -v
```

## 9. YAML 配置规范

### 9.1 operations 块写法

```yaml
operations:
  - type: time_series          # 分类（对应 executor dispatch）
    name: momentum_ma          # 输出列名
    category: ts_mean          # 算子名（必须在 registry 中存在）
    inputs: [returns_20d]      # 输入列/因子名列表
    params:                    # 参数字典（映射到函数 kwargs）
      window: 20
```

### 9.2 type 与 registry category 对应表

| YAML type | executor dispatch | registry category |
|-----------|-------------------|-------------------|
| `time_series` | `_apply_ts_operator` | `time` |
| `section` | `_apply_sec_operator` | `section` |
| `math` | `_apply_math_operator` | `point` |
| `composite` | `_apply_composite_operator` | `point` / `multi_section` |

### 9.3 params 映射规则

YAML `params` 字典的 key 必须与算子函数参数名**完全一致**：

```yaml
params:
  window: 20        # → rolling_mean(f, window=20)
  alpha: 0.5        # → ewm_mean(f, alpha=0.5)
  lower: 0.01       # → winsorize(f, lower=0.01)
```

拼写错误会被 `**kwargs` 静默吸收，不会报错但算子会使用默认值。

## 10. 自定义算子规范

### 10.1 YAML 配置

```yaml
validation:
  custom_operators:
    - source: "/absolute/path/to/my_ops.py"
      category: "time_series"
      functions: ["custom_momentum"]  # 可选
```

### 10.2 自定义算子文件格式

```python
# /path/to/my_custom_ops.py
import polars as pl

def custom_momentum(f, window=20, **kwargs):
    """自定义动量因子"""
    return f / f.shift(window) - 1
```

### 10.3 自动发现规则

- 函数名以 `custom_` 开头的自动注册
- 指定 `functions` 列表时，只注册列出的函数
- 非 `custom_` 前缀的函数不自动注册

## 12. TA-Lib 技术分析集成

### 12.1 概述

QuantNodes 通过 `operators/talib.py` 集成了 TA-Lib 0.6.x（158 个技术分析指标），覆盖：
- **重叠/趋势** (17): SMA, EMA, DEMA, TEMA, WMA, KAMA, T3, BBANDS, MA, ...
- **动量** (30): RSI, MACD, STOCH, CCI, WILLR, MFI, ROC, MOM, ADX, ...
- **波动率** (3): ATR, NATR, TRANGE
- **成交量** (3): AD, ADOSC, OBV
- **K线形态** (61): CDL_DOJI, CDL_HAMMER, CDL_ENGULFING, ...
- **统计函数** (9): BETA, CORREL, LINEARREG, STDDEV, ...

### 12.2 安装

```bash
pip install TA-Lib          # 0.6.5+ 自带 C 库 binary wheel (x86_64 Linux)
pip install quantnodes[talib]  # 通过 extras 安装
```

### 12.3 YAML 配置示例

```yaml
operations:
  - type: talib
    name: rsi_14
    category: talib_rsi
    inputs: [close]
    params: {timeperiod: 14}

  - type: talib
    name: sma_20
    category: talib_sma
    inputs: [close]
    params: {timeperiod: 20}

  - type: talib
    name: bb_upper
    category: talib_bbands_upper
    inputs: [close]
    params: {timeperiod: 20, nbdevup: 2.0}
```

### 12.4 命名约定

所有 TA-Lib 算子使用 `talib_` 前缀：
- 单输出: `talib_rsi`, `talib_sma`, `talib_atr`
- 多输出拆分: `talib_macd_line`, `talib_macd_signal`, `talib_macd_hist`
- 布林带拆分: `talib_bbands_upper`, `talib_bbands_middle`, `talib_bbands_lower`

### 12.5 实现机制

TA-Lib 函数通过 `map_batches` 桥接 Polars ↔ NumPy：
```python
@staticmethod
def rsi(expr, timeperiod=14):
    import talib
    e = _ensure_expr(expr)
    return e.map_batches(
        lambda s: pl.Series(talib.RSI(s.to_numpy(), timeperiod=timeperiod)),
        return_dtype=pl.Float64,
    )
```

K线形态识别函数返回 `Int32`（-100, 0, 100），使用 `return_dtype=pl.Int32`。
