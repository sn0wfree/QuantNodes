量化全天候模型 2.0 —— 核心生产版（精简三层架构）

一、设计总纲

1.1 核心哲学

  • 少先先验，数据驱动：不预设资产类别的主观权重，让聚类和风险平价算法自主发现结构。
  • 分层兜底，危机退位：每一层都有明确的失效边界，危机时逐层退守现金，常态时逐层释放收益。
  • 不确定时不下注：信号模糊时保持中性，不赌反转。

1.2 架构取舍说明

相较于完整技术研讨版（含IPCA隐含因子），本生产核心版暂不纳入时变因子提取模块，原因如下：

  1. 前三层（负向趋势 + AVS去噪 + HRP）已构成完整闭环，足以应对常态配置与尾部危机。
  2. IPCA解决的是“结构慢变增强”问题，属于锦上添花，而非生存必需。
  3. 剔除该模块可降低60%以上的计算复杂度，避免因子提取与资产配置之间的循环依赖，使归因分析更透明。

二、核心管线架构（五步流水线）

数据流严格按顺序执行，层层递进：

日线行情 → ① AVS分层去噪协方差（估计稳定相关性） → ② HRP层次风险平价（每20个交易日慢速重平衡） → ③ 自适应负向趋势因子（逐日快速扫描）→ 乘性惩罚约束 → ④ 债券权重硬上限处理（溢出资金重分配） → ⑤ 目标波动率缩放 & 现金管理（杠杆上限2.3倍，余钱转短融ETF） → 输出最终持仓与净值

三、核心模块技术规格

3.1 模块一：AVS 分层去噪协方差（替代传统RMT）

  • 功能：在样本协方差矩阵中剥离噪声，提取稳健的相关结构。
  • 技术方案：采用分层解析方差收缩（Hierarchical AVS）。
    • 首先基于资产相关性进行Ward层次聚类。
    • 构造分块目标矩阵 F：同一簇内的相关系数保留，不同簇之间的相关系数强制归零。
    • 最优收缩强度 δ* 由MSE最小化解析给出：
      δ* = min{ 1, (N+2)/(T+N+2) · ||F||²_F / ||S−F||²_F }
      （N为资产数，T为样本天数，S为样本协方差）
    • 最终协方差矩阵：C = (1−δ*)·S + δ*·F
  • 优势：解决了传统RMT在小样本（q = T/N较大）下退化为对角矩阵的痛点，保证协方差始终带有经济结构。

3.2 模块二：HRP 层次风险平价（核心配置器）

  • 功能：分配资产权重，使得组合对各个聚类簇的风险贡献尽量均衡。
  • 执行步骤：
    1. 基于去噪后的协方差矩阵 C 计算资产距离矩阵。
    2. 进行Ward层次聚类，生成树状图。
    3. 执行递归二分风险分配（Recursive Bisection），在树状图的每个节点处，依据簇内方差进行风险平价切分。
  • 更新频率：每20个交易日重新计算一次完整的HRP权重（慢变量），避免高频换手。

3.3 模块三：自适应负向趋势因子（尾部止损）

  • 功能：在极端下跌环境中，快速降低特定资产的暴露，资金转入短融。
  • 设计逻辑：不预测底部，只识别“危墙”。
  • 构造骨架（伪代码）：
    # 1. 计算三路子信号 sub_trend = 多周期斜率标准化(returns, windows=[5,10,20]) sub_vol = 当前波动率 / 自身60日历史高分位(>60%) sub_flow = -收益率 * (1 + 波动率比率) # 价跌量增叠加惩罚 # 2. 合成综合因子 neg_trend = w1*sub_trend + w2*sub_vol + w3*sub_flow # 3. 自适应阈值（高波动环境阈值自动下移，更易触发） threshold = base_threshold * (1 - 波动率偏离系数) # 4. 生成惩罚系数（0~1之间） penalty = clip((neg_trend - low) / (high - low), 0, 1) # 5. 乘性作用于HRP权重（非替代） w_final_asset = w_HRP * (1 - penalty)
  • 异质权重说明：股票类资产更重 sub_trend，期货品种更重 sub_flow，黄金等避险资产更重 sub_vol。

3.4 模块四：债券倾斜修正（硬约束 + 重分配）

  • 背景：标准风险平价天然会过度配置低波动债券（常达60%~90%）。
  • 解决方案（方法3+2组合）：
    1. 现金踢出风险池：短融ETF不参与HRP的风险预算分配，仅作为承接溢出资金的容器。
    2. 债券权重硬上限：设定 w_bond ≤ 40%。
    3. 溢出重分配：若HRP输出的债券权重超过40%，将超出部分按风险贡献比例（RC Share）重新分配给股票、商品和黄金。
  • 动态联动：若负向趋势因子触发债券类信号，债券的“风险预算”临时减半（强制重算一次HRP），加速减仓。

3.5 模块五：目标波动率与现金停泊

  • 目标波动率：设定组合年化波动率目标为 10%。
  • 杠杆约束：允许的最大倍数不超过 2.3倍（基于国内ETF融资限制及流动性考量）。
  • 现金管理：未被占用的保证金/资金，自动投资于短融ETF，计入组合净值。

六、为什么暂不纳入“隐含因子（IPCA）”模块？

虽然IPCA在学术上可用于捕捉时变载荷，但在本生产框架中，我们将其降级为离线诊断工具：

  1. 增量收益不明确：HRP慢速重平衡已能适应数月尺度的结构漂移；负向趋势因子已覆盖突变断裂。
  2. 工程代价过高：IPCA涉及逐日交替最小二乘迭代，参数敏感，易引入过拟合噪声。
  3. 归因困难：加入IPCA后，无法清晰区分收益来源是“因子结构变化”还是“风险预算分配”。

后续扩展计划：当核心三层架构稳定运行满1年实盘或3年样本外验证后，若发现常态市场下收益提升空间显著，再考虑将IPCA以“辅助增强”形式（固定α≤0.3）引入。

七、核心公式速查表

  • AVS收缩最优解：δ* = min{ 1, (N+2)/(T+N+2) · ||F||²_F / ||S−F||²_F }
  • 负向乘性约束：w_final = w_HRP · (1 − penalty)
  • 分层目标矩阵：F = BlockDiag(簇内相关系数, 簇间=0)
  • 最终合成权重：w = ScaleToTargetVol( Redistribute( w_final ) )
