# ATR追踪止损策略

## 1. 核心逻辑

月度信号生成 + 日度ATR追踪止损

### 流程

```
月末: 生成月度信号 (sig = +1/-1/0)
  ↓
持仓期间: 每日监控止损线
  做多: 止损线 = max(前止损线, 收盘价 - 1.5×ATR14)
  做空: 止损线 = min(前止损线, 收盘价 + 1.5×ATR14)
  ↓
触发检查:
  做多: 日内最低价 ≤ 止损线 → 以止损价平仓
  做空: 日内最高价 ≥ 止损线 → 以止损价平仓
  ↓
月末: 未触发则持有至月末收盘
```

## 2. 参数

| 参数 | 值 | 说明 |
|---|---|---|
| ATR_MULTIPLE | 1.5 | 止损距离 = 1.5 × ATR |
| ATR_WINDOW | 14 | ATR计算窗口 (14日) |
| 信号频率 | 月频 | 月末生成信号 |
| 止损监控 | 日频 | 每日检查触发 |

## 3. ATR计算

```python
TR = max(high - low, abs(high - prev_close), abs(low - prev_close))
ATR14 = mean(TR, 14日)
```

## 4. 止损线更新

```python
# 做多
止损线 = max(前止损线, 收盘价 - 1.5 * ATR14)

# 做空
止损线 = min(前止损线, 收盘价 + 1.5 * ATR14)
```

## 5. 触发逻辑

```python
# 做多触发
if 日内最低价 <= 止损线:
    以止损价平仓

# 做空触发
if 日内最高价 >= 止损线:
    以止损价平仓
```
