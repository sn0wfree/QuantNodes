## 3. TVPR集成

### 3.1 TVPR简介

TV-PR (Total-Variation Predictive Regression) 是Cui et al. (2025)提出的时变因子权重估计方法。

**目标函数**:
```
min Σ_t Σ_i (r_{i,t} - x_{i,t}' β_t)^2
    + λ_tv Σ_t ||β_t - β_{t-1}||_1       (TV罚项: 控制结构性断裂)
    + λ_l1 Σ_t ||β_t||_1                  (L1罚项: 因子稀疏性)
```

**核心优势**:
- β_t随时间变化，捕捉因子关系的结构性变化
- TV罚项使β_t呈分段常数，避免频繁切换
- L1罚项可选，控制因子稀疏性

### 3.2 集成参数

| 参数 | 值 | 说明 |
|---|---|---|
| lambda_tv | 0.15 | TV平滑度 (CTA策略验证) |
| lambda_l1 | 0.0 | 不做因子稀疏 (保留所有12因子) |
| min_history | 104 | 最少104周历史 (2年) |
| step | 13 | 每13周更新权重 (季度) |
| method | 'expanding' | expanding窗口 (无前视) |

### 3.3 TVPR工作流程

```python
# 1. 构建因子矩阵 X (T, 12)
X = factors_df.values  # 每行是一个时间点的12个因子值

# 2. 计算收益率 Y (T,)
Y = close_w.pct_change().values

# 3. TVPR估计时变权重
betas = tvpr_estimator(
    Y=Y, X=X,
    lambda_tv=0.15,
    lambda_l1=0.0,
    method='expanding',
    step=13
)  # 输出: (T, 12) 时变权重

# 4. 合成仓位
position_raw = (X * betas).sum(axis=1)  # X @ β_t
```

## 4. bull_enhance集成

### 4.1 逻辑说明

bull_enhance层在v6.2中已验证有效，核心逻辑：
1. **牛市判定**: 26周动量 > 10%
2. **增强条件**: 多因子确认 (库存低 / 期限结构back / 铜油比强)
3. **增强幅度**: 仓位提升至0.9

### 4.2 增强条件

```python
bull = mom26 > 0.10  # 牛市判定

# 增强条件 (任一满足)
enhance = bull & (
    (lme_z < -0.5) |           # 库存低于均值0.5σ
    (carry > 0.7) |             # 强backwardation
    (cu_crude > 0.6)            # 铜油比强势
)
```

### 4.3 增强幅度

```python
position_enhanced = position_raw.copy()
position_enhanced[enhance] = np.maximum(position_enhanced[enhance], 0.9)
```

## 5. 波动率目标化

### 5.1 参数

| 参数 | 值 | 说明 |
|---|---|---|
| target_vol | 0.12 | 目标年化波动率 |
| vol_window | 4 | 4周波动率窗口 |
| max_scale | 1.0 | 最大缩放因子 (无杠杆) |

### 5.2 公式

```python
ret_w = close_w.pct_change()
vol_4w = ret_w.rolling(4).std() * np.sqrt(52)
scale = (target_vol / vol_4w).clip(upper=1.0)
position_final = (position_enhanced * scale).clip(upper=1.0)
```

## 8. 风险提示

1. **TVPR过拟合**: λ_tv和λ_l1需要在OOS上验证
2. **热身期**: 前2年无TVPR权重，可能表现不佳
3. **因子相关性**: 12个因子可能存在多重共线性
4. **市场regime**: TVPR假设因子关系分段常数，极端regime可能失效
