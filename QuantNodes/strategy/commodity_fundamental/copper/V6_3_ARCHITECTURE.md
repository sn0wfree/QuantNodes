# v6.3 多因子架构设计

## 1. 设计目标

v6.3 是 v6 系列的重构版本，采用清晰的多因子体系：

- **因子独立**：每个因子单独计算，互不干扰
- **分组管理**：同类因子归入一组，组内加权合成
- **权重可调**：组间权重、组内权重均可配置
- **统一风控**：最后统一做波动率目标化

## 2. 架构图

```
┌─────────────────────────────────────────────────────────────┐
│                    因子计算层 (12个因子独立计算)                │
├─────────────────────────────────────────────────────────────┤
│  动量组: mom_2w, mom_13w                                     │
│  宏观组: dxy_z, pmi, industry_dz                            │
│  库存组: lme_z, quadrant_pos                                │
│  期限结构组: carry, curvature                               │
│  波动率组: vol_13w_z, vol_pct                               │
│  跨资产组: cu_crude                                          │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│                    组内合成层 (同组因子加权)                    │
├─────────────────────────────────────────────────────────────┤
│  mom_score    = w1*mom_2w + w2*mom_13w                      │
│  macro_score  = w3*dxy_z + w4*pmi + w5*industry_dz          │
│  inv_score    = w6*lme_z + w7*quadrant_pos                  │
│  term_score   = w8*carry + w9*curvature                     │
│  vol_score    = w10*vol_13w_z + w11*vol_pct                 │
│  cross_score  = cu_crude                                    │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│                    跨组合成层 (组间加权)                       │
├─────────────────────────────────────────────────────────────┤
│  position = 0.30*mom + 0.25*macro + 0.20*inv               │
│           + 0.15*term + 0.05*vol + 0.05*cross               │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│                    风控层 (统一处理)                           │
├─────────────────────────────────────────────────────────────┤
│  1. 波动率目标化: scale = target_vol / realized_vol          │
│  2. 仓位上限: position *= scale, clip(0, 1)                │
└─────────────────────────────────────────────────────────────┘
```
