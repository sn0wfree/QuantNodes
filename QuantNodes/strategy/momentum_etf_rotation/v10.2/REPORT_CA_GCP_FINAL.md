# CA-GCP v10.2 最终报告

## 1. 项目概述

### 1.1 目标
在双动量策略（Dual Momentum）基础上引入 CA-GCP（Cross-Asset Graph Conformal Prediction）风险控制层，通过 prediction interval 监控实现动态仓位管理。

### 1.2 策略架构
- **底层策略**：双动量（月频调仓，4只ETF：A股/美股/黄金/国债）
- **风控层**：CA-GCP（周频检查，基于 prediction interval width 和 stress 指标）
- **信号频率**：月频动量 + 周频风控 + 日频持仓

### 1.3 核心参数
| 参数 | 值 | 说明 |
|------|-----|------|
| k | 6 | 图邻域数 |
| eta | 0.5 | 灵敏度 |
| tau | 20 | 衰减窗口 |
| red_scale | 0.6 | 红色警报缩仓比例 |
| yellow_scale | 0.85 | 黄色警报缩仓比例 |
| cost_bp | 10 | 交易成本（基点） |
| trend_filter | True | 趋势过滤（上涨趋势中跳过alert） |
| trend_window | 5 | 趋势窗口（交易日） |
| trend_threshold | 0.02 | 趋势阈值（滚动收益） |

## 3. 市场环境判断方案全景测试

### 3.1 已测试方案汇总

| 方案 | 思路 | 全时段Sharpe | WF平均Sharpe | 结论 |
|------|------|-------------|-------------|------|
| **趋势过滤** (tw=5, thr=0.02) | 上涨趋势中跳过CA-GCP alerts | **0.714** | **1.755** | ✅ 有效，推荐 |
| NoGate (baseline) | CA-GCP始终启用 | 0.665 | 1.688 | - |
| GateAND | 波动率+相关性双触发才启用 | 0.615 | 1.723 | ❌ 全时段差 |
| ADX (min_scale=0.7) | 趋势强度调节仓位 | 0.545 | 1.372 | ❌ 收益太低 |
| Fusion (w_risk=1, min=0.7) | 波动率+CA-GCP融合 | 0.578 | 1.642 | ❌ 收益太低 |
| HMM (3状态) | 隐马尔可夫模型识别牛/熊/震荡 | - | - | ❌ 状态切换太频繁 |
| Bare | 纯双动量，无风控 | 0.501 | 1.665 | ❌ 波动最大 |

### 3.2 各方案详细分析

#### 趋势过滤 ✅ 推荐
- **原理**：短期（5日）滚动收益 > 2% 时认为是上涨趋势，跳过 CA-GCP 的降仓预警
- **效果**：
  - 全时段 Sharpe +0.049（vs NoGate）
  - WF 平均 Sharpe +0.067
  - 换手率略降（11.7x vs 12.5x）
- **成功原因**：
  1. 短窗口（5日）比长窗口（20日）更灵敏，能快速响应
  2. 小阈值（0.02）确保轻微下跌就触发保护
  3. 在上涨趋势中让利润奔跑，不被 CA-GCP 预警打断
- **注意**：参数敏感，tw=20/thr=0 效果差

#### ADX ❌ 不推荐
- **问题**：
  1. 只有收盘价，没有 OHLC，ADX 精度受限（简化版）
  2. ADX 对4资产等权组合几乎没有预测力（各十分位未来收益无差异）
  3. 独立乘数方式导致仓位系统性偏低，拖累收益
  4. 换手率翻倍（22.5x vs 12.5x），交易成本高

#### 多信号融合 ❌ 不推荐（当前配置）
- **问题**：
  1. 纯风险信号（波动率+CA-GCP）导致仓位太低，年化收益只有 6.74%
  2. 加入趋势成分（ADX+均线）反而拉低表现
  3. 换手率太高（23.8x）
- **如果 min_scale 设得很高（如0.8-0.9）**，效果接近 NoGate，失去意义

#### HMM ❌ 不推荐
- **问题**：
  1. 2022-2026期间没有识别出 bear 状态（只有 bull 和 neutral）
  2. 状态切换太频繁（几乎每天变），不稳定
  3. 2维特征（收益+波动率）太少，4资产组合噪声大
  4. 整体表现远不如 NoGate

### 3.3 核心发现

**趋势过滤是唯一真正有效的市场环境判断方案。**

原因分析：
1. **简洁有效**：只判断"是不是上涨趋势"，二进制决策，参数少
2. **互补性强**：CA-GCP 擅长风险预警，趋势过滤擅长确认上涨环境，两者互补
3. **减少误判**：上涨趋势中 CA-GCP 的 width_z 波动往往是噪音，跳过能减少假警报
4. **换手率低**：只改变 alert 是否生效，不增加额外交易

## 5. 推荐配置

### 5.1 最优参数

```python
# CA-GCP 核心参数
cfg = CAGCPConfig(k=6, sensitivity_eta=0.5, recency_tau=20)

# 风险过滤规则（最优：趋势过滤 + NoGate）
rules = RiskFilterRules(
    width_z_yellow=3.0,
    width_z_red=4.5,
    stress_yellow=0.92,
    stress_red=0.98,
    yellow_scale=0.85,
    red_scale=0.6,
    confirm_threshold=2,
    min_hold_days=5,
    # 趋势过滤（最优配置）
    trend_filter=True,
    trend_window=5,
    trend_threshold=0.02,
    # ADX 和 Fusion 不推荐使用
    adx_filter=False,
    fusion_enabled=False,
)

# 策略调用
nav, diag = dual_momentum_with_ca_gcp(
    daily_prices, weekly_prices, pipe, etf_returns,
    rules=rules, cost_bp=10,
    use_gate=False,  # 不使用 gate
)
```

## 6. 后续优化方向

### 6.1 短期（可立即实施）
1. **Per-fold 参数校准**：每个 fold 独立优化 k/eta/tau 和趋势过滤参数
2. **趋势过滤 + Gate 组合**：趋势过滤和 Gate 可能互补，值得测试
3. **调整 red_scale**：从 0.6 改为 0.7，在保护和收益间找平衡

### 6.2 中期（需要更多数据/资产）
1. **扩展资产池**：从4只ETF扩展到38+只，提升 CA-GCP 和 HMM 信号质量
2. **周频调仓**：从月频改为周频，加快响应速度

### 6.3 长期（架构升级）
1. **机器学习择时**：更多特征 + 更复杂模型
2. **强化学习**：端到端优化仓位管理
