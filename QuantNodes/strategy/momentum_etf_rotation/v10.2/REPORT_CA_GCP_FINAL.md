# CA-GCP v10.2 最终报告

## 1. 项目概述

### 1.1 目标
在双动量策略（Dual Momentum）基础上引入 CA-GCP（Cross-Asset Graph Conformal Prediction）风险控制层，通过 prediction interval 监控实现动态仓位管理。

### 1.2 策略架构
- **底层策略**：双动量（月频调仓，4只ETF：A股/美股/黄金/国债）
- **风控层**：CA-GCP（周频检查，基于 prediction interval width 和 stress 指标）
- **信号频率**：月频动量 + 周频风控 + 日频持仓

### 1.3 核心参数
| 参数 | 值 | 说明 |
|------|-----|------|
| k | 6 | 图邻域数 |
| eta | 0.5 | 灵敏度 |
| tau | 20 | 衰减窗口 |
| red_scale | 0.6 | 红色警报缩仓比例 |
| yellow_scale | 0.85 | 黄色警报缩仓比例 |
| cost_bp | 10 | 交易成本（基点） |

## 3. 模式对比分析

### 3.1 三种模式定义

| 模式 | CA-GCP | Gate | 说明 |
|------|--------|------|------|
| **Bare** | ✗ | ✗ | 纯双动量，无风控 |
| **NoGate** | ✓ | ✗ | CA-GCP 始终启用（最优模式） |
| **GateAND** | ✓ | ✓ | CA-GCP 仅在波动率+相关性双触发时启用 |

### 3.2 模式优劣

| 指标 | Bare | NoGate | GateAND |
|------|------|--------|---------|
| Sharpe | 最低 | **最高** | 中间 |
| MaxDD | 最差 | **最好** | 中间 |
| Turnover | 最低(5x) | 最高(9x) | 中间(7x) |
| Alerts | 0 | 多(25) | 少(15) |
| 复杂度 | 低 | 低 | 高 |

### 3.3 结论

**NoGate 模式在所有时段都是最优的。**

原因：
1. CA-GCP 只做仓位管理（scale=0.6/0.85），不做方向判断
2. 不依赖市场状态判断，避免误判
3. 保持动量信号的完整性，不被外部指标干扰

## 4. 择时方案测试总结

### 4.1 已测试方案

| 方案 | 思路 | 结果 | 问题 |
|------|------|------|------|
| Adaptive Gate | 波动率+相关性判断是否启用CA-GCP | 减少alerts 42% | MaxDD反而恶化 |
| 趋势过滤 | 上涨趋势中跳过alerts | 减少alerts 50% | 错过反转保护 |
| 残差→现金 | 缩仓时不买任何资产 | 危机时更干净 | 系统性降低年化收益 |
| 残差→国债 | 缩仓时买入国债 | 国债每年正收益 | 危机时国债也亏 |
| 降低red_scale | 0.6→0.7/0.8 | 减少残差拖累 | 保护力度减弱 |
| 缩短min_hold | 5天→2-3天 | 更快恢复满仓 | 可能频繁切换 |

### 4.2 核心发现

**所有择时方案的共同问题：**

1. **无法预测市场拐点**
   - 2022.10: stress=0.999 → 触发red alert → 但11月A股暴涨+10.52%
   - 趋势过滤试图解决这个问题，但过滤后反而更差

2. **保护和收益的根本矛盾**
   - 保护强 → 错过反弹 → 收益低
   - 保护弱 → 错过下跌 → 回撤大

3. **信号滞后不可避免**
   - stress/width_z 是后视指标（基于历史数据）
   - 月频调仓进一步延迟响应
   - hysteresis（min_hold=5天）再加延迟

### 4.3 最终结论

**择时方案不适合本策略。CA-GCP 的价值在于仓位管理（降低波动），而非方向判断。**

## 7. 后续优化方向

### 7.1 短期（可立即实施）
1. **Per-fold 重新校准 k/eta/tau**：每个 fold 独立优化参数
2. **动态止损**：回撤 > 8% 时强制切换到国债
3. **调整 red_scale**：从 0.6 改为 0.7，减少残差拖累
