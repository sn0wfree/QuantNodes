# 教训 007: Lasso 在高维场景下的稀疏解

## 日期
2026-07-28

## 严重度
MODERATE

## 问题描述

v7.3.2 设计了 β 预筛选 + 分散度约束（n_assets=15），但实际运行中从未触发 — FRP 已自然稀疏（6-8 只活跃资产）。

## 根因

修复数据管道后，β 矩阵恢复正常，Lasso 的 L1 正则化自然产生稀疏解。FRP 优化器在稀疏 β 上进一步优化，结果已经很稀疏。

## 教训

1. **先修 bug 再加功能**：数据管道 bug 修复后，很多"优化"变得冗余
2. **稀疏性是 Lasso 的内生属性**：不需要额外约束来实现稀疏
3. **验证假设再实施**：先确认问题存在（45.5 只活跃），再设计解决方案

## 防范流程

1. **修复优先**：先修复已知 bug，再考虑优化
2. **量化验证**：用数据确认问题存在，再设计方案
3. **A/B 测试**：对比有/无约束的结果，确认约束有效
