## 当日教训

### L-20260716-1: 截面因子 vs 时序因子用不同 IC 计算方法 [HIGH]

**问题**：`fd7fc94` 宏观因子默认用对数收益率 + 区分截面/时序 IC：

```python
# PV 因子 (k≥17): 截面 IC — 选股能力
ic = spearmanr(contrib[t,:], Y[t+1,:])

# 宏观因子 (k≤16): 时序 IC — 择时能力
#   因为对所有资产截面值相同, 截面 IC 会返回 NaN
ic = spearmanr(β_k[t] × X[t,0,k], mean(Y[t+1,:]))
```

**教训**：
1. **不要寄希望于通用 `compute_ic(factor_panel)` 一个函数搞定**
2. 截面 IC 衡量"选股能力"（同一时间不同资产）
3. 时序 IC 衡量"择时能力"（同一资产不同时间）
4. 宏观因子对所有资产截面值相同 → 截面 IC 必然 NaN

**正确做法**：
1. **所有 IC 计算代码**：必须明确"截面 or 时序"
2. **宏观因子**：用时序 IC（β × X vs mean(Y)）
3. **PV 因子**：用截面 IC（contrib vs Y）

**关联**：[05_LESSONS_LIBRARY §L-102](../research_history/05_LESSONS_LIBRARY.md) 截面因子 vs 时序因子

### L-20260716-2: macro 沿时间复制，PV 沿截面填充 [HIGH]

**问题**：`09a4e35` 数据加载器：宏观因子 vs PV 因子用不同标准化方式。

**原则**：
| 类型 | 标准化维度 | 备注 |
|------|----------|------|
| 宏观因子 | 时间维 Z-score | 沿时间标准化（同一宏观信号在不同资产含义相同）|
| PV 因子 | 截面 Z-score | 沿资产标准化（不同资产量级差异大）|

**正确做法**：
```python
# 宏观因子: 沿时间
macro_normalized = (macro - macro.mean()) / macro.std()  # 时间维

# PV 因子: 沿截面
pv_normalized = (pv.T - pv.T.mean()) / pv.T.std()  # 截面维
```

**应用**：
1. **所有因子标准化**：明确"沿时间 or 沿截面"
2. **不要一刀切**

**关联**：[05_LESSONS_LIBRARY §L-222](../research_history/05_LESSONS_LIBRARY.md) macro 沿时间复制，PV 沿截面填充

### L-20260716-3: 特质波动率计算需要考虑窗口稳定性 [MEDIUM]

**问题**：`8045aae` 修复 NaN + 优化特质波动率计算。

**教训**：
1. 特质波动率 = 总波动 - 系统性波动（β × 市场波动）
2. 窗口太短（< 30 日）：噪声大
3. 窗口太长（> 252 日）：滞后
4. 推荐：60 日滚动 + 至少 30 个非 NaN

**正确做法**：
```python
def specific_volatility(returns, market_returns, beta, window=60):
    """特质波动率"""
    systematic = beta * market_returns
    specific = returns - systematic
    # 滚动波动率, 至少 30 个非 NaN
    return specific.rolling(window, min_periods=30).std()
```
