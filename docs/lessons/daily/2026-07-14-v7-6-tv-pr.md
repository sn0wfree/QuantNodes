## 当日教训（重大发现）

### L-20260714-1: 连续 TF Score 理论优于二值，实测退步 -68% [HIGH]

**问题**：`f34e4ee` V7.5 Step 2 连续 TF Score 替代二值 MA200：

| 配置 | Calmar |
|------|--------|
| 二值 TF | 0.981 |
| 连续 TF Score | **0.317 (-68%)** ❌ |

**根因**：
1. 连续 TF Score 在边界（TF=0.5 附近）震荡剧烈，导致频繁切换
2. 二值 TF 有明确冷却期（MA200 稳定后才切换），减少交易
3. "理论更精细"≠"实测更好"——金融工程里过度拟合的常见陷阱

**正确做法**：
1. **任何"理论更优"**：必须先 OOS 回测
2. **二值 vs 连续**：保守用二值（边界明确）
3. **连续变量风险**：边界震荡 + 高换手 = 退步

**关联**：[05_LESSONS_LIBRARY §L-133](../research_history/05_LESSONS_LIBRARY.md) 连续 TF Score 理论优于二值，实测退步

### L-20260714-2: 时变 LASSO rolling 156w 实测退步 -66% [HIGH]

**问题**：`5f44fbf` V7.5 Step 3 时变 LASSO（Rolling Window 156w）：

| 窗口 | Calmar |
|------|--------|
| expanding | 0.981 |
| rolling 156w | **0.333 (-66%)** ❌ |

**根因**：
1. rolling 窗口引入"老数据丢弃"——LASSO 学到的模式是短暂的
2. expanding 累积所有历史，β 估计更稳定
3. 156 周（约 3 年）样本量不足以稳定估计 36+ 因子

**正确做法**：
1. **时变估计**：优先 expanding
2. **rolling 仅做"稳健性测试"**：不放生产
3. **窗口大小**：必须 ≥ 8x 因子数（36 因子 → 至少 288 周）

**关联**：[05_LESSONS_LIBRARY §L-134](../research_history/05_LESSONS_LIBRARY.md) 时变 LASSO 实测退步

### L-20260714-3: V6.2 起点依赖 56.9% FAIL → DEPRECATED [CRITICAL]

**问题**：`223ef65` V6.2 添加交易成本 + 起点依赖测试：

| 策略 | CV% | 状态 |
|------|------|------|
| v6.2 5-fold OOS | 4/5 胜 | 看起来 PROMISING |
| v6.2 **起点依赖** | **56.9%** | **DEPRECATED** ⚠️ |
| v7.10 起点依赖 | 16.6% | PASS ⭐ |

**教训**：
- 5-fold OOS 是"K-fold 总体测试"
- 起点依赖是"单起点稳健性测试"
- 两者都通过才算稳健
- V6.2 5-fold 通过但起点依赖 56.9% → 过拟合

**正确做法**：
1. **CV% 测试**：5+ 不同起点 OOS
2. **阈值**：< 25% PASS / 25-50% PROMISING / > 50% DEPRECATED
3. **必须两测都过**：5-fold + 起点依赖

**关联**：[05_LESSONS_LIBRARY §L-203](../research_history/05_LESSONS_LIBRARY.md) 起点依赖测试 / §L-321 5 道闸门

### L-20260714-4: V7.6 TV-PR 频率从日频改周频是设计决策 [MEDIUM]

**问题**：`fc7fc5a` V7.6 修复 22 个问题，频率改为周频。

**教训**：
1. 因子计算 + TV-PR 训练 → 周频（避免日频噪声）
2. NAV 计算 + 业绩展示 → 日频（连续性）
3. 混频 = 错误（周频信号用日频权重 = 提前一天成交）

**正确做法**：
```python
# 周频信号 → 日频执行
weekly_signal = compute_signal(weekly_panel)  # 周频
daily_weights = expand_to_daily(weekly_signal) # 转换为日频权重
# 关键: daily_weights[t] 必须使用 weekly_signal[t-1] 的信号
#      (避免同日信号 + 同日成交 = look-ahead)
```

**关联**：[05_LESSONS_LIBRARY §L-221](../research_history/05_LESSONS_LIBRARY.md) 周频特征 + 日频执行的双频体系

### L-20260714-5: V7.6 walk_forward 必须用 NO LOOKAHEAD 原则 [HIGH]

**问题**：`826db4d` V7.6 实现 Walk-Forward + 滚动窗口 + warm-start。

**核心原则**：
```python
# 提供 backtest_fn(Y_train, X_train, **params) → (weights, returns)
# β 估计只用训练数据（Y_train = Y.iloc[:test_start]）
def backtest_fn(Y_train, X_train, **params):
    # 只用 Y_train 训练
    beta = estimate_beta(X_train, Y_train)
    # 测试期用 Y_test 应用权重
    weights = compute_weights(beta, X_test)
    return weights, Y_test
```

**应用**：
1. **walk_forward**：train → test 严格分离
2. **warm-start**：从训练期最后状态开始，不是从零
3. **rolling window**：每窗口重新训练，避免使用未来数据

**关联**：[05_LESSONS_LIBRARY §L-233](../research_history/05_LESSONS_LIBRARY.md) walk_forward 框架通用化
