## 当日教训

### L-20260717-1: Symmetry 正交化破坏因子信息结构 [CRITICAL]

**问题**：`db4a852` V7.9 正交化实验：
- 应用 Symmetry 正交化前：Sharpe 1.40
- 应用 Symmetry 正交化后：**Sharpe 0.15（-91%）** ❌

**根因**：
1. **等方差变换抹杀相对强度**：所有因子缩放到同方差，丢失了"哪个因子更重要"的信息
2. **ADMM 的 L1 罚项依赖原始尺度做因子选择**：等方差后所有因子被平等对待，Lasso 退化为 Ridge
3. **看似"数学干净"，实则让时变 β 估计失效**

**正确做法**：
```python
# 错误: Symmetry 正交化（等方差）
def symmetry_orth(X):
    """等方差正交化: 把所有列缩放到单位方差"""
    return X / X.std(axis=0)  # ❌

# 正确 1: 只做因子去重（删高度相关）
# f18_mom_short ↔ f21_reversal, r=-1.000 → 删 f21
# f3_amt_vol ↔ f4_vol_vol, r=0.958 → 删 f4
# f8_pv_rankcov ↔ f9_pv_corr, r=0.938 → 删 f9

# 正确 2: log 变换（处理偏态量纲）
X_log = np.log1p(X)  # 处理右偏分布

# 正确 3: 保留原始因子尺度
X_orig = X  # 不要变换

# 不要: 任何"对称化"操作
```

**应用**：
- 只做因子去重（删高度相关）+ log 变换（处理偏态量纲）
- 保留原始因子尺度

**关联**：[05_LESSONS_LIBRARY §L-104](../research_history/05_LESSONS_LIBRARY.md) Gram-Schmidt 残差化有效，QR 对称正交失败 / §L-109 Symmetry 正交化破坏因子信息结构
