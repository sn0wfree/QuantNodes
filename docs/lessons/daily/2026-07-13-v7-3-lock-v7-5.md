### L-20260713-2: NaN 跨缺口 bug 是数据质量红线 [HIGH]

**问题**：`bb382dc` 修复 v9_indices_daily 数据 NaN 跨缺口 bug。

**根因**：原始数据有"跨日缺口"（如停牌、节假日），pct_change 默认会把 NaN 视为 0，导致：
- 跨缺口的"虚假收益"（连续 0 收益被错误计算为 0%）
- 或者"跨缺口收益"（如停牌后第一天的涨跌幅被错误归到停牌期间）

**正确做法**：
```python
# 错误: 直接 pct_change
returns = nav.pct_change()  # 默认会填 0

# 正确: NaN-safe
returns = nav.pct_change().where(nav.shift(1).notna() & nav.notna())
# 跨缺口收益不应计算
```

**关联**：[05_LESSONS_LIBRARY §L-213](../research_history/05_LESSONS_LIBRARY.md) NaN-safe pct_change

### L-20260713-3: n_years 计算必须用日期差，不是数据点数 [HIGH]

**问题**：`7f330d9` + `0a1c3dc` 修正 n_years 计算：
- **错误**：`n_years = len(returns) / 252`（假设每年 252 交易日）
- **正确**：`n_years = (end_date - start_date).days / 365.25`（真实日历）

**根因**：
1. 252 是交易日，不是自然日
2. 数据可能不全（节假日、停牌、上市前）
3. 年化指标必须用真实日历年数

**正确做法**：
```python
# 错误
n_years = len(returns) / 252

# 正确
n_years = (returns.index[-1] - returns.index[0]).days / 365.25

# 更稳健
n_years = (returns.index[-1].year - returns.index[0].year) + \
          (returns.index[-1].dayofyear - returns.index[0].dayofyear) / 365.25
```

**应用**：
1. **年化 Sharpe**：`sharpe * sqrt(n_periods_per_year)` → 错误
2. **年化 Sharpe**：`sharpe = mean(daily_ret) / std(daily_ret) * sqrt(252)` → 252 是交易日约定
3. **n_years 用真实日历**：与回测长度一致

**关联**：[05_LESSONS_LIBRARY §L-302](../research_history/05_LESSONS_LIBRARY.md) 高 Ann ≠ 高 Calmar

### L-20260713-5: 硬止损 10% DD 是 P0 风控层 [MEDIUM]

**问题**：`02f63ad` V7.5 Step 1 - 硬止损（Stop Loss, 10% DD），OOS Calmar +20%。

**正确做法**：
```python
def apply_stop_loss(nav, dd_threshold=0.10):
    """当回撤 > 10% 时减仓至 0"""
    peak = nav.cummax()
    drawdown = (nav - peak) / peak
    # 当 dd < -10% 时清仓
    in_stop = drawdown < -dd_threshold
    weights = np.where(in_stop, 0.0, 1.0)
    return weights
```

**应用**：
1. **硬止损**：简单阈值（dd < -10%）清仓
2. **冷却期**：触发后 N 天不再开仓（避免反弹追高）
3. **与 TF 协同**：止损 + 趋势过滤

**关联**：[05_LESSONS_LIBRARY §L-321](../research_history/05_LESSONS_LIBRARY.md) 5 道闸门
