### L-20260709-1: OHLCV 各字段必须同口径调整 [CRITICAL]

**问题**：`49d8420` 修复 9 只 ETF 拆合股检测（OHLCV 各字段必须同口径调整）：
- 修复前：v5 2024 收益 **87.36%**（虚假）
- 修复后：v5 2024 收益 **35.55%**（真实）
- v5 Calmar: 0.643 → 0.764 (+19%)

**根因**：拆合股时，市场只调整价格，不调整历史价格。各字段（open/high/low/close）必须用同一调整因子，但 volume 是否乘价格复权因子需要按需选择（价格连续性 vs 真实成交金额）。

**正确做法**：
```python
# 1. 检测拆合股: |日收益| > 50%（绝对阈值）
abs_daily_ret = close.pct_change().abs()
suspect_days = abs_daily_ret > 0.50

# 2. 计算累积调整因子
adj_factor = (close / close.shift(1)) / (1 + ret_no_adj)
cum_adj = adj_factor.cumprod()

# 3. 同字段同调整
for col in ['open', 'high', 'low', 'close']:
    df[col] = df[col] / cum_adj

# 4. volume 可选：保留真实成交金额 或 同步调整
df['volume'] = df['volume'] * cum_adj  # 价格连续性优先
```

**防范流程**：
1. **任何回测前**：先跑 `fix_ohlcv_adjust.py`
2. **复权阈值**：50% 绝对日收益
3. **OHLCV 同字段同调整**：open/high/low/close 一致
4. **volume 选择**：根据策略类型（趋势 vs 量价）决定

**关联**：[05_LESSONS_LIBRARY §L-211](../research_history/05_LESSONS_LIBRARY.md) OHLCV 各字段必须同口径调整

### L-20260709-2: 简单规则常胜复杂 IC 择时 [CRITICAL]

**问题**：`e983294` 6 因子 IC 诊断发现：
- 仅 `value` 稳定正 IC（mean +0.044, hit 60%, IR 0.17）
- `reversal` / `dividend` 是稳定负 alpha（A 股无反转效应）
- `low_vol` 是反指因子（IC -0.454），已删除
- 短期 IC 记忆 4-13 周最佳

**结论**：静态 value 单买 = Calmar 0.638，比复杂 IC 择时更好。

**根因**：
1. 复杂 IC 择时依赖因子 IC 的稳定性，但 IC 本身在 A 股噪声极大
2. 因子 IC 多为弱信号（|IC| < 0.05），加权后收益被交易成本吞噬
3. 单一稳定因子 + 简单加权，反而能保留信号强度

**正确做法**：
```python
# 错误: 6 因子等权 + IC 加权
weights = normalize(factor_panel.apply(ic_weight))

# 正确: 单因子 + 等权
value_ic = compute_ic('value', Y, window=60)
weights = normalize(value_ic)  # 仅用 value
```

**防范流程**：
1. **新因子加入前**：先测试简单单因子等权 baseline
2. **奥卡姆剃刀**：金融工程里是硬规律
3. **复杂化前**：必须有显著统计 evidence

**关联**：[05_LESSONS_LIBRARY §L-101](../research_history/05_LESSONS_LIBRARY.md) 简单规则常胜复杂 IC 择时

### L-20260709-6: 起跑日对齐不要全局硬改，改为各策略独立削平 [HIGH]

**问题**：NAV 起跑日对齐 3 次反复：
- `f0cd21b`：同图内取"最晚首次交易日"为起跑（无法跨图比较）
- `c52b227`：全局强制 `2019-04-30`（隐藏 v5 早段收益）
- `bb5971d` ⭐：各策略独立削平 `trim_flat_prefix()`（信息保留完整）

**正确做法**：
```python
# 错误: 全局强制起跑日
def align_start(navs, start_date='2019-04-30'):
    return {k: v.loc[start_date:] for k, v in navs.items()}

# 正确: 各策略独立削平
def trim_flat_prefix(nav, min_threshold=1e-4):
    """找到 nav 第一次显著 > 1.0 的日期"""
    first_active = (nav > 1.0 + min_threshold).idxmax()
    return nav.loc[first_active:]

# 公平比较: 另取共同有效区间
def common_period(navs_dict):
    starts = [trim_flat_prefix(n).index[0] for n in navs_dict.values()]
    return max(starts)
```

**防范流程**：
1. **业务上推荐**："各策略独立削平"
2. **公平比较应另取共同有效区间**
3. **不要"为对齐而对齐"**：隐藏有效信号

**关联**：[05_LESSONS_LIBRARY §L-212](../research_history/05_LESSONS_LIBRARY.md) 起跑日对齐不要全局硬改
