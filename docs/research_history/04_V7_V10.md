## 五、教训库（V7–V10 专项）

### Look-ahead bias 类（TV-PR 反复踩坑，4 条）

1. **`full_sample_tvpr` 有前视偏差**：用全量 [0, T] 估计 β_t，β[t] 包含 t 之后的数据。修复：默认 `method="expanding"`；`method="admm"` DEPRECATED。**expanding OOS Sharpe 1.57 优于 full_sample 1.11** ⭐
2. **X[t] 预测 Y[t]（同期）而非 Y[t+1]**（`0c1c6a4` 6 bug + `4be2fa3` 彻底修复）：原信号在 t 周五生成，但用了 t 周收益构造训练集。**X[t] → Y[t+1] 严格重构 + 日频 NAV 映射**
3. **v7.7 数据 Y[t] 和 f18_mom_short[t] 完全重叠**（`f22c407` 修复）：导致 corr=0.96；修复后所有模型 R² ≈ 0
4. **v7.10 OOS Calmar 0.671 → 0.486 → 0.466 off-by-one bug**：`688862d` + `eaa6c9b` + `ead005c` 4 步验证

### OOS 验证类（5 条）

1. **5-fold OOS 不够**：5-fold OOS 通过（C.Beta Calmar 6.29）但 5 起点 CV% 50.2% FAIL → 必须多起点 + CV% < 25% ⭐
2. **起点依赖测试是 P0 任务**：v6.2 CV% 56.9% FAIL 直接导致 DEPRECATED；v7.10 CV% 16.6% < 25% PASS ⭐
3. **expanding-window OOS 优于 rolling**：`v7/tvpr_estimator.py` expanding 跨窗口平均 Sharpe 1.40 vs rolling 52/104/208w 全部 1.57
4. **敏感性测试 10 阶段**：5 个 🔴 红色 Phase 暴露严重过拟合
5. **多窗口对比**：full_sample 0.93 / expanding 2.25 → expanding 是首选

### 因子工程类（7 条）
