#### L-102: 截面因子 vs 时序因子用不同 IC 计算方法

> **首次**：v7.11 (`5c30172`, 2026-07-20)
> **当前结论**：PV 截面 IC + 宏观时序 IC 必须分别实现

**代码原则**：
```python
# PV 因子 (k≥17): 截面 IC — 选股能力
ic = spearmanr(contrib[t,:], Y[t+1,:])

# 宏观因子 (k≤16): 时序 IC — 择时能力（因为对所有资产截面值相同, 截面 IC 会返回 NaN）
ic = spearmanr(β_k[t] × X[t,0,k], mean(Y[t+1,:]))
```

**应用**：
- 所有 IC 计算代码必须明确"截面 or 时序"
- 不要寄希望于通用 `compute_ic(factor_panel)` 一个函数搞定

#### L-131: HMM 在 A 股 2018-2026 几乎只识别"震荡市"

> **首次**：v4 HMM 深度研究 (`64dcba4`, `bcc3b9a`)
> **当前结论**：HMM regime-based meta-allocator 难以发挥作用，必须配合 distance prior

**distance prior 公式**：
```python
POTENTIAL = {0:0.0, 1:0.5, 2:1.0}  # bear / transition / bull
rate[i,j] = exp(-α × d_eff(i,j))
d_eff = d + γ × (potential[i] - potential[j])
```

**应用**：
- 用 distance prior HMM，不要用无先验 HMM
- HMM 在 A 股是"震荡市检测器"，不是"牛市检测器"

#### L-204: X[t]→Y[t+1] 信号-执行同期是常见陷阱

> **首次**：v7.6 未来函数 6 Bug (`0c1c6a4`)
> **当前结论**：信号在 t 周五生成，但若用了 t 周收益构造训练集就是同期（look-ahead）

**修复要点**：
```python
# 错误: 用 t 周收益训练，预测 t+1 周
Y[t] = (NAV[t] / NAV[t-1]) - 1  # 默认 t-1 到 t
# 但 (X[t], Y[t]) → 这是同期训练, look-ahead!

# 正确: 用 t-1 周收益训练，预测 t 周
Y[t] = (NAV[t] / NAV[t-1]) - 1  # t-1 → t
X[t-1] → Y[t]  # 严格下一期
```

**应用**：
- 训练时必须有明确的"t 定义"
- 写代码注释：`X[t] → Y[t+1]`

#### L-205: v7.7 Y[t] 和 f18_mom_short[t] 完全重叠，corr=0.96

> **首次**：v7.7 (`f22c407`, 2026-07-19)
> **当前结论**：看起来"高预测力"的因子，可能跟 Y 是同口径

**反推**：
```python
# f18_mom_short[t] = nav[t] / nav[t-1] - 1   ← t-1 → t 收益
# Y[t]              = nav[t] / nav[t-1] - 1   ← t-1 → t 收益
# → 必然 corr=1.0 (or 0.96 with epsilon)
```

**修复**：
```python
Y[t] = (nav[t+1] / nav[t]) - 1  # t → t+1
f18_mom_short[t] = (nav[t] / nav[t-1]) - 1  # t-1 → t
# → corr 应该为 0 (independent tests)
```

**应用**：
- 任何"高 IC 因子"先做"Y 重叠检查"
- corr=1.0 必有 bug

#### L-213: NaN-safe pct_change：避免跨缺口收益与伪零收益

> **首次**：v7.14 (`6ad3f88`, 2026-07-20)
> **当前结论**：必须显式禁用隐式填充并设置 gap rule

**修复要点**：

#### L-214: 动态资产池（min_assets=10）作为最简洁工程

> **首次**：v7.14 (`40e2d52`, 2026-07-20)
> **当前结论**：动态资产池 > 静态 + 复杂缺失处理

**实现**：
```python
def _get_valid_assets(returns, t, window, min_assets=10):
    """返回 t 时有足够历史的资产子集"""
    history = returns.iloc[t-window:t+1]
    valid = history.notna().sum() > window * 0.7
    if valid.sum() < min_assets:
        # 放宽到 0.5
        valid = history.notna().sum() > window * 0.5
    return valid[valid].index.tolist()
```

**应用**：
- 任何 miss-data 敏感场景都应"动态资产池"
- 比"复杂 imputation"简洁
