## 五、教训库（V0-V3 专项）

### 业绩呈现 / 可视化类（5 条）

1. **嵌入 plotly.js 比 CDN 可靠**：`4d534c2` 试 CDN 242KB → `2025c1d` 发现 `file://` 协议 CORS 拦截外部 JS，改为内嵌（4.7 MB 单文件）。v10 仍沿用此模式。
2. **统一基准 + 公平起跑 + 前复权**三件套缺一不可：5 起跑日对齐 fix + OHLCV 前复权 fix 一次性解决同图不同起点 + 拆合股跳变两个隐藏偏差。
3. **起跑日"全局对齐" vs "各策略独立削平"**：业务上更推荐后者，信息保留更完整。
4. **HTML 仪表盘要"卡片化"**：`51b5045` 在 V1V5 NAV CURVES HTML 加"8 策略卡 + 解读段 + 关键事件 + 风险提示"，把"图表"升级为"可读报告"。
5. **HTML 表格 OOS 显示 bug 防御**：`a60589c` v6 全期 0.748 误显 OOS 0.748 → 真实 OOS 0.662。根因：navs_A.loc[OOS_START:] 时 v6 还没加入 → fallback metrics(full_metrics[col]) 把全期 Calmar 填进 OOS 格。

### 公平对比 / 起跑日对齐类（4 条）

1. **统一池 vs 设计意图池**："设计意图"如果不强行扩到统一池，永远不能横向比。
2. **双口径（A 含成本 / B 无成本）**：5bp 成本对长期 Calmar 影响 < 0.04，但 v1.0 locked 影响最大 (-0.022)。双口径并存报告，防止成本被低估/高估。
3. **A 股 cap 严格性**：跨版本对比时必须显式声明 A 股 cap 口径。
4. **v4 因子在统一池中完全失效**：原 Stage 18 OOS Calmar 0.581 → 统一池下 -0.085（亏损）。

### 多策略架构类（5 条）

1. **抽象基类 + 校验函数**：让 3 个子策略在同一主回测内组合，子策略独立性 → 可独立回测。v4-v7 全部继承。
2. **子策略独立性 → 可独立回测**：反转/行业轮动先在 `test_reversion_v3.py` / `test_industry_rotation_v3.py` 单测通过，再在 `multi_strategy_v3.py` 集成。
3. **架构先进 ≠ 业绩进步**：v3 Calmar 0.504 < v2 0.892，1/N 等权稀释动量优势。
4. **粗粒度组合比细粒度多策略更稳**：后续真实有效路径是 `v3 80% + v5 20%` 这种粗组合，而非 v3_equal 1/3 细粒度。
5. **子策略 NAV 跟踪是隐性债**：v3 验证报告明确"reversion/momentum 缺失" → signal/risk_parity 权重法无法验证。此债到 v10 仍以"修复 NAV 跟踪"名义反复出现。

### 因子 / 信号类（6 条）

1. **斜率×R² 与 VT 不能同启**（`07956ca`）：slope_r2 + VT 退步 (Calmar 0.92)，因为 VT 缩放对波动剧烈的 slope_r2 高频信号冲突。
2. **斜率×R²单独使用 DD 改善但 Ann 降**：提示"涨得快+涨得稳"会错过"涨得慢但持续"的标的。
3. **IC 因子择时是低信噪比游戏**（v4 6 因子诊断）：仅 value 稳定正 IC（mean +0.044, hit 60%）；复杂 IC 择时 < 简单持有。
4. **趋势过滤 (TF) 优于 HMM**：Stage 9-B TF 简单规则 (HS300 MA200 < 暴露 0.7)，Calmar 0.88；Stage 9-D HMM 复杂 3-regime 检测，Calmar 0.52。
5. **逆波动加权胜过完整风险平价**：21 日窗口逆波动胜过 LW RP（RP-LW Calmar 0.34 vs inv_vol 0.45）。
6. **A 股低配是结构性，不是参数问题**：动量信号 2018-2024 期间海外/商品 vs 沪深300 涨幅 168.6% vs 67.9%。即使 cap 放宽到 6，也只是"少配"而非"配对"。**真正解是换信号源或扩展上下文**。
