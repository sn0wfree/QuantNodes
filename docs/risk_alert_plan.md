# QuantNodes 风险预警系统实施计划

## 一、目标

为 QuantNodes 动量 ETF 轮动策略构建完整的风险预警系统，支持：
1. 每日信号文件输出
2. 跨资产联合预警
3. HTML 交互式仪表板

## 三、信号级别定义

| 级别 | 概率范围 | 信号标签 | 建议动作 |
|------|---------|---------|---------|
| **0** | prob < 0.50 | 正常 | 正常持仓 |
| **1** | 0.50 ≤ prob < 0.65 | 关注 | 关注市场变化 |
| **2** | 0.65 ≤ prob < 0.80 | 警告 | 减仓 50% 或对冲 |
| **3** | prob ≥ 0.80 | 危险 | 清仓或全对冲 |

## 四、跨资产联合告警规则

| 规则名称 | 触发条件 | 建议动作 |
|---------|---------|---------|
| **系统性风险** | 3+ 资产 signal_level ≥ 2 | 全局减仓至 50% |
| **极端风险** | 2+ 资产 signal_level ≥ 3 | 全局减仓至 20% |
| **分化信号** | max(signal) ≥ 2 且 min(signal) ≤ 0 | 关注资产轮动机会 |

## 六、每日状态文件格式

### daily_YYYY-MM-DD.parquet

| 列名 | 类型 | 说明 |
|------|------|------|
| asset | str | 资产名称 (equity/gold/commodity) |
| probability | float64 | 风险概率 [0, 1] |
| signal_level | int64 | 信号级别 (0/1/2/3) |
| signal_label | str | 信号标签 (正常/关注/警告/危险) |
| uncertainty | float64 | Bootstrap 不确定性 |
| prev_signal | int64 | 前一日信号级别 |
| signal_changed | bool | 信号是否变化 |
| model_health | str | 模型健康状态 |
| timestamp | datetime | 计算时间 |

### 示例数据

```python
{
    "asset": ["equity", "gold", "commodity"],
    "probability": [0.72, 0.45, 0.68],
    "signal_level": [2, 0, 2],
    "signal_label": ["警告", "正常", "警告"],
    "uncertainty": [0.0139, 0.0139, 0.0112],
    "prev_signal": [1, 0, 2],
    "signal_changed": [True, False, False],
    "model_health": ["Normal", "Normal", "Normal"],
    "timestamp": ["2026-06-01 09:00:00", "2026-06-01 09:00:00", "2026-06-01 09:00:00"]
}
```

## 十一、风险评估

| 风险 | 影响 | 缓解措施 |
|------|------|---------|
| 模型输出 NaN | 低 | 使用前一日值填充 |
| 数据延迟 | 中 | 检查数据新鲜度 (>5天告警) |
| 仪表板加载慢 | 低 | 使用内联 CSS/JS |
| 联合告警误触发 | 中 | 设置合理的阈值 |
