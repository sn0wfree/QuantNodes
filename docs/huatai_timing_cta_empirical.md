## 三、对照实验（消融研究）

**目的**：验证文章核心论点 — 复合策略（状态识别 + 多类信号 + 四层退出）优于任何单类/简化变体。

| 变体 | AnnRet | Sharpe | MaxDD | **Calmar** | Trades | Signal Cov |
|------|--------|--------|-------|------------|--------|------------|
| **full** (复合) | **+0.46%** | **+0.07** | **-20.6%** | **+0.022** | 87 | 14.2% |
| trend_only (仅趋势) | -0.60% | -0.07 | -29.9% | -0.020 | 499 | **95.1%** |
| range_only (仅震荡) | -0.50% | -0.47 | -2.6% | -0.190 | 10 | 8.6% |
| no_chandelier (无吊灯) | -1.12% | -0.11 | -22.7% | -0.049 | 247 | 14.2% |
| multi_period (5/20/60 共振) | -1.06% | -0.16 | -25.4% | -0.042 | 81 | 9.9% |
| weighted_period (5/20/60 加权 0.5/0.3/0.2) | -1.06% | -0.16 | -25.4% | -0.042 | 81 | 9.9% |
| vol_regime (vol>75分位才启用共振) | -0.29% | -0.10 | -4.3% | -0.067 | 19 | 6.7% |
| cross_dim (EMA+动量+波动率压缩 三维投票) | -0.42% | -0.12 | -8.9% | -0.047 | 47 | 8.2% |

### 核心结论（与文章论点一致）

1. **复合策略（full）是唯一 Calmar > 0 的变体**，验证"状态识别 + 多类组合"的必要性。
2. **trend_only 信号覆盖率 95.1%** 但 Calmar=-0.020 → 高换手在震荡市频繁止损，证明"恒为趋势"假设不成立。
3. **range_only Calmar=-0.190 最差** → RSI 反转无趋势过滤时频繁假突破。
4. **no_chandelier Calmar=-0.049** vs full +0.022 → 吊灯止损贡献约 +0.07 卡玛比（独立验证 §"实证分析" 结论）。
5. **4 种共振变体均未超越 full**：multi_period / weighted_period / vol_regime / cross_dim 的 Calmar 全部为负。**共振过滤在 2020-2024 区间对本策略无增益**。

## 四、参数敏感性（5 预设 × 全回测）

| 预设 | 改动 | AnnRet | Sharpe | Calmar | Signal Cov |
|------|------|--------|--------|--------|------------|
| **default** | (基线) | +0.46% | +0.07 | **+0.022** | 14.2% |
| responsive | confirm 10→5 | -3.06% | -0.35 | -0.085 | 17.8% |
| levered | target_vol 0.15→0.20 | +0.52% | +0.05 | +0.018 | 14.2% |
| patient | hold_days 60→120 | +0.46% | +0.07 | +0.022 | 14.2% |
| aggressive | 三者综合 | -4.35% | -0.34 | -0.094 | 17.8% |

### 结论

1. **default = patient**：60 天 max_holding 在当前信号频率下从不生效，patient 与默认完全相同。
2. **levered 边际改善**：杠杆 0.45x → 0.60x，Calmar 略降至 0.018（成本上升略大于收益）。
3. **responsive / aggressive 显著恶化**：状态确认窗口缩短导致频繁切换，全样本回撤放大。
4. **本区间 5 个预设无一显著改善 default**，说明文章原文参数已接近局部最优。

## 五、根因分析（业绩低迷）

按重要性排序：

### 根因 1：信号覆盖率仅 14.2%（主因）

86% 时间资金闲置 → 即使信号期年化 10%，组合年化仅 ≈ 14.2% × 10% = 1.4%。

**结构性原因**：

| 品种 | range 占比 | trend 占比 | unknown 占比 |
|------|-----------|-----------|--------------|
| IF | 64% | 15% | 21% |
| AU | 62% | 18% | 21% |
| T | 73% | 7% | 21% |

T 国债趋势期仅 7%（2020-2024 国债长期震荡上行），IF/AU 也以 range 为主。

### 根因 2：交易成本 2‰ 单边侵蚀

87 笔交易，假设平均持仓 1M 元：
- 单笔成本 ≈ 2000 元 × 2 = 4000 元（双边）
- 总成本 ≈ 87 × 4% × avg_notional ≈ 显著
- 年化成本 ≈ 0.3-0.5%（占年化 0.5% 中 60-100%）

### 根因 3：杠杆利用率仅 0.45x

- target_vol=0.15，实际波动 6.7%
- 等效杠杆 0.45，未拉满 → 单边收益被压缩

### 根因 4：状态识别滞后 70 天

AR(1) 60 日窗口 + 10 日确认 = 信号最早出现在第 70 日。
**错过 2020-Q1 的 IF 反弹、2020-Q3 的 AU 突破**等关键窗口。

### 根因 5：T 国债样本适配性差

T 的 1.5x ATR 吊灯在长期趋势行情中过早震出（2022 年债市牛市的回吐周期内反复止损）。

### 根因 6：多周期共振未改善（更新于 2026-09-07 后续实验）

新增 `multi_period` 变体（5/20/60 日 EMA 多数决作为趋势状态二次确认）后：

| 维度 | full | multi_period |
|------|------|--------------|
| 信号覆盖率 | 14.2% | **9.9%** (-30%) |
| Calmar | +0.022 | **-0.042** |
| Sharpe | +0.07 | -0.16 |

**意外发现**：多周期共振**反而恶化**业绩。分析可能原因：

1. **趋势信号本就稀缺**（仅 14.2% 时间），再叠加共振过滤（多数决）使信号更稀疏 → 信号覆盖率下降 30%
2. **5/20/60 三周期方向不一致时 = 趋势反转早期** → 反而过滤掉了真正应该入场的早期信号
3. **共振确认在快速反转行情中延迟反应** → 错过最佳入场点
4. **数据区间 2020-2024 震荡偏多**，趋势本身的稀疏性被共振过滤放大

### 根因 7：3 种共振变体均未改善业绩（更新于 2026-09-07）

针对根因 6 提出的三种改进方向均已落地验证：

| 改进方向 | 变体 | 期望效果 | 实测 Calmar | 结论 |
|----------|------|----------|-------------|------|
| **加权多数决** | weighted_period (0.5/0.3/0.2) | 近期权重高 → 更灵敏 | -0.042 | ❌ 与 multi_period 一致 |
| **场景化启用** | vol_regime (vol > 75 分位) | 高波动期才启用 | -0.067 | ❌ 信号过稀 (19笔/5年) |
| **跨维度共振** | cross_dim (EMA+动量+vol压缩) | 三维投票更稳健 | -0.047 | ❌ 仍劣于 full |

**实测反直觉的发现**：

1. **加权多数决与等权多数决完全一致**：
   - 加权 (0.5, 0.3, 0.2) 总和 = 1.0，阈值 = 0.5 × 1.0 = 0.5
   - 单个 5d 投票 (权重 0.5) 即满足阈值 → 与 2-of-3 多数决结果一致
   - **当前加权公式并不"近期更敏感"**，需重新设计 (例如: 阈值改为 0.7×total 或采用投票而不是阈值)

2. **场景化启用 (vol_regime) 信号过于稀疏**：
   - 仅在波动率历史 75 分位以上时启用 → 19 笔交易 / 5 年 = 年均 4 笔
   - 9.9% → 6.7% 信号覆盖率进一步降低
   - 仍是"信号稀缺"问题，未根本解决

3. **跨维度共振 (cross_dim) 略优于 multi_period 但仍负**：
   - 三维投票比单维度多周期更稳健 (Calmar -0.047 vs -0.042)
   - 但绝对业绩仍为负
   - 信号覆盖率 8.2% 比 9.9% 更低 (三维投票更难达成多数)

### 根因 6/7 综合启示

**共振过滤对本策略在此区间无增益**的根本原因：

1. **策略本身已含多层过滤**：state 分类 + 自适应 EMA + RSI 反转 + 四层退出。额外叠加共振过滤 = 过滤过度
2. **信号本身已稀缺**（14.2%），任何额外过滤都放大稀缺性
3. **共振对错误信号和正确信号一视同仁地过滤**，但在低信噪比场景下正确信号也被过滤 = 净损害 > 净收益

**这意味着本策略在当前形态下不宜使用共振作为过滤层**。文章 §"复合信号层" 的共振思想**适用于更激进的入场策略**（如 trend_only 信号覆盖率 95.1%），通过共振过滤减少噪音。

### 可能的改进方向（暂未验证）

| 方向 | 思路 | 预期 |
|------|------|------|
| 共振作为"加码确认" | 开仓先入场，浮盈后用共振确认加码 | 不减少信号，但提高加码质量 |
| 共振仅在 RANGE 启用 | 高波动+震荡市特殊处理 | 隔离共振影响 |
| 加权公式重设计 | 近期权重要显著高（如 0.8/0.15/0.05） | 真"近期更敏感" |

## 七-B、退出机制重构实验 (2026-09-08)

### 背景

诊断发现 v1 基线的三个退出缺陷: (1) range 交易被错误套用趋势吊灯止损 (98% 交易持仓仅 1 天);
(2) ATR 未做 TR 5%-95% 分位截断 (原文要求); (3) DrawdownCircuitBreaker 未连接引擎 (已修复)。

### 已落地的改动 (全部保留, 可配置开关)

| 改动 | 文件 | 说明 |
|------|------|------|
| RSI 回落退出 (原文) | `exits/range_exit.py` 新增 | 空单 RSI<60 平空 / 多单 RSI>40 平多 |
| TR 5%-95% 分位截断 (原文) | `exits/chandelier.py` | `tr_clip=True` 默认开启 |
| 熔断连接引擎 | `cta_engine.py` | `CtaStrategy.post_step(nav)` 钩子, 熔断真实生效 |
| 持仓优先模式 | `huatai_timing_cta.py` | `hold_priority=True` 开关 (默认 False) |
| 再入场冷却期 | `huatai_timing_cta.py` | `cooldown_days=5`, 防止损-开仓循环 |
| 开仓状态追踪 | `huatai_timing_cta.py` | `_entry_state`, 按开仓状态分流退出机制 |

### 实验结论 (7 版迭代, 20 品种 2020-2024)

| 版本 | 模式 | 平均 Calmar | 正 Calmar |
|------|------|------------|-----------|
| v1 | 信号驱动 + 统一吊灯 | +0.036 | 10/20 |
| v3~v5 | 持仓优先 (原文模式) | -0.016~-0.023 | 8-9/20 |
| **v8 (当前默认)** | 信号驱动 + RSI回落 + TR截断 + 冷却期 + **熔断生效** | **+0.076** | **15/20** |

**关键发现**:
1. **持仓优先模式 (原文) 未整体超越信号驱动** — v1 的"信号消失即平仓"是自适应持有期
   机制, entry 信号持续性天然编码持有节奏; 持仓优先使交易数暴增 4 倍 → 成本暴增
   (止损-开仓循环, 即原文 §"趋势的可交易性"描述的痛点)。已做成开关默认关闭。
2. **熔断生效是最大单一贡献** — MaxDD 被 -15% 阈值截断后 Calmar 普遍改善。
3. **正 Calmar 15/20**: IC/T/TF/TS/AG/CU/ZN/NI/RB/I/MA/TA/M/Y/P。

### 已知遗留 (新)

1. **AU MaxDD -78.7%** (熔断反复触发/解除 → 重开循环, recovery_ratio=0.5 过宽松);
   熔断解除条件需收紧 (原文语义: 触发后进入观察期, 而非反复进出)
2. 12/20 品种触发熔断 → 阈值 -15% 可能过松, 待 walk-forward 重标定
3. 熔断生效改变了业绩结构 → 信号级盈亏归因需全部重跑 (牛熊过滤/黑名单决策顺延)

### 3. 结构性解释

- 2020-2026 为商品超级牛市周期 (疫情放水 + 通胀 + 地缘), 做空存在结构性逆风
  (通胀漂移 + 期货展期收益偏置)
- trend_down 判定 (μ 显著为负) 在长牛品种上捕捉到的多是"超跌反弹起点"
  而非可持续熊市
- **样本期偏差**: 做空腿的有效性需要一个真正熊市验证; 当前样本整体无利可图,
  但 ZN/RB 2022H2、NI 2023 等真实熊市段证明做空并非完全无效 — 关键是
  **识别"商品结构性熊市窗口"再放行做空**

### 11A. 低波品种 vol cap (国债成本侵蚀修复)

**问题**: T/TF/TS 年化波动 3.01%, target_vol=15% → 杠杆 3.0x (打满) →
每轮调仓名义 ≈ 6×权益, 双边成本 4‰ × 杠杆 ≈ 年化 **-10%**,
远超放大后信号 alpha (+6%) → 净亏。根因不是信号失效, 而是**成本被杠杆放大**。

**方案: 按品种有效杠杆上限 (vol cap)**

```python
# HuataiTimingConfig 新增:
product_max_leverage: dict[str, float] = {
    "IC": 1.5,   # 高波动 → cap 1.5x (从 0.62x cap)
    "IH": 1.5,
    "T":  1.5,   # 低波动 → cap 1.5x (从 3.0x 降)
    "TF": 1.5,
    "TS": 1.5,
    # 其他品种: 默认 max_leverage (3.0) 不受限
}
```

**_positions() 修改**:
```python
for product in weights.columns:
    max_lev = cfg.product_max_leverage.get(product, cfg.max_leverage)
    # 当前杠杆 = |position| × price × multiplier / equity
    # 限制: 目标杠杆 ≤ max_lev
    with np.errstate(divide="ignore", invalid="ignore"):
        raw_lev = weights[product] * capital / notional
        cap_lev = raw_lev.clip(upper=max_lev, lower=-max_lev)
        target = cap_lev * notional / capital
    lots[product] = target.replace([np.inf, -np.inf], np.nan).fillna(0).round()
```

**预期效果**:
- T: 杠杆从 3.0x → 1.5x → 成本减半 (年化 -10% → -5%), alpha +3% → 净 -2% (改善)
- T 类三品种 (T/TF/TS): 组合里占比小, 改善有限但方向正确
- 高波动品种 (AU/CU): 不受影响 (杠杆已 < 1.5x)

**变体**: 仅 T 类 cap 1.5x vs 全品种 cap 1.5x vs cap 2.0x → 需回测对比。

### 11B. CRB 指数增强 (外部宏观第四维度)

**问题**: DXY + US10Y + VIX 的 external 闸在 2022H2 (Fed 紧缩) 误判
US10Y 上行 = "商品顺风" → 禁空 → 错过 ZN/RB 熊市做空盈利。
CRB 指数是商品自身价格指数, 不受单一宏观变量偏差影响。

**方案: CRB 120日动量 < 0 → 商品承压 → 放行做空 (允许空)**

CRB 数据源选择:
- A: `quantnodes_adapter` 的 `continuous_main_cr_daily` (CRB 期货主力连续, 若有)
- B: 自制品等权指数 (20品种 close / MA250 占比就是商品广度因子的变体)
- C: AKShare/外部数据 (需调研可用性)

方案 B 最简单: 广度因子已经捕捉了商品整体方向。但用户说的是 CRB **价格指数**而非广度,
两者有区别: 广度 = 趋势方向统计量 (0/1), CRB = 连续价格 (连续动量)。
若 CRB 可用, 可以添加为 external 闸的第四个条件:
`crb_mom < 0 → 商品承压 → 允许做空`。

**实施**:
```python
# macro_gate.py 新增:
def crb_breadth_favorable(px_panel, ma=250) -> pd.Series:
    """CRB 等权价格指数 120日动量 < 0 → 商品承压 → 允许做空 (False = 不顺风)."""
    # 用 20品种 close 等权构建 CRB 代理
    equal_idx = px_panel.mean(axis=1).dropna()
    mom = equal_idx / equal_idx.shift(120) - 1
    return (mom > 0)  # True = CRB 上行 → 商品顺风 → 禁空 (与外部闸语义一致)
```

把 `crb_favorable` 加入 `external_commodity_favorable` 的 frames 列表。

**预期**: 改善 external 闸在 2022H2 的偏差 (CRB 下行 → 放行空头 → 保留 ZN/RB 熊市盈利)。
需验证: 与 DXY/US10Y 三因子的交集是否有显著变化。
