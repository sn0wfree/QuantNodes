# 42. v7.6 L1 罚项修复

> 日期: 2026-07-16
> 状态: 已完成

## 问题发现

在评估 IC 计算方式时，发现 `tvpr_estimator.py` 的 ADMM 求解器中 **L1 罚项未实现**。

### 铁证

`reports/momentum_etf_rotation/v7_6_lambda_cv.csv` 显示所有 16 组 λ_l1 值产生完全相同的 Calmar (0.5966)：

```
lambda_tv,lambda_l1,mean_calmar
0.01,0.001,0.5966
0.01,0.01,0.5966
0.01,0.05,0.5966
...
0.5,0.1,0.5966
```

### 代码分析

`tvpr_admm` 函数 (L55-186)：
- L59: 接收 `lambda_l1` 参数
- L97-98: 只初始化 `z` 和 `u`（各一个，对应 TV 罚项）
- L171: 只有 `z = soft_thresholding(diff_beta + u, lambda_tv / rho)`（TV 罚项）
- **缺少**: L1 罚项的辅助变量 `z2`, `u2` 和对应的 update 步骤

## 修复方案

### 数学推导

**原目标函数**:
```
min Σ_t Σ_i (r_{i,t} - x_{i,t}' β_t)² + λ_tv ||Δβ||₁ + λ_l1 ||β||₁
```

**ADMM 分裂**（引入两个辅助变量）:
```
min Σ_t Σ_i (r_{i,t} - x_{i,t}' β_t)² + λ_tv ||z₁||₁ + λ_l1 ||z₂||₁
s.t. Δβ = z₁, β = z₂
```

**ADMM 更新步骤**:

1. **β-update**:
```
(X'X + ρ*AᵀA + ρ*I) β = X'Y + ρ*Aᵀ(z₁ - u₁) + ρ*(z₂ - u₂)
```

2. **z₁-update (TV 罚项)**:
```
z₁ = soft_thresholding(Δβ + u₁, λ_tv / ρ)
```

3. **z₂-update (L1 罚项)**:
```
z₂ = soft_thresholding(β + u₂, λ_l1 / ρ)
```

4. **u-update**:
```
u₁ += Δβ - z₁
u₂ += β - z₂
```

5. **收敛检查**:
```
primal_res = sqrt(||Δβ - z₁||² + ||β - z₂||²)
dual_res = ρ * sqrt(||z₁ - z₁_old||² + ||z₂ - z₂_old||²)
```

### 代码修改

**文件**: `QuantNodes/strategy/momentum_etf_rotation/v7/tvpr_estimator.py`

**修改内容**:
1. 新增 L1 辅助变量 `z2`, `u2` (L99-104)
2. 修改 β-update 的 LHS 对角线: `+ ρ` (L159)
3. 修改 β-update 的 RHS: `+ ρ*(z2 - u2)` (L153)
4. 新增 z2-update 步骤 (L169-170)
5. 新增 u2-update 步骤 (L174)
6. 更新收敛检查公式 (L176-186)
