# 风控机器学习研究 — Phase 1-3

> 立项日期: 2026-08-31
> 状态: 进行中
> 检验区间: 2018-2025 (与之前研究一致, 严格IS/OOS分离)
> 子周期划分: 2018-2020 / 2021-2022 / 2023-2025

---

## 一、动机

前期研究发现:
- 现有risk_overlay (L1-L3) 使用固定参数 (VolCap=0.15, SoftCap=-0.07, HardCap=-0.10等)
- 全因子合成 (5层11因子) IS Sharpe=4.13 → OOS=-0.32 (严重过拟合)
- 单因子检验: 仅F10_dxy_z (4/4通过), 其他L1-L5单因子增量有限

本立项目标: **用ML动态生成风控参数**, 替代/增强固定参数, 同时**强制遵守约束**(MaxDD<15%)。

---

## 二、研究目标

1. **Phase 1: 特征重要性验证** - XGBoost特征重要性 vs 人工经验 (L1-L5权重)
2. **Phase 2: 风控ML生成** - 用ML预测L1-L3参数(动态), 测试OOS表现
3. **Phase 3: 集成原型** - 若Phase2成功, 在原型脚本中测试ML参数 vs 固定参数

---

## 三、目标变量 (5个风控参数)

| 参数 | 当前值 | ML预测任务 | 约束 |
|------|--------|-----------|------|
| **L1_VolCap** | 0.15 (年化波动上限) | 回归: 动态0.10-0.25 | <0.25 |
| **L2_SoftCap** | -0.07 (软减仓阈值) | 回归: 动态-0.05至-0.12 | >-0.15 |
| **L3_HardCap** | -0.10 (硬止损阈值) | 回归: 动态-0.08至-0.15 | >-0.20 |
| **DailyCap** | -0.02 (单日DD阈值) | 回归: 动态-0.015至-0.03 | >-0.05 |
| **CooldownDays** | 5 (冷却天数) | 回归: 动态3-10 | 3-15天 |

**硬约束**: G3核心 — MaxDD实际值 <15%, 不允许违反。

## 七、Go/No-Go门槛 (5个)

| 门槛 | 标准 | 备注 |
|------|------|------|
| **G1: 重要性一致性** | XGBoost top-3重要特征包含F10 + VIX | 验证人工权重 |
| **G2: OOS优于基线** | 风控ML Sharpe ≥ 生产信号 (0.886) | 必须 |
| **G3: 约束遵守** | MaxDD实际值 < 15% | 核心硬约束 |
| **G4: 稳定性** | 5折CV Sharpe标准差 < 0.3 | 不过拟合 |
| **G5: 可集成性** | 输出为risk_overlay可直接使用的格式 | 实用性 |

**判定规则**:
- 4/5过 → 出集成建议 (进Phase 3)
- 3/5过 → 出研究价值报告
- <3/5过 → 归档负结果

---

## 八、纪律与安全

- **不触碰生产代码** (gold_ensemble / risk_overlay零改动)
- ML生成的风控参数**只在原型脚本中测试**, 不替换现有risk_overlay
- 全部7个模型/参数预注册, 报告全量呈现
- 严格5折time series split (绝不用random KFold)
- 强制约束检查 (G3) 不能跳过
- 允许负结果归档
- git first / doc first 节奏提交
