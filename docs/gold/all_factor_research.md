> 立项日期: 2026-08-31

---

## 一、动机

`gold_all_factor` 整体被证伪 (IS Sharpe=4.13 → OOS Sharpe=-0.32, 衰减108%)。
但**单个指标或layer可能仍有独立价值**:
- CB购金、ETF持仓变化是黄金特有指标
- L1利率层 (TIPS/US10Y) 与生产信号依赖重复, 增量有限
- L3实体需求层是全因子中最独特的部分

本立项目标: 找出有独立预测力的单因子, 验证能否作为辅助风险指标集成到生产信号。

## 三、Go/No-Go门槛 (全部预注册)

| 门槛 | 标准 | 备注 |
|------|------|------|
| **G1 独立预测力** | 偏IC(20日波动, 控制VIX+GVZ) ≥ **+0.08** | 与金油比研究口径一致 |
| **G2 子周期稳健** | ≥2/3子周期偏IC > 0 | 2018-20/21-22/23-25 |
| **G3 时效性** | IC(5日波动) ≥ 0.05 | 近端预警能力 |
| **G4 与VIX低相关** | 与VIX相关系数 < 0.5 | 避免冗余 |

**判定规则**:
- 4门槛全过 → Phase 3集成原型 + G4集成增益门槛
- 2-3个过 → 二期研究建议
- 0-1个过 → 归档负结果

### Phase 1 结论: F10_dxy_z 是唯一4/4通过的因子
- 偏IC_20d_vol = +0.2002 (远超门槛0.08)
- IC_5d_vol = +0.0955 (近端预警能力)
- 3/3子周期全部正向 (+0.21, +0.28, +0.04)
- 与VIX负相关(-0.25), 提供VIX/GVZ未覆盖的信息

|------|------|---------|-----------|

| P3_F2 | F2_us10y_z | -0.0143 | -0.2146 ❌ |

- 结论: F10单独使用已是最优, 组合不增加价值

## 七、最终综合判定

### 7.1 主要发现

| 发现 | 结论 |
|------|------|
| F10_dxy_z 是唯一独立有效因子 | ✅ 4/4门槛全过, 偏IC=+0.20, 3/3子周期稳健 |
| F5_epu_pct 有部分价值 | ⚠️ 3/4过, 但偏IC=+0.06仅勉强 (G1未过) |
| L3实体需求 (CB/ETF/CFTC/COMEX) | ❌ 全军覆没, 1/4过, 偏IC均为负或零 |
| L1利率层 (tips/us10y) | ❌ 偏IC接近零, 在2018-2025区间无独立价值 |
| L2风险层 (vix/gprd/epu) | ⚠️ 与VIX高度冗余或弱信号, VIX本身已足够 |
| 组合是否提升F10 | ❌ 提升<1pp, 不议集成 |

### 7.2 F10_dxy_z (美元) 的核心价值

- **独立预测力强**: 偏IC=+0.20, 在控制VIX+GVZ后仍有+0.20 (不冗余)
- **跨周期稳健**: 2018-2020/2021-2022/2023-2025三段全部正向
- **经济意义清晰**: 美元弱 → 黄金强 (经典负相关), 但作为**未来波动**的预测因子是新增价值
- **与现有因子互补**: VIX捕捉股权波动, GVZ捕捉黄金自身波动, DXY捕捉汇率传导

### 7.3 L3实体需求为何全军覆没

| 因子 | 问题 |
|------|------|
| F6 comex_inv | 数据2020才有, 样本太短 |
| F7 cftc | 13周变化率, 与VIX高度冗余 |
| F8 etf_chg | 4周变化率太短, 信号噪声 |
| F9 cb_chg | 月频26周变化率, 频率不匹配 |

**核心原因**: 这些"黄金特有"指标要么数据短, 要么变化率窗口不匹配日频/周频预测, 在标准zscore化后失去信息。

### 7.4 对生产的启示

| 启示 | 说明 |
|------|------|
| ✅ F10_dxy_z 可作辅助风险指标 | 集成到risk_overlay L1, 边际贡献待集成测试 |
| ⚠️ L3实体需求暂无价值 | 不必强行集成, 现有VIX/GVZ足够 |
| ✅ 全因子整体被证伪 ≠ 所有因子无价值 | 需逐层拆解验证 |
| ✅ F10是唯一值得关注的单因子 | 但组合不增加, 说明F10已是最强信号 |

### 7.5 研究价值

- ✅ 提供USD口径下DXY对黄金未来波动**独立预测力**的实证
- ✅ 证伪全因子的5层11因子中,**大部分无独立增量**
- ✅ 唯一有价值的是F10 (DXY z-score)
- ✅ 不触碰生产代码, 与生产信号完全隔离
- ✅ 全部因子/组合预注册, 无p-hacking
