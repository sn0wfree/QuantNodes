## 一、设计原则

**核心原则**: ML独立输出信息, 与现有风控完全剥离开, 减仓决策由人/规则做.

```
ML异常检测 (独立)
    ↓
R分数 + 未来场景概率 + 验证区间
    ↓ (断点: ML终止于信息)
人工决策 (独立)
    ↓
减仓决策 (与ML无关)
```

## 二、ML输出格式

### 2.1 风险评分

- **R**: 连续分数 [0, 100]
- 越大 = 越异常 = 未来5d风险越高
- 5模型融合: M1_IF(0.5) + M4_Maha(0.5)

### 2.2 异常类型 (来自v1/v2的4类异常)

- E1: 跨资产相关性突变
- E2: 波动集聚
- E3: VIX跳升
- E4: 趋势断裂

### 2.3 持续天数

- 当前异常已持续多少天

### 2.4 类似历史时刻

- 基于R分数匹配历史上的相似regime
- 提供参考 (不做预测)

## 三、未来场景分析

### 3.1 场景定义

不做预设场景, 给出**连续概率分布**:

```
P(未来5d最大回撤 < x) = 1 - 历史上同类regime的回撤分布
```

基于当前R分数, 找历史R相似时段, 统计5d最大回撤分布.

### 3.2 概率计算方法

1. **相似regime匹配**: 找历史上R分数与当前±5范围内的时段
2. **5d回撤分布**: 统计这些时段的5d最大回撤
3. **概率估计**: P(回撤<x) = (这些时段中5d回撤<x的占比)

### 3.3 报告格式

```
P(回撤<-1%)  = 25%  [95% CI: 18%, 32%]
P(回撤<-3%)  = 12%  [95% CI: 8%, 17%]
P(回撤<-5%)  = 6%   [95% CI: 3%, 10%]
P(回撤<-8%)  = 2%   [95% CI: 1%, 4%]
P(回撤<-10%) = 1%   [95% CI: 0%, 3%]
期望最大回撤: -2.3%
VaR(95%):     -4.8%
```

## 四、概率验证

### 4.1 Bootstrap置信区间

- 每个概率点做B=1000次bootstrap重采样
- 计算95%置信区间
- **目的**: 证明概率不是点估计, 有统计可靠性

### 4.2 Brier Score

- 概率预测的均方误差
- **目的**: 量化预测质量 (<0.1优秀, 0.1-0.2中等, >0.2差)
- **公式**: BS = (1/N)Σ(实际结果 - 预测概率)²

### 4.3 可靠性图

- 横轴: 预测概率分桶 (10%, 20%, ..., 90%)
- 纵轴: 每个桶内实际发生的频率
- **目的**: 直观显示校准程度 (完美校准=45°对角线)

### 4.4 时间稳定性

- 滚动1y窗口计算Brier Score
- **目的**: 验证模型在不同regime下预测是否稳定

## 五、ML模型 (复用v2)

| 模型 | 训练方式 | 在v3中的角色 |
|------|---------|-------------|
| M1 IF | 无监督 | 主力模型(权重0.5) |
| M4 Maha | 无监督 | 辅助模型(权重0.5) |
| M2/M3/M5 | 无监督 | 备选 |

融合: `R = 0.5×M1_score + 0.5×M4_score`

## 六、评估门槛 (升级版)

| 门槛 | 标准 | 备注 |
|------|------|------|
| G1 异常覆盖率 | holdout > 85% | 校准后已验证 |
| G2 误报率 | < 5% | 软触发降低 |
| G3 报告有用性 | Brier < 0.1 + 可靠性图校准良好 | 概率质量 |
| G4 实时性 | < 1秒 | 不变 |

## 七、纪律

- ML不与现有风控通信
- ML只输出信息, 不做决策
- 报告供人参考, 不自动交易
- 允许负结果归档
- git first / doc first
