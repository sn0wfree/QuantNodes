# 黄金双独立期权策略设计文档 (v2 - 互斥触发)

## 一、设计哲学

**核心洞察**: 减MaxDD和增收益是**两个独立目标**,应该用**两个独立策略**实现。

```
┌────────────────────────────────────────────────────────┐
│  减MaxDD策略 (Buy Put)                                  │
│  触发: VIX > 25 (极端下行风险)                          │
│  目的: 保护本金,限制最大亏损                            │
│  代价: -1~2%/年 (仅触发时)                              │
└────────────────────────────────────────────────────────┘
                         +
┌────────────────────────────────────────────────────────┐
│  增收益策略 (Sell Call)                                 │
│  触发: VIX < 15 (极端低上行风险)                         │
│  目的: 锁定部分上行,获取权利金                          │
│  收益: +1~2%/年 (仅触发时)                              │
└────────────────────────────────────────────────────────┘
                         ||
                         \/
              互斥触发 (不会同时运行)
```

## 二、用户选择汇总

| 选择 | 用户决定 | 说明 |
|---|---|---|
| 1. 设计哲学 | **C: 两个独立策略,各自针对不同VIX环境** | 互斥触发 |
| 2. Buy Put触发阈值 | **C: 宽松 (VIX>25)** | 更早保护,覆盖更多危机期 |
| 3. Sell Call触发阈值 | **A: 严格 (VIX<15)** | 只在最稳定时增强,触发少但权利金高 |
| 4. 回测重点 | **D: 全部测试对比** | 找到最优组合 |

## 三、策略详细设计

### 3.1 Buy Put独立策略 (减MaxDD)

**触发条件**: VIX > 25
- 用户选择"宽松"阈值
- 覆盖2018-2025所有主要大跌期
- 包括2020年3月COVID崩盘、2022年熊市

**期权参数**:
| 参数 | 默认值 | 测试范围 | 说明 |
|---|---|---|---|
| 行权价 (OTM) | 3% | 3%, 5%, 7% | 越深OTM=越便宜,保护越弱 |
| 到期 | 1个月 | 1, 2, 3个月 | 短到期=更灵活,长到期=更便宜 |
| 换月 | 提前1-2周 | 固定 | 行业标准 |
| 流动性 | >50手 | 固定 | 确保可执行 |

**状态机**:
```
[空仓] --VIX>25--> [买入Put] --持有--> [每日盯市]
[持有Put] --VIX<22--> [平仓Put] --> [空仓]
[持有Put] --到期--> [结算] --> [空仓]
```

**预期效果**:
- MaxDD: -19% → -12~-15% (Put保护)
- 年化: -1~2% (Put成本)
- 触发频率: VIX>25天数占比 (约5-10%)

### 3.2 Sell Call独立策略 (增收益)

**触发条件**: VIX < 15
- 用户选择"严格"阈值
- 只在市场最稳定时增强收益
- 平时持续,触发后获取权利金

**期权参数**:
| 参数 | 默认值 | 测试范围 | 说明 |
|---|---|---|---|
| 行权价 (OTM) | 3% | 3%, 5% | 越深OTM=权利金越低,触发风险越小 |
| 到期 | 1个月 | 1, 2, 3个月 | 标准 |
| 换月 | 提前1-2周 | 固定 | 行业标准 |
| 流动性 | >50手 | 固定 | 确保可执行 |

**状态机**:
```
[空仓] --VIX<15--> [卖出Call] --持有--> [每日盯市]
[卖出Call] --VIX>18--> [平仓Call] --> [空仓]
[卖出Call] --到期--> [结算] --> [空仓]
```

**预期效果**:
- 年化: +1~2% (Call权利金)
- MaxDD: 不变 (Call下跌归零)
- 触发频率: VIX<15天数占比 (约10-15%)

### 3.3 双独立策略组合 (互斥触发)

**核心逻辑**:
```python
if vix > 25 and not have_put:
    # 极端下行风险 → 启动Buy Put保护
    buy_otm_put(otm=0.03)
elif vix > 25 and have_put:
    # 继续持有
    pass
elif vix < 22 and have_put:
    # VIX回落,平仓Put
    close_put()

if vix < 15 and not have_call:
    # 极端低上行风险 → 启动Sell Call增收益
    sell_otm_call(otm=0.03)
elif vix < 15 and have_call:
    # 继续持有
    pass
elif vix > 18 and have_call:
    # VIX上升,平仓Call
    close_call()
```

**互斥约束**:
- Buy Put和Sell Call**永远不会同时持仓**
- VIX在15-25之间: 仅基础策略,无期权
- VIX>25: Buy Put (保护)
- VIX<15: Sell Call (增收益)
- 转换平滑:VIX穿越阈值时先平仓再开仓

**预期效果**:
- 综合年化: 基础18% + Call增强1% = ~19%
- 综合MaxDD: 基础-19% + Put保护 = -13~-16%
- 综合Calmar: 显著提升 (1.0+)
