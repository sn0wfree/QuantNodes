## 一、动机

前期风控ML研究 (commit 141f8c0d, 56587066) 失败:
- 目标变量 `L1_VolCap = future_vol * 2` 让ML学"vol大→cap高"反模式
- ML参数 Sharpe 0.804 (退化7.7%), MaxDD -15.55% (违反G3硬约束)
- 5维度深度诊断确认: **目标变量方向反了**, 不是ML能力问题

**本立项** (方案B): 放弃"参数预测"路径, 改为**市场结构异常检测**作为风控的补充层。

---

## 二、核心定位

```
原失败方向: 信号层 → 风控层(rule) → [ML预测参数] → 仓位
                          ↑ 反方向

新方向:     信号层 → 风控层(rule) → [ML异常检测] → 仓位
                          ↑ 补充层       ↑ 同向: 异常→减仓
```

**异常检测是补充层, 不替代现有风控规则**:
- 正常时段: ML不触发, 现有风控照常运行
- 异常时段: ML触发"额外减仓×0.5"

---

## 三、目标变量构造 (4类异常)

| 异常类型 | 检测对象 | 标签定义 |
|---------|---------|---------|
| **A1: 跨资产相关性突变** | gold-oil, gold-DXY, gold-VIX滚动相关性 | 未来5d内滚动corr变化 > 历史2σ |
| **A2: 波动集聚** | 已实现波动率突破历史分位 | 未来5d内vol > 历史95%分位 |
| **A3: VIX跳升** | 股市恐慌信号 | 未来5d内VIX > 5d前 × 1.3 |
| **A4: 趋势断裂** | 黄金价格趋势突然反转 | 未来5d内最大单日跌幅 < -2% |

**目标变量 (任一触发)** = max(A1, A2, A3, A4) → 二分类 0/1

**关键优势**:
- 方向正确: 异常→减仓, 与业务目标一致
- 二分类问题, ML擅长处理类别不平衡
- 不需要反方向构造target

## 七、集成方案 (补充层)

```python
# 原: 现有风控规则
position = compute_risk_overlay(...)

# 新: ML异常检测补充层
anomaly_score = compute_anomaly_score(features)
if anomaly_score > 0.95:  # 异常分数>95%分位
    position = position * 0.5  # 额外减仓50%
```

**触发**: 异常分数 > 历史95%分位
**动作**: 仓位×0.5（保守, 避免误报代价）

### Phase 2: 6模型对比

| 模型 | 计算时间 | 危机日分位 | G1(>90%) | G2误报率(<5%) |

| 门槛 | 结果 |
|------|------|
| G1 (已知危机检测) | ❌ |
| G2 (误报率<5%) | ✅ |

**通过 3/4门槛** (G2/G3-M3/G4, G1未达) — 出**研究价值报告**。

### 核心发现

1. **G1失败是标签问题, 非ML问题**:
 - 当前标签用5d窗口, crisis当天已在窗口内
 - ML的rolling baseline在crisis后几天才显著偏离
 - 修复: 改用"crisis前3d"的预测窗口, 或精确到crisis当天

2. **G3 (集成增益) 显著**:
 - M3_LOF补充层在生产参数基础上Sharpe提升4.1%
 - 但其他4个模型都退化, 说明不是ML普遍有效
 - LOF (局部异常因子) 特别适合"局部regime转换"检测

3. **异常检测方向正确**:
 - 之前参数预测ML: 6个模型全失败
 - 现在异常检测: 1个模型通过G3, 5个模型通过G2
 - 证明**二分类+补充层**比**回归+替代**更适合ML

### 修复建议 (若G1要解决)

| 方案 | 预期效果 | 实施成本 |
|------|---------|---------|
| 改用"crisis前3d"标签 | G1分位可能升至>90% | 低 (改build_anomaly_labels) |
| 加更多已知危机日 (覆盖2024) | 改善ground truth | 低 |
| 用HMM (隐马可夫) 检测regime突变 | 更准的异常定义 | 中 (需新模型) |

### 对生产的明确建议

- ⚠️ **暂不建议直接集成** (G1未达, M3_LOF仅一例)
- ✅ **方向已验证**: 异常检测比参数预测更可行
- 🔧 **下一步**: 修复标签窗口, 重做G1验证, 若G1通过则出M3_LOF集成原型
