# 黄金量化策略业界调研

## 一、业界经典框架参考

### 1.1 三大驱动因子框架 (来自 gold_rir_tips.ipynb)

业界常用的黄金定价因子分为三类：

#### 1. 避险因子 (Safe Haven Factor)

**波动率风险成分**:
- 权益波动率: SP500 VIX
- 债券市场波动: 美债10年期收益率60日波动率
- 外汇波动: 美元指数的60日波动率

**相关性风险成分**:
- 黄金~美债相关性
- 黄金~SP500相关性
- SP500~美债相关性

**避险需求成分**:
- 黄金ETF持仓变化: 全球黄金ETF月度流量/GDP占比
- 隐含避险溢价: 黄金远期曲线斜率

#### 2. 抗通胀因子 (Inflation Hedge Factor)

**实际利率成分**:
- 美国10年期TIPS收益率
- 实际利率预期（美联储点阵图）
- 名义利率与通胀的缺口（10年国债 - 核心PCE）
- 全球实际利率（G10国家中位数）

**通胀预期成分**:
- 盈亏平衡通胀率（10年美债 - TIPS）
- 通胀互换率（5年期）
- 通胀预期离散度
- 消费者通胀预期（密歇根大学）

#### 3. 货币信任因子 (Currency Trust Factor)

**核心指标**:
- 全球央行净购金量（年化）
- G20国家5年期CDS利差中位数
- 发达国家政府债务/GDP比率
- 经济政策不确定性指数(EPU)

## 二、关键业界经验

### 2.1 实际利率 (TIPS) 是黄金最重要的驱动因子

**业界共识**:
- 实际利率上升 → 黄金下跌（持有黄金的机会成本增加）
- 实际利率下降 → 黄金上涨（避险+抗通胀需求）
- TIPS收益率是最佳代理变量

**我们的验证**:
- 实际利率策略IC = 0.0276（正相关，符合预期）
- 但实际利率策略单独表现一般（年化11.96%）

### 2.2 VIX是黄金的领先指标

**业界共识**:
- VIX飙升 → 黄金短期下跌（恐慌抛售）
- VIX回落 → 黄金反弹（避险回归）
- VIX高位 → 黄金波动率增加

**我们的验证**:
- VIX动量IC = 0.0293（良好）
- VIX动量策略在所有VIX区间都是最优信号
- VIX动量策略年化14.48%, MaxDD -20.18%

### 2.3 央行购金是长期支撑

**业界共识**:
- 央行持续购金 → 长期支撑金价
- 2022-2024年央行购金量创历史新高
- 中国、印度、土耳其等是主要买家

**我们的验证**:
- 仓位流（央行+ETF）IC = 0.0378（最高）
- 仓位流策略IC = 0.0428（Rank IC）
- 这是最有效的预测因子

### 2.4 突破和趋势跟踪的局限性

**业界反思**:
- 黄金2018-2025是单边大牛市
- 趋势跟踪在牛市中已"price in"
- 突破信号IC为负(-0.0159)，不适合作为单一信号

**我们的发现**:
- 趋势B&H IC = -0.0288（负！）
- 突破IC = -0.0159（负）
- 突破和趋势B&H都不适合作为单一信号

## 三、业界风险控制方法

### 3.1 多层级风控（参考）

**层级1: 信号层**
- 因子IC为负的信号应降低权重或排除
- 突破IC=-0.0159，趋势B&H IC=-0.0288 → 应排除

**层级2: 市场状态层**
- 牛市/正常/压力/危机 → 不同仓位
- VIX>80% + 加速 → 危机状态

**层级3: 仓位限制层**
- 最大单日仓位变化: 20%
- 最大回撤限制: -15%
- 最大持仓比例: 100%

**层级4: 流动性层**
- 成交低迷时降低仓位
- 重大事件前减仓

### 3.2 业界常用止损方法

| 方法 | 描述 | 优点 | 缺点 |
|---|---|---|---|
| 固定止损 | -8%硬止损 | 简单 | 不灵活 |
| 追踪止损 | 从峰值回撤8% | 保护利润 | 可能过早止损 |
| ATR止损 | 2倍ATR | 自适应 | 慢 |
| 波动率止损 | 波动率倍数 | 动态 | 复杂 |

我们的选择: 8%追踪止损（已验证最优）

## 四、关键差异：学术 vs 实战

### 4.1 学术研究的局限

**学术常用方法**:
- VECM协整
- 因子模型
- 均值回归

**问题**:
- 数据频率低（月度）
- 假设过强（正态分布）
- 忽略交易成本
- 忽略流动性
- 忽略政策变化

### 4.2 实战的关键差异

| 维度 | 学术 | 实战 |
|---|---|---|
| 数据频率 | 月度/季度 | 日度/分钟 |
| 交易成本 | 忽略 | 必须考虑（5bps） |
| 流动性 | 假设无限 | 必须考虑 |
| 杠杆 | 通常无 | 可用1-2倍 |
| 政策变化 | 静态 | 动态适应 |
| 极端事件 | 厚尾 | 真实发生 |

## 五、对我们策略的启示

### 5.1 验证业界共识

| 业界共识 | 我们的验证 | 一致性 |
|---|---|---|
| TIPS是黄金主要驱动 | TIPS IC=0.0276 | ✅ |
| VIX是领先指标 | VIX动量IC=0.0293 | ✅ |
| 央行购金是长期支撑 | 仓位流IC=0.0428 | ✅ |
| 突破/趋势在牛市中失效 | 突破IC=-0.0159 | ✅ |

### 5.2 业界未提及的发现

**我们发现**:
- 突破和趋势B&H在黄金大牛市中IC为负
- 这是黄金的特性（不是普适规律）
- 解释: 黄金2018-2025单边上涨,突破后往往回调

### 5.3 需要进一步调研

1. **业界对黄金做空的态度**: 多数机构不允许做空黄金
2. **黄金与其他资产的相关性**: 危机时与股票负相关,正常时弱相关
3. **黄金的季节性**: 历史上Q3表现较弱
4. **黄金与利率周期**: 实际利率是核心驱动
