## 六、结论与分析

### 6.1 这次发现的真实价值

1. **金油比值的"风险预测力"确认存在**: USD口径下R_zscore_252偏IC=+0.110, 比之前SC口径(au/sc)的IC_5d=0.047强23倍。
2. **Q5/Q1区分清晰**: 高比值时段未来波动18.49% vs 低比值13.24%, 同时收益+1.83% vs +0.02%, **不是单纯风险信号, 而是** "风险+收益同时放大"的动态指标。
3. **结构性变化** (G2负周期): 2008-2013期间金油比与未来波动反相关, 2014后转为正相关。这反映QE时代后期黄金"避险"角色消退、转为"通胀对冲"角色。

### 6.2 为什么G3失败

**R_zscore_252偏正但R_zscore_126偏负**, 这不是"计算错误"而是**真实结构**:
- 短窗口(126天)更接近"近期regime", 但2008-2013负相关拖累了均值
- 长窗口(504天)更接近"长期平衡", 2014后正相关主导
- 这意味着**金油比的"合理窗口"取决于市场结构, 没有单一最优**

### 6.3 与之前SC口径的对比

| | SC口径 (au/sc, 2018-2026) | USD口径 (gold_spot/WTI, 2008-2026) |
|---|---|---|
| 样本量 | 2042天 | 4736天 |
| IC_5d (原始) | +0.047 | +0.157 |
| 偏IC_20d_vol (R_zscore_252) | +0.160 | +0.110 |
| 结论 | 看似强但样本短 | 实质强且覆盖3周期 |

**USD口径是更可靠的估计**。之前SC口径的IC_5d=0.047在更长样本下其实是不可持续的。

### 6.4 副产物: 顺手归档的事件研究

因子在主要事件前的状态:
- **2013 Taper (实际-30%金价暴跌)**: R_zscore_252 < 0 (低) → 因子说"低风险", 但实际暴跌 — **因子对QE时代黄金独立暴跌盲区**
- **2020 COVID**: R_zscore_252 > 0 (高) → 因子说"高风险", 实际波动确实大 ✅
- **2022 加息周期**: R_zscore_252 > 0 → 因子说"高风险", 但实际波动中等 ⚠️
- **2026 崩盘**: R_zscore_252 ≈ 0 → 因子中性, 策略靠VIX风控躲过 ✅

## 十一、二期: Regime-Adaptive 测试 (2026-08-31)

### 11.1 动机

Phase 1结果显示G3失败的根本原因不是"无信号",而是 **2008-2013期间信号反方向**:
- 2008-2013: R_zscore_252 偏IC = -0.081 (负,黄金"避险"角色)
- 2014后: R_zscore_252 偏IC = +0.115~+0.42 (正,黄金"通胀对冲"角色)

这是真实的结构性变化(跨5变体一致),不是过拟合。

### 11.2 设计思路

构造regime指标,使因子在两个regime下方向一致:

```python
R_zscore = (比值 - 均值) / 标准差
R_adaptive = R_zscore * sign(regime - threshold)
```

### 11.3 候选Regime指标 (4个全部测试)

| 编号 | 指标 | 定义 | 数据源 | 经济含义 |
|------|------|------|--------|---------|
| R1 | RIR趋势 | TIPS.diff(252) > 0 | gold_fred.tips | 真实利率上行=Taper/加息期 |
| R2 | VIX百分位 | vix_pct > 0.7 | gold_fred.vix | 市场恐慌=避险模式 |
| R3 | CPI同比 | CPI_YoY > 3% | gold_fred.cpi(如有) | 高通胀环境 |
| R4 | Fed Rate方向 | fed_rate.diff(252) > 0 | gold_macro.fed_rate | 退出QE/加息周期 |

### 11.4 快速验证标准

- 三个子周期偏IC**全正** (vs 原R_zscore 2/3)
- 全样本偏IC ≥ 0.10
- **至少2/4个regime**达标 → regime-adaptive有研究价值
- 没有regime达标 → 负结果归档,与Phase 1并列
