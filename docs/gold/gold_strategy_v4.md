## 1. 策略概述

**一句话**: 黄金(沪金)日频趋势跟随策略——4路宏观/量价信号加权 → 双层风控 → 1.5倍杠杆预算内网格化执行, 目标年化~18%/最大回撤-17%以内。

**本质定位**: 金价beta + 回撤管理的配置型工具, 不是独立alpha来源 (归因显示杠杆层贡献最大)。

**核心指标** (2018-06-20 ~ 2026-08-28, 开盘到开盘+5bps成本):

| 指标 | 值 |
|---|---|
| CAGR | **+18.47%** |

## 8. 执行层设计语义

### 8.1 预算制网格 (非叠加仓位)

总杠杆硬封顶1.5; 核心信号最多用1.25; 网格库存是**从杠杆预算划出的独立仓位**, 只在价格低于锚点时累积 (低吸), 回到锚点上方归零 (高抛)。语义 = 把闲置杠杆让渡给网格交易。

### 8.2 日平滑

每日调仓限速0.20 (单日最大调仓0.88→0.57), 业绩无损 (+0.07pp)。与"每天最多一次调仓"的执行设计自洽。

## 9. 执行时点与数据时序 (实测验证)

### 9.1 Bar归属规则

SHFE黄金 T交易日 = **T-1日21:00夜盘** + T日9:00-15:00日盘。日K的open = 前一晚21:00夜盘开盘价 (波动率分解实证: 15:00→21:00 gap段方差占比31% ≈ 6h/24h时间占比)。

### 9.2 信号→执行时序

```
T日 15:00  日盘收盘 → 信号计算 (输入: AU收盘 + vix/gvz shift2, 均为≥15h前已发布数据)
T日 21:00  夜盘开盘成交 (6小时后)      ← 每天最多一次调仓
T日 21:00→次日21:00  O2O收益段
```

- 15:00→21:00的欧美盘变动**不在信号里、由成交价承担** (gap段日度std 0.588%), 无前视
- vix/gvz shift(2)双重保守 (shift(1)已够: 美盘凌晨4-5点结算, 早于15:00信号10小时+)

### 9.3 三种执行口径对照 (同一B3仓位, 2018-2026)

| 口径 | CAGR | Sharpe | MaxDD |
|---|---|---|---|
| T日收盘15:00成交 (信号即成交) | +18.15% | 1.55 | -17.11% |
| **T+1夜盘开盘21:00成交 (现状)** | **+18.47%** | **1.56** | **-16.84%** |
| 次日日盘收盘15:00成交 (拖一天, 悲观) | +17.55% | 1.46 | -15.70% |

- 收盘 vs 夜盘开盘 (6小时): 仅差0.32pp/年, 逐年正负交替无系统性 → **两口径等价**
- 夜盘开盘 vs 次日日盘收盘 (24小时): 全期差+0.92pp, **2026崩盘年单年差+8.06pp** → 崩盘年保护速度价值巨大, 实盘SOP必须当晚执行

### 9.4 最坏延迟案例 (2026-08-31, 70小时)

```
周五15:00   收盘999.28, 信号+35.43% (暴跌未发生)
周五21:00-02:30  夜盘暴跌-2.9% (分钟线实证: 993→973→970) ← 日频信号不看盘中
周末        休市
周一09:00-15:00  继续下探954 (10:45), 15:00收盘961.92 ← 信号此刻才"看见"
周一15:00后  信号计算: 链层减仓-0.20 (非应急: -3.74%未到-5%线)
周一21:00   夜盘开盘成交 = 日K"9-1"的open ← 从暴跌主段到执行≈70小时
```

回测会计: 暴跌段损失全数计入旧仓位 (pos[周五]扛过整个事件), 无前视。**70小时是日频框架的频率上限, 不是缺陷; 消除它需要盘中风控模块 (未立项, 见§10)。**

## 10. 鲁棒性与过拟合声明

| 检验 | 结果 |
|---|---|
| 网格sp敏感性 | 1.5~2.0%平台全组合赢基准; 2.5%退化 |
| 应急阈值 | -5%~-7%结果相同 (稳健平台); -3%~-4%路径敏感区避开 |
| 逐年 | 9年中7年≥旧生产, 仅2020/2021略弱, 无灾难年 |
| 执行口径 | 三口径CAGR极差0.92pp, 口径不敏感 |
| 平滑/应急 | 消融显示为正贡献 (+0.8pp合计) |

**⚠️ 过拟合声明**: B3参数为样本内优化 (9年单资产), +3.05pp增益 (vs 旧生产) 存在过拟合风险。缓解: ①纸面跟踪3个月后再实盘 ②参数取平台中心非极值 ③子信号权重未因归因结果调整 (避免事后拟合)。

**已知局限**:
1. 日频频率上限 (夜盘暴跌最坏70小时延迟, §9.4); 盘中风控未立项
2. 换月调整平滑了换月4天的真实跳空
3. 5bps未建模冲击成本 (当前单日最大调仓0.57×资金规模在SHFE黄金深度内可忽略)
4. 单资产回测, 无跨品种分散验证
