| 维度 | 结论 |

## 4. 机制结论

### 多因子 vs 生产B3 的差距（+4.18pp CAGR = +0.29 Sharpe）

```
B3(18.5%) − 多因子(14.3%) ≈ B3(18.5%) − L0裸信号(14.3%) = +4.18pp
   ≡ L0 → L6 消融贡献: 一层风控(-1.1) + 杠杆(+6.9) + 二层(-2.4) + 执行层(+0.8)
```

**多因子6因子组合 ≈ 生产4路原始加权（都是"裸信号层"）**——CAGR几乎重合（14.3% vs 14.3%）。差距100%在信号层之上。

### TV-PR失败根因

- TV-PR的结构约束（TV罚分段常数 + L1稀疏）**理论上能改善**权重机制
- 但前提是因子有真信号——7个因子在裸奔回撤-20%~-30%下，单层风险叠加后TV-PR面对的几乎全是噪声
- BIC正确地选择了最小λ（无正则化=OLS），**这是对弱信号的自适应识别，不是bug**
- 与ML异常研究L2自适应权重失败同因：**机制对了，信号层质量不行**

## 5. 优化建议（从结论反推）

若仍想尝试改进路径，应改**信号层**而非权重机制：

1. **移除usd**（已权重=0，独占1.89% CAGR/+0.16 Sharpe）
2. **减少position_flow**（月频数据滞后，多因子权重15%降为0？）
3. **纳入macro_regime**（生产standalone最优13.32%/1.17/-9.5%，多因子池里竟没有）
4. **风险叠加方式**：7因子×独立一层风控（当前实现）vs 7因子加权后**单层**风控（更激进）—— 后者可能在弱信号上效果不同
