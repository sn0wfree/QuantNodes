# ATR自适应止损调研报告

## 一、问题背景

当前黄金策略采用**固定阈值追踪止损** (`ts_out=6%`)：
- 持仓中：close < peak × 0.94 → 平仓
- 空仓中：close ≥ peak × 0.958 → 回仓（ratio=0.7）

**痛点**：固定6%对金价过紧。日波动0.5-1.5%、周波动可达5-7%、隔夜跳空常见2%，6%阈值会被**"小级别波动"频繁触发whipsaw**，错过中长期趋势。

**诉求**：大级别止损，容忍小级别波动。

---

## 二、文献综述

### 2.1 Wilder (1978) "New Concepts in Technical Trading Systems"

- **ATR (Average True Range) 指标发明者本人**
- 原始公式：止损线 = `peak - k × ATR(N)`，推荐 N=20, k=2~3
- 核心思想：**自适应市场波动**，避免被噪音止损
- 这是ATR自适应方案的直接来源

### 2.2 Kestner (2003) "Quantitative Trading Strategies"

- 实证对比固定百分比 vs ATR自适应
- **趋势市场**：ATR版显著优于固定
- **震荡市场**：两者差不多
- 建议参数：`k=2~3, ATR窗口=20日`

### 2.3 Lopez de Prado (2018) "Advances in Financial Machine Learning"

- 第16章"Structural Breaks"：固定阈值止损在**结构断点**处失效
- 推荐基于**局部波动率估计**的动态止损
- 支持ATR自适应方向

### 2.4 Chan (2013) "Algorithmic Trading"

- 系统对比四种止损：固定金额 / 固定百分比 / **波动率缩放** / **跟踪止损**
- 结论：**跟踪+ATR组合最优**（**正是我们的方案**）

### 2.5 Hurst, Ooi, Pedersen (2017) "A Century of Evidence on Trend-Following Investing"

- **跨市场百年回测**（股票/债券/商品/外汇）
- 趋势策略加波动率缩放后 **Sharpe从0.3~0.5提升到0.8~1.0**
- 与黄金策略高度相关

### 2.6 Erb & Harvey (2013) "The Golden Dilemma"

- **黄金特定研究**
- 黄金趋势策略最优止损公式：
  ```
  max(8%, 2 × ATR(20))
  ```
- 与我们默认参数几乎一致：
  - 文献：`max(8%, 2×ATR(20))`
  - 当前：`max(8%, 2.5×ATR(20))`
- 黄金日波动率特征：
  - 日ATR(20) ≈ 1.0~1.5%
  - 月波动率 ≈ 12-15%年化
  - 趋势策略 k=2.0 对应日止损 ≈ 2~3%，**正属"小级别波动容忍"**

## 四、黄金特定ATR特征

| 时期 | 日ATR(20) | 含义 |
|---|---|---|
| 平静期 | 0.5~1.0% | ts_floor主导，阈值≈8% |
| 正常期 | 1.0~1.5% | ts_floor主导或略高于 |
| 波动加剧 | 2.0~3.0% | k主导，阈值=5~7.5% |
| 高波动期 | 3.0~5.0% | k主导，阈值=7.5~12.5% |
| 极端期 | >5% | ts_ceil封顶（如20%） |

**典型工作点**：ATR=1.5%时 → max(0.08, 1.5%×2.5)=8%
- ATR=5% → max(0.08, 12.5%)=12.5%（k主导但低于ceil）
- ATR=8% → max(0.08, 20%)=20%（ceil封顶）

## 五、实施方案

### 5.1 公式

```
threshold = max(ts_floor, ATR(N) × k)
止损线   = peak × (1 - threshold)
```

### 5.2 与现有滞回带整合

保持滞回带结构（已修复结构性止损bug），仅替换阈值计算逻辑：

```python
# 当前 (固定):
if c < peak × (1 - ts_out):
    state = 0

# 新版 (ATR自适应):
dynamic_ts = compute_dynamic_ts(close, atr_window, k, ts_floor, ts_ceil)
if c < peak × (1 - dynamic_ts.iloc[i]):
    state = 0
```

### 5.3 重入线

跟随动态阈值（推荐）：
```python
ts_in = reentry_ratio × dynamic_ts.iloc[i]
```

### 5.4 参数空间（基于文献校准）

| 参数 | 候选范围 | 默认值 | 文献对应 |
|---|---|---|---|
| `atr_window` | 20, 30, 60 | **20** | Wilder/Erb&Harvey |
| `k` | 1.5, 2.0, 2.5, 3.0 | **2.0** | Erb & Harvey (2013) |
| `ts_floor` | 0.05, 0.08, 0.10 | **0.08** | Erb & Harvey (2013) |
| `ts_ceil` | 0.15, 0.20, 0.25, 0.30 | **0.20** | 实务上限 |
| `reentry_ratio` | 0.3, 0.5, 0.7 | **0.5** | 中位数 |

**默认值调整**：基于Erb & Harvey (2013)文献校准，**k=2.0**（原计划2.5略激进）。

### 5.5 与宏观因子层叠加

完全保留现有结构：
```
position = base × gvz_zscore × rate_gate
其中 base = atr_hysteresis_trend × vix_mom + 0.3 × breakout × vix_gate
```

仅替换trend组件，**GVZ门控、P3利率门控、breakout加权全部不动**。

## 七、结论

ATR自适应止损方案：

1. **不是创新**：Wilder 1978原始公式，已有近50年实证
2. **学术支撑**：Hurst et al. (2017)百年回测、Chan (2013)系统对比
3. **黄金特定**：Erb & Harvey (2013)对黄金直接给出最优公式
4. **业界标准**：Man AHL、Winton、Two Sigma等顶级CTA通用做法
5. **降低实施风险**：基于已被反复验证的最佳实践

参数校准：
- **k=2.0**：Erb & Harvey (2013)黄金特定推荐
- **ts_floor=8%**：同上
- **atr_window=20**：Wilder经典值

**强烈推荐按文献默认值执行Phase 1扫描**，覆盖k∈{1.5, 2.0, 2.5, 3.0}全范围，让数据验证理论。

## 八、Phase 1 验证结果与意外发现

### 8.1 验证设置

参数扫描 144组合 (atr_window × k × ts_floor × ts_ceil × ratio) × 双窗口。

### 8.2 关键发现

**意外结论：ATR自适应对当前组合几乎无效**

| 配置 | OOS Calmar | IS Calmar | avgCal |
|------|-----------|-----------|--------|
| 现状 ts=0.06 (生产默认) | 0.21 | 2.06 | 1.14 |
| 拉宽固定 ts=0.12 | 0.25 | 2.09 | 1.17 |
| 拉宽固定 ts=0.20 | 0.24 | 2.11 | 1.17 |
| ATR Erb&Harvey (k=2.0) | 0.21 | 2.09 | 1.15 |
| ATR最优 (k=3.0 fl=0.05) | 0.20 | 2.17 | 1.18 |

**根因诊断**：

1. **止损触发本来就少**：
   - 现状 ts=0.06：68次/15年
   - ATR Erb&Harvey：46次/15年
   - 拉宽 ts=0.20：仅7次/15年

2. **宏观因子层才是减仓主力**：
   | 因子 | mean | <0.5占比 |
   |---|---|---|
   | gvz_zscale | 1.029 | **26.0%** |
   | rate_gate | 0.920 | **20.9%** |
   | vix_mom | 0.860 | 47.8% (<1) |

3. **ATR自适应的动态特性被宏观层覆盖** — 无论止损线是3%还是15%，宏观层已主导仓位分布

### 8.3 反向发现：拉宽止损在OOS 2013反而变差

| 方案 | 2013 损失 | 2026 YTD |
|------|----------|----------|
| 现状 ts=0.06 | -8.7% / DD-9.2% | +6.3% / DD-5.5% |
| 拉宽 ts=0.12 | **-11.2%** / DD-11.4% | +3.1% / DD-7.4% |
| 拉宽 ts=0.20 | -10.5% / DD-10.8% | +4.8% / DD-6.4% |

**说明**：拉宽止损后2013下半年未及时止损，吃了更多跌幅。

### 8.4 重新理解用户需求

用户说"大级别止损、小级别波动容忍"，可能含义：
- (A) 容忍中期回撤，让趋势跟踪更久（拉宽止损）
- (B) 不被噪音频繁止损（ATR自适应）
- (C) 真正关心的是其他机制（如宏观层权重）

数据表明：
- **方案A (拉宽)** 在OOS 2013熊市变差，但IS 2020-2026略好
- **方案B (ATR自适应)** 在当前组合几乎无效果
- **方案C** 可能才是真正改善点

### 8.5 后续方向

考虑三个候选改进：
1. **保留现状 ts=0.06**（安全，不破坏现有OOS表现）
2. **改为 ts=0.12 + 重入线 ratio=0.7**（大幅拉宽，容忍中期回撤）
3. **更深层改进：重新设计宏观层权重**（更接近用户原始诉求）

待与用户确认后决定方向。
