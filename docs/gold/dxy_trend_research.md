# DXY变化趋势与黄金关系研究 — Phase 1-3

> 立项日期: 2026-08-31
> 状态: 进行中
> 检验区间: 2008-2025 (17年, 3个宏观周期)
> 子周期划分: 2008-2013 / 2014-2019 / 2020-2025

---

## 一、动机

前期Phase 1-2研究的F10 (DXY z-score, 绝对水平) 是唯一4/4门槛全过因子:
- 偏IC_20d_vol = +0.20, 3/3子周期正向, 4/4门槛过

但**DXY变化趋势（动量/变化率）是独立维度, 前期未测**。本立项研究:
1. DXY趋势是否独立有效?
2. DXY水平 vs 趋势, 哪个更强?
3. 两者能否组合(趋势+水平)提升预测力?

---

## 二、候选变体 (7个全部预注册)

| 变体 | 定义 | 含义 |
|------|------|------|
| **M1**: dxy_chg_5d | dxy.pct_change(5) | 短期变化率 (周度) |
| **M2**: dxy_chg_20d | dxy.pct_change(20) | 月度变化率 |
| **M3**: dxy_chg_60d | dxy.pct_change(60) | 季度变化率 |
| **M4**: dxy_diff_20 | dxy.diff(20) | 月度绝对变化 |
| **M5**: dxy_ma_ratio | dxy / dxy.rolling(60).mean() | 均线比 |
| **M6**: dxy_breakout | dxy > 60日最高 × 0.95 | 突破信号 |
| **M7**: dxy_trend_z | (dxy - MA60) / std60 | 趋势z-score |

**核心逻辑**: DXY走弱趋势 → 黄金走强 → 未来波动放大

## 三、研究步骤

### Phase 1: 单变体基础检验
- 每个变体的偏IC(20d_vol)、IC(5d_vol)
- 子周期稳健性 (3段)
- 与F10_dxy_z相关性 (避免冗余)
- 输出: 变体排名表

### Phase 2: 组合检验 (Phase1有≥2变体过G1)
- M_best + F10 (水平+趋势)
- M_best + F5_epu (跨层)
- 与F10基线对比

### Phase 3: 集成原型 (组合有效)
- risk_overlay L1加入dxy_chg调节因子
