# DXY变化趋势与黄金关系研究 — Phase 1-3

> 立项日期: 2026-08-31
> 状态: 进行中
> 检验区间: 2008-2025 (17年, 3个宏观周期)
> 子周期划分: 2008-2013 / 2014-2019 / 2020-2025

---

## 一、动机

前期Phase 1-2研究的F10 (DXY z-score, 绝对水平) 是唯一4/4门槛全过因子:
- 偏IC_20d_vol = +0.20, 3/3子周期正向, 4/4门槛过

但**DXY变化趋势（动量/变化率）是独立维度, 前期未测**。本立项研究:
1. DXY趋势是否独立有效?
2. DXY水平 vs 趋势, 哪个更强?
3. 两者能否组合(趋势+水平)提升预测力?

---

## 二、候选变体 (7个全部预注册)

| 变体 | 定义 | 含义 |
|------|------|------|
| **M1**: dxy_chg_5d | dxy.pct_change(5) | 短期变化率 (周度) |
| **M2**: dxy_chg_20d | dxy.pct_change(20) | 月度变化率 |
| **M3**: dxy_chg_60d | dxy.pct_change(60) | 季度变化率 |
| **M4**: dxy_diff_20 | dxy.diff(20) | 月度绝对变化 |
| **M5**: dxy_ma_ratio | dxy / dxy.rolling(60).mean() | 均线比 |
| **M6**: dxy_breakout | dxy > 60日最高 × 0.95 | 突破信号 |
| **M7**: dxy_trend_z | (dxy - MA60) / std60 | 趋势z-score |

**核心逻辑**: DXY走弱趋势 → 黄金走强 → 未来波动放大

## 七、关键发现 (为何DXY变化趋势完全失败)

### 7.1 反向预测 (Counterintuitive)

直觉假设: **美元走弱 → 黄金走强 → 未来波动放大**

实测结果: **DXY变化趋势的偏IC全部为负**, 即DXY走弱反而对应未来波动*缩小*, 这与直觉相反。

### 7.2 核心解释

| 机制 | DXY水平 (F10成功) | DXY变化趋势 (本研究失败) |
|------|-------------------|--------------------------|
| 测量对象 | "美元当前多贵" (相对均值) | "美元在朝哪走" (方向) |
| 经济含义 | 美元高估/低估 → 全球资本流动 → 黄金定价压力 | 短期汇率波动, 无长期影响 |
| 预测未来波动 | ✅ +0.21 (强) | ❌ 接近0或负 |
| 持续性 | 水平偏离均值持续数月 | 变化趋势5-60日即反转 |

### 7.3 子周期稳健性反差

| 区间 | F10_dxy_z (水平) | 7个变化趋势变体 |
|------|------------------|---------------|
| 2018-2025 | 3/3子周期正向 | 大多1/3或0/3 |
| **2008-2025** | **1/3** (变差) | **0/3** (全负) |

F10在更长区间也变差, 但仍然正向 (+0.21 vs -0.05~0.18), 证明**水平比趋势更稳健**。

### 7.4 为何F10的子周期从3/3降到1/3?

2008-2025包含了金油比研究识别的**2008-2013 QE/危机regime**:
- 该regime下DXY水平与黄金波动关系不稳定
- 但F10仍然是7个变体中**唯一正向**的(其他全负或零)
- 说明F10的水平信号比变化趋势**方向稳定性高得多**

## 八、结论

| 项 | 结论 |
|----|------|
| DXY变化趋势预测未来黄金波动 | ❌ **负向**或零, 全部7个变体不通过G1 |
| 与F10 (DXY水平) 对比 | F10 +0.21 vs 变化趋势 -0.05~-0.18, **水平远优于趋势** |
| 组合可能性 | 不议 (0个变体通过G1, 无组合基础) |
| 对生产启示 | **F10 (DXY水平) 已是最优DXY因子, 不必再探索变化趋势** |
