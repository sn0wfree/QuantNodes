旧文档 (docs/63-67) 与新文档 (docs/68) 偏差原因:
1. 旧 v0-v7.10 数据起点 2018-01-02 (1 天偏差)

3. OOS 起点混乱: docs/63 用 2021-08-01, docs/66 用 2022-01-01

**本文档统一用 2018-01-03 ~ 2026-05-29** (新策略全区间)。

### 2.2 指标定义一致性

| 指标 | 公式 (本文) | 与之前差异 |
|------|------------|-----------|
| **Sharpe** | `ann_ret / vol` | 不减除 rf, 反映真实波动率 |
| **Calmar** | `ann_ret / |max_dd|` | 同 |
| **MaxDD** | `(nav / cummax - 1).min()` | 用真实 NAV, 不用 rets 重建 |
| **AnnRet** | `(1+total)^(1/n_years) - 1` | 同 |
| **Vol** | `rets.std() × √252` | 同 |
| **WinRate** | `(rets > 0).mean()` | 同 |
| **Sortino** | `ann_ret / downside_vol` ⭐ 新 | 只惩罚下行波动 |
| **DownsideVol** | `rets[rets<0].std() × √252` ⭐ 新 | 仅负收益的 std |
| **MaxDDDays** | 最长 under-water days ⭐ 新 | 策略从新高恢复到新高经历的最长下跌天数 |
| **PayoffRatio** | `mean(rets>0) / |mean(rets<0)|` ⭐ 新 | 盈亏比 |

## §4 9 指标详细定义

### 4.1 原 6 指标 (已有)
| 指标 | 含义 |
|------|------|
| Sharpe | 单位波动率收益, 越高越好 |
| Calmar | 年化收益/最大回撤, 越高越好 |
| MaxDD | 最大回撤幅度, 越接近 0 越好 |
| AnnRet | 年化复合增长率 |
| Vol | 年化波动率 |
| WinRate | 收益为正的天数比例 |

### 4.2 新增 4 指标 (本文加入)
| 指标 | 公式 | 含义 |
|------|------|------|
| **Sortino** | `ann_ret / downside_vol` | 类似 Sharpe 但只惩罚下行波动 |
| **DownsideVol** | `rets[rets<0].std() × √252` | 仅负收益的波动率 |
| **MaxDDDays** | 历史最长 under-water days | 从新高到恢复新高的最长连续下跌天数 |
| **PayoffRatio** | `mean(rets>0) / |mean(rets<0)|` | 单次盈利 / 单次亏损, >1 表示盈多亏少 |

**为什么新增这 4 个**:
1. **Sortino**: 解决"上行波动算不算风险"问题 (上行波动不影响策略好坏)
2. **DownsideVol**: 直接看亏损有多大
3. **MaxDDDays**: 实盘关键指标 (回撤很深不可怕, 但回撤时间长会让资金不能动用)
4. **PayoffRatio**: 策略盈亏特征
