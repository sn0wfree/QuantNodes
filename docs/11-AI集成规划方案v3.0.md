## 三、数据库设计

### 3.1 SQLite 表结构

```sql
CREATE TABLE sessions (
    session_id TEXT PRIMARY KEY,
    user_id TEXT,
    context TEXT,  -- JSON
    metadata TEXT,  -- JSON
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE messages (
    message_id INTEGER PRIMARY KEY AUTOINCREMENT,
    session_id TEXT NOT NULL,
    role TEXT NOT NULL,  -- system/user/assistant
    content TEXT NOT NULL,
    metadata TEXT,  -- JSON {model, tokens, cost}
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (session_id) REFERENCES sessions(session_id) ON DELETE CASCADE
);

CREATE TABLE strategies (
    strategy_id TEXT PRIMARY KEY,
    user_id TEXT,
    name TEXT NOT NULL,
    description TEXT,
    current_code TEXT NOT NULL,
    tags TEXT,  -- JSON array
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE strategy_versions (
    version_id TEXT PRIMARY KEY,
    strategy_id TEXT NOT NULL,
    code TEXT NOT NULL,
    comment TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (strategy_id) REFERENCES strategies(strategy_id) ON DELETE CASCADE
);

CREATE INDEX idx_messages_session ON messages(session_id);
CREATE INDEX idx_messages_created ON messages(created_at);
CREATE INDEX idx_strategies_user ON strategies(user_id);
```

## 六、讨论议题

在开始实施前，需要确认以下设计决策：

### 议题 1: 数据库选择

| 选项 | 优点 | 缺点 |
|------|------|------|
| A. SQLite (推荐) | 零配置、便携、单文件 | 并发写入有限制 |
| B. DuckDB | 分析查询快、Parquet 支持 | 额外依赖 |
| C. PostgreSQL | 生产级并发 | 需要单独部署 |

建议: SQLite，适合个人/研究场景，未来可迁移

### 议题 2: 异步支持

| 选项 | 优点 | 缺点 |
|------|------|------|
| A. 同步 (推荐) | 简单、Streamlit 兼容 | 阻塞 |
| B. 异步 | 非阻塞、可并发 | 复杂度增加 |

建议: 同步实现优先，Streamlit 本身是同步的，未来可升级

### 议题 3: 流式输出

| 选项 | 说明 |
|------|------|
| A. 非流式 (推荐) | 完整响应后一次性展示 |
| B. 流式 | 打字机效果，需额外处理 |

建议: 先做非流式，UI 更简单

### 议题 4: 多用户支持

| 选项 | 说明 |
|------|------|
| A. 单用户 (推荐) | user_id 可选，默认 None |
| B. 多用户 | 需要用户认证、数据隔离 |

建议: 单用户优先，符合当前使用场景

### 议题 5: 代码执行

| 选项 | 说明 |
|------|------|
| A. 仅验证 (推荐) | CodeSandbox 验证，不执行 |
| B. 沙箱执行 | 限制性执行生成的代码 |

建议: 仅验证，CodeSandbox 已实现，执行有安全风险

### 议题 6: 配置管理

| 选项 | 说明 |
|------|------|
| A. 独立 AIConfig (推荐) | 在 `ai/config.py` 新建独立类 |
| B. 扩展 LLMConfig | 扩展现有的 `core/config.py` 中的 LLMConfig |

建议: 独立 AIConfig 类，与 core/config.py 解耦

import streamlit as st
from ai.facade import AIAgentFacade

def show_ai_chat():
    st.title("AI 助手")
    
    # 侧边栏：会话列表
    with st.sidebar:
        st.subheader("会话")
        if st.button("新建会话"):
            session_id = st.session_state.agent.create_session()
            st.session_state.current_session_id = session_id
            st.rerun()
        
        # 显示会话列表
        sessions = st.session_state.agent.list_sessions(limit=20)
        for s in sessions:
            label = f"{s.created_at.strftime('%m-%d %H:%M')} - {s.id[:8]}"
            if st.button(label, key=s.id):
                st.session_state.current_session_id = s.id
                st.rerun()
    
    # 主聊天区域
    if "current_session_id" in st.session_state:
        messages = st.session_state.agent.history_store.get_messages(
            st.session_state.current_session_id
        )
        
        # 显示历史消息
        for msg in messages:
            with st.chat_message(msg.role):
                st.markdown(msg.content)
        
        # 用户输入
        if prompt := st.chat_input("输入您的问题..."):
            with st.chat_message("user"):
                st.markdown(prompt)
            
            # 调用 AI
            with st.spinner("AI 思考中..."):
                response = st.session_state.agent.chat(
                    st.session_state.current_session_id,
                    prompt
                )
            
            with st.chat_message("assistant"):
                st.markdown(response.content)
    else:
        st.info("请选择或创建一个会话开始聊天")
```

## 4.3 Strategy Lab 页面 (app/pages/01_Strategy_Lab.py)

import streamlit as st
from ai.facade import AIAgentFacade

def show_strategy_lab():
    st.title("策略实验室")
    
    col1, col2 = st.columns([1, 1])
    
    with col1:
        st.subheader("策略描述")
        description = st.text_area(
            "请描述您的策略",
            placeholder="例如：双均线策略，当短期均线上穿长期均线时买入，下穿时卖出",
            height=200
        )
        
        return_pipeline = st.checkbox("返回 Pipeline 对象", value=True)
        
        if st.button("生成策略", type="primary"):
            with st.spinner("AI 正在生成策略..."):
                result = st.session_state.agent.generate_strategy(
                    description,
                    return_pipeline=return_pipeline
                )
                st.session_state.last_result = result
    
    with col2:
        st.subheader("生成结果")
        if "last_result" in st.session_state:
            result = st.session_state.last_result
            
            if result.is_valid:
                st.success("策略生成成功！")
                
                # 显示代码
                st.code(result.code, language="python")
                
                # 复制按钮
                st.button("复制代码", on_click=lambda: st.code(result.code))
                
                # 显示警告
                if result.warnings:
                    st.warning("警告：\n" + "\n- ".join(result.warnings))
            else:
                st.error("策略生成失败")
                if result.error_message:
                    st.code(result.error_message)
        else:
            st.info("输入策略描述后点击生成")
```

from ai.llm.base import LLMClientBase, ChatCompletion

class MockLLMClient(LLMClientBase):
    def __init__(self, responses=None, error=None):
        self.responses = responses or ["Mock response"]
        self.call_count = 0
        self.call_history = []
        self.error = error
    
    def _call_api(self, messages, **kwargs):
        self.call_count += 1
        self.call_history.append(messages)
        
        if self.error:
            raise self.error
        
        content = self.responses[self.call_count - 1 % len(self.responses)]
        return ChatCompletion(
            content=content,

            finish_reason="stop",
            usage={"prompt_tokens": 10, "completion_tokens": 20}
        )

# 第六部分：错误处理

## 6.1 异常层次

```python
# ai/exceptions.py

class QuantNodesAIError(Exception):
    """AI 模块基异常"""
    pass

class StorageError(QuantNodesAIError):
    """存储相关错误"""
    pass

class SessionNotFoundError(StorageError):
    """会话不存在"""
    pass

class StrategyNotFoundError(StorageError):
    """策略不存在"""
    pass

class ValidationError(QuantNodesAIError):
    """代码验证失败"""
    pass

class ConfigurationError(QuantNodesAIError):
    """配置错误"""
    pass
```

## 6.2 各组件错误处理策略

| 组件 | 场景 | 处理策略 |
|------|------|----------|
| SessionManager | session_id 不存在 | 抛出 SessionNotFoundError |
| HistoryStore | 数据库写入失败 | 回退到内存模式，记录告警日志 |
| StrategyStore | 策略 ID 不存在 | 抛出 StrategyNotFoundError |
| AIAgentFacade.chat | LLM API 超时 | 重试 3 次后返回友好错误 |
| StrategyGenerator | 沙箱验证失败 | 返回 GenerationResult 含错误信息 |

## 6.3 错误重试机制

```python
# ai/retry.py

import time
import functools
from typing import Callable, Any

def retry(max_attempts=3, delay=1.0, backoff=2.0, exceptions=(Exception,)):
    def decorator(func: Callable) -> Callable:
        @functools.wraps(func)
        def wrapper(*args, **kwargs) -> Any:
            current_delay = delay
            for attempt in range(max_attempts):
                try:
                    return func(*args, **kwargs)
                except exceptions as e:
                    if attempt == max_attempts - 1:
                        raise
                    time.sleep(current_delay)
                    current_delay *= backoff
            return None
        return wrapper
    return decorator
```

## 7.2 Token 用量统计

```python
# ai/token_counter.py

from typing import List, Dict

class TokenCounter:
    def __init__(self):
        self.daily_usage: Dict[str, int] = {}  # date -> tokens
    
    def add_usage(self, tokens: int, model: str):
        date = time.strftime("%Y-%m-%d")
        if date not in self.daily_usage:
            self.daily_usage[date] = 0
        self.daily_usage[date] += tokens
    
    def get_daily_usage(self, date: str = None) -> int:
        if date is None:
            date = time.strftime("%Y-%m-%d")
        return self.daily_usage.get(date, 0)
    
    def check_limit(self, daily_limit: int) -> bool:
        return self.get_daily_usage() < daily_limit
```
