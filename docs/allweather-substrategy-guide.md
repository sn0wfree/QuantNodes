## 2. A sleeve — 类别级风险预算 (防御锚)

**代码**: `class_erc.py` (206 行) | **配置**: `weight_scheme="class_erc", bond_risk_cap=0.10, lev=1.0`

### 2.1 动机 (§5.17-5.19 诊断)

原 HRP+MP 组合在 38 资产池退化为 **3.5x 杠杆国债组合**:
- 债券 gross 352%, P&L 债券贡献 51.7% (2022 年 196%, 2025 年 364%)
- 与债券合成 120 日滚动相关 mean 0.77
- DV01 解析: 久期贡献 12.8 年 → 利率 +100bp ≈ **-12.9% NAV**

根因: 风险平价在权重空间 w ∝ 1/σ 天然向低波资产倾斜; 资产级 cap 封不住
类别级集中 (3 只国债期货同属一个利率因子)。

### 2.2 算法 (4 步)

```
① 类内合成: 每类成员 inv-vol 合成类收益序列 (滚动窗口因果)
② 类级协方差 (窗口 252 日)
③ 类间 ERC: CCD 坐标下降 (Griveau-Billion 2013), x_i(Σx)_i = b_i 精确解
   债券封顶: RC_bond > cap → bond 预算固定为 cap, 其余 (1-cap) 等预算重解
④ 摊回: 类权重按成员 inv-vol 分到资产; 映射遗漏的资产并入等权残余
```

**关键发现**: 类级 ERC 自然 RC = 1/K = 0.10, cap=0.10 即"自然封顶"——
类级 ERC 本身就修复了债券集中, cap 是 <0.10 的进一步收紧选项。

## 3. B sleeve — 等权 vol-target + Sub-B 方向 alpha

**代码**: `backtest.py` (run_backtest) + `subfactors.py` / `subfactors_weekly.py`
**配置**: `use_hrp=False, use_vol_target=True, max_leverage=1.0, subfactor_mode="abc", subfactor_alpha=3.0`

### 3.1 基础引擎: 等权 + vol target

等权持有全部可交易资产 (渐进入池: 窗口内非空观测 ≥ 60 才纳入),
vol_target=10% 缩放总敞口 (cap 1.0)。角色: 风险资产牛市参与 sleeve。

### 3.2 Sub-B 方向性 alpha (V6.8, §13.3.1 + V6.8 消融)

三子因子中的 Sub-B **趋势力度** 维度, 增强参数化:

```
Sub-B = (TrendQualityFactor + MomentumSlopeFactor) / 2   ∈ [-1, 1]
  TrendQuality:  60 日回归 R² (>0.6 视为趋势纯) × 方向
  MomentumSlope: 30 日动量斜率 + 15 日短斜率确认

V6.8 定版: rank 标准化 + directional_risk_transform (subfactors_weekly.py:118)
  clip(score, upper=0)   ← 只保留负向 (文章"负向趋势"语义)
  应用: w × (1 + α × clip(score,0)) = w × (1 - α·max(0,-score))
  α = 3.0 (消融定版): 趋势破坏资产最多 3 倍降权; 趋势确认不超配 (非对称)
```

**设计语义**: 单向风控而非双向 alpha——"趋势确认期参与, 趋势破坏时先走"。
V6.8 vs 纯等权: Sharpe +11.9% (0.758→0.848), MaxDD +3.59pp (§5.15)。

## 5. D sleeve — 资产级配置管线 v3 (生产候选) ★

**代码**: `d_pipeline.py` (412 行) + `momentum_tilt.py` + `neg_trend_daily.py`
**配置**: lw / W-FRI / bond_cap=0.40 / lev=1.0 / trend balanced + rapid + momentum β=0.20

### 5.1 核心管线 (调仓日五步, `d_pipeline.py:141-276`)

```
① 协方差估计 (默认 Ledoit-Wolf; 可选 oas/lw_ewma/block_corr/nqn/poet/avs)
② HRP(Ward) 权重 → 风险预算 b = RC(w_HRP)/ΣRC
     (层次聚类洞察 → 求解器预算, 非直接用 HRP 权重)
③ 合成债券资产: fut_t/tf/ts 三债券 inv-vol 合成 → 1 个合成资产
④ 盒约束风险预算求解 (SLSQP, d_pipeline.py:40-107):
     min Σ(RC_i(w) - b_i)²   s.t. Σw=1, 0 ≤ w ≤ u
     合成债券 u = bond_cap (0.40), 其余 u = 1.0
⑤ 摊回: 合成债券权重按 inv-vol 分回 3 只国债期货
```

**设计原则 (§5.24 勘误后的原理性重构 v2, PLAN §17.10)**:
- 不变量 1 — 估计器自调节: EWMA λ 随 N_eff 自适应; OAS 与 sklearn 对齐
- 不变量 2 — 约束由求解器内建: **删除 v1 的 RC share 重分配**
  (近奇异协方差下无界放大 → 曾致负权重 / gross 56x 爆炸)
- 验证: 全部协方差方法 min_w=0 / gross_max=1.0 恒成立

**关键发现 (§5.25)**: 预算通道使协方差选择几乎不重要 (7 方法极差 0.375, LW 最优)。
A vs D 剩余差距 0.29 来自配置引擎结构 (类别级 vs 资产级), 非协方差质量。

### 5.2 四层叠加 (按执行顺序)

| 层 | 频率 | 机制 | 代码 |
|----|------|------|------|
| D.2 动量倾斜 | 周频调仓日 | `w × t_i`, t = 1 + β·tanh(0.5·t-stat), β=0.20, clip [1-β, 1+β] | `momentum_tilt.py` |
| D.1 负趋势 | **日频** | `w × (1 − penalty)`, penalty∈[0,1] | `neg_trend_daily.py` |
| rapid 急跌 | 日频 (叠加 10% 权重) | max(5日回撤代理, vol扩张), 资产通用 | `neg_trend_daily.py` |
| **P1-B 相关性覆盖** | **日频** | `w × m`, m = 1 − k·max(0, sig−θ)/(1−θ), 类内相关 > θ 才降权 | `d_pipeline.py` |

**D.2 语义**: 双向 alpha——动量正超配/负低配。
**修复 (§5.32)**: 按 (input_sum/tilted_sum) 重缩放, tilt 只再分配相对权重,
**总敞口 (杠杆语义) 保持不变**——原实现无条件归一化把 vol_target 杠杆抹掉。

**P1-B 语义 (§5.37)**: 结构性风控——检测类内两两相关是否飙升（分散化坍缩 → 风险平价前提失效）。
阈值门控: 平时 (sig < θ) 零影响; 危机 (sig ≥ θ) 线性降权, 最多降 k。
与 D.1 完全正交（全样本相关 0.103）——D.1 是价/量/波微观信号, P1-B 是类间结构信号。
41 资产池有效（Sharpe 0.90→1.02, DD -10.41%→-8.75%）; 对齐池 13 资产不适用（分散化已充分）。
默认关闭 (k=0); 启用推荐: θ=0.60, k=1.00 或保守 θ=0.65, k=0.80。

### 7.2 关键教训清单

1. **RC 重分配爆炸** (§5.24): 近奇异协方差 (EWMA N_eff < N) 下 RC share 重分配
   无界放大 → 负权重 / gross 56x。修复: 原理性重构, 约束由 SLSQP 内建。
2. **HRP 伪最优** (§5.35): 残缺数据让 HRP 把权重堆到 CASH/低波资产,
   vol=2.0%/DD=-1.95% 的"无风险"伪象; 完整数据后 Sharpe 1.77→1.24, DD -5.46%。
   数据补全 = 风险重估。
3. **vol_target 杠杆 bug** (§5.32): tilt 后无条件归一化抹掉杠杆语义。
   修复: 按 (input_sum/tilted_sum) 重缩放。
4. **tanh 饱和** (§5.27): 价格单位斜率 ÷ 收益率 vol 在高价资产上是天文数字,
   70% 格子 |x|≥1。修复: 收益率单位 t-stat。
5. **预算机制中和协方差选择** (§5.25): 经 HRP RC → 求解器通道后,
   7 种协方差极差仅 0.375——不要再花力气换协方差引擎。
6. **资产池 > 引擎** (§5.30): 换池 +26% 远大于任何引擎改进 (+10%);
   结构问题 (商品 47% 过度代表) 是第一瓶颈。
