# v9 银河方案 归因分析 (Brinson 分解)

> 数据窗口: 2021-08-01 ~ 2026-05-31 (247 周, 4.8 年)
> 资产: 43 ETF (v9_factor_galaxy_etf.py 过滤后)

## 背景

v9 已落地 2 个业界因子配置方案: **银河证券因子配置** (主方案) + v8/v9 自研的多因子动态择时.
当前最优 = 银河方案-动态仓位 (Sharpe 1.384, 年化 15.53%, MaxDD -14.00%).

但该方案混合了 2 个信号 (银河选股 + 动态仓位), 各自贡献多少不清楚.
之前一版归因 (signal_attribution v1) 有 2 个致命 bug, NAV 互不闭合.

## Brinson 三因子分解 (0 成本, 严格闭合)

设:
- `r_eq`     = 等权基准 (固定 1/N) 周收益
- `r_galaxy` = W^银河因子配置 * r  (固定仓位) 周收益
- `r_full`   = pos × W^银河因子配置 * r  (银河方案-动态仓位) 周收益
- `pos`      = 动态仓位 (0.2 ~ 1.0, z_score 标准化)

分解:
- **仓位效应** (Allocation)  = (pos - 1) × r_eq
- **选股效应** (Selection)    = r_galaxy - r_eq
- **交互效应** (Interaction)  = (pos - 1) × (r_galaxy - r_eq)
- **合计超额** (Total Excess) = r_full - r_eq

| 效应 | 年化贡献 | 占比 |
|------|----------|------|
| **仓位效应** | **+7.80%** | **71.3%** |
| 选股效应 | +1.28% | 11.7% |
| 交互效应 | +1.87% | 17.1% |
| **合计超额** | **+10.94%** | 100% |

`alloc + select + interact = excess` 严格闭合 (差额 0.0e+00).

## 关键结论

1. **主导 alpha = 仓位效应 (+7.80%, 71%)** 而非选股 (+1.28%, 12%)
2. 银河因子配置 本身相对等权仅 +0.71% (4.8年累计), 几乎无 alpha
3. 真正起作用的是 `pos = (0.7 - 0.5·z_score).clip(0.2, 1.0)` 这条动态仓位曲线
4. 震荡市选股贡献才显现 (+3.17%), 牛/熊市选股反而拖累
5. 交互项 +1.87%: 仓位与选股**同向** (选股 alpha 高的时点仓位也高, 互相增强)

## 修复 vs 旧版

旧版 `signal_attribution` 函数有 2 个致命 bug:
1. 变量 `nav_dynamic` 实为 W^银河因子配置 × r (固定仓位) 但被错标为「完整」
2. `nav_eq_pos` 用代数 pos × r_mean 构造但未跑独立回测

给出 NAV 1.90 / 1.29 / 2.24 这种互不闭合的数字 (完整 < 任何子信号).

新版用 3 个独立回测 (等权基准 / 银河因子配置 / 银河方案-动态仓位) 的**周度收益序列**做 Brinson 分解.

## 未来改进方向 (因子选股不力)

1. **因子方向修正**: 5 类宏观指标 IC 显示 4/5 类与 ETF 收益负相关 (详见 factor_galaxy_attribution v1 报告)
2. **因子替换**: 用技术/动量/质量因子替代宏观因子, 提升选股 alpha
3. **滚动 IC 筛选**: 只在 IC > 0 的窗口使用因子选股, IC ≤ 0 时降为等权
4. **更智能的仓位**: 根据 IC 强度动态调整 (而不是简单 z-score)
