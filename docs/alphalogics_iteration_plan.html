1

LLM 驱动的因子自动生成系统

构建因子自动生成 — 回测 — 迭代闭环，研发效率提升 10x+
P0 ★
定义因子 DSL 基元算子（时序算子、截面算子、逻辑组合算子），构建 Multi-Agent 因子工厂， 复用现有回测引擎和数据基础设施，形成生成→回测→反馈→重生成的自动化闭环。
定义因子 DSL — 时序算子(ts_mean/ts_corr/ts_rank)、截面算子(rank/scale)、组合算子(signed_power/if_else)
Multi-Agent 工厂 — FactorIdeaAgent(生成)→FactorCodingAgent(编译)→FactorFeedbackAgent(反馈)→FactorOrchestrator(编排)
复用基础设施 — BacktestEngine 作为回测引擎，DataAPI 作为数据源
LLM Agent DSL 自动迭代 Early-Stop
2

市场逻辑库构建

从 100+ 现有生产因子逆向提取市场逻辑，构建结构化 H=<C,B> 逻辑库
P0 ★
遍历现有因子代码，用 LLM 逆向提取市场逻辑（条件 predicates + 信念 belief）， 存储为结构化数据，构建可查询、可组合的逻辑知识库。
因子→逻辑 Pipeline — 对每个因子提取 C(变量/算子/阈值/权重) 和 B(目标/方向/视野)
逻辑库 Schema — logic_id / conditions(JSON) / belief(JSON) / source_factors / avg_performance / category
人工验证 — 专家校验 LLM 提取结果，合并同类逻辑，剔除错误逻辑
知识库 逆向提取 结构化存储 DuckDB
3

市场逻辑驱动的因子搜索与优化

给定市场逻辑 H，自动编译为约束 Γ 并在约束空间内搜索最优因子实现
P0 ★
LogicToConstraint 编译模块将自然语言逻辑转化为可执行约束， 在约束空间内通过 LLM 搜索、遗传编程或混合策略进行因子优化， 以验证集 IR 为目标函数，early-stop 机制控制迭代轮次。
LogicToConstraint 编译 — H=<C,B> → 约束 Γ(变量范围/算子族/参数范围/符号方向)
三层搜索策略 — LLM 搜索(快速探索) / 遗传编程(精细调优) / 混合策略(先LLM后GP)
回测驱动优化 — 目标函数 J=IR_val，早停轮次 T_early=5
约束编译 遗传编程 LLM 搜索 Early-Stop
4

市场逻辑自动生成与进化

基于逻辑库自动生成新逻辑，用因子实际表现评判逻辑有效性，形成进化闭环
P1
Market Logic Generator Agent 通过组合、类比、反逻辑、跨类别杂交等方式生成新候选逻辑， 经由方向三的因子搜索验证后，保留高绩效逻辑到库中。
逻辑生成器 — 组合已有逻辑 predicates、类比推理、方向反转、跨类别杂交
逻辑绩效评估 — 对每个 H_new 运行因子搜索，目标 IR > 0.8 保留
逻辑演化 — 淘汰无效逻辑，分支探索有效逻辑的变体，形成逻辑进化树
逻辑生成 进化算法 逻辑库刷新
5

因子 DSL 引擎

高性能因子 DSL 编译与执行引擎，支持表达式快速验证与 GPU 加速
P1
构建 DSL 解析器（表达式→AST）、编译器（AST→可执行代码，支持 numba/jax 加速）、 验证器（类型/维度/参数范围检查），兼容现有 FactorBase 接口。
DSL 解析器 — 因子表达式字符串 → AST 节点树
DSL 编译器 — AST → Python/numba/jax 可执行代码，自动向量化
DSL 验证器 — 类型检查、维度检查、参数范围检查
AST 编译器 Numba GPU 加速
6

多维度因子绩效分析与可视化
