#### 1.2 完整 CI/CD 配置

```yaml
# .github/workflows/ci.yml
name: CI

on:
  push:
    branches: [master, develop]
  pull_request:
    branches: [master]

jobs:
  lint:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: '3.11'
      - uses: pre-commit/action@v3.0.1

  typecheck:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: '3.11'
      - run: pip install mypy
      - run: mypy QuantNodes/ --ignore-missing-imports

  test:
    runs-on: ubuntu-latest
    strategy:
      matrix:
        python: ['3.11', '3.12']
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: ${{ matrix.python }}
      - run: pip install -e ".[dev]"
      - run: pytest tests/ -x -q --cov=QuantNodes --cov-report=xml

  coverage:
    runs-on: ubuntu-latest
    needs: [test]
    steps:
      - uses: actions/checkout@v4
      - uses: codecov/codecov-action@v4
        with:
          files: ./coverage.xml
```

#### 2.4 测试隔离铁律（v3.0.0 实战教训）

> 「单独跑通过、全量跑失败」几乎总是**跨测试状态泄漏**，不是 flakiness。下面两个真实案例均在 v3.0.0 Stage 6 根因修复。

**① 环境变量必须用 `monkeypatch.setenv`，禁止裸 `os.environ[...] = ...`**

```python
# ❌ 错误：临时目录在 with 退出后被删，残留悬空 HOME；
#    后续 subprocess e2e 测试继承坏 HOME，~/.quantnodes 写入失败 → 非零退出
def test_expanduser():
    with tempfile.TemporaryDirectory() as td:
        os.environ["HOME"] = td        # 永不还原！污染整个 session
        ...

# ✅ 正确：monkeypatch 在 test 结束自动还原
def test_expanduser(monkeypatch):
    with tempfile.TemporaryDirectory() as td:
        monkeypatch.setenv("HOME", td)
        ...
```

**② 全局注册表用「快照/还原」autouse fixture，而非按条件删除**

```python
# ❌ 错误：只删本模块注册的 op，YAML 动态注册的 op（__module__ 指向库代码）漏网
#    → 泄漏到其他模块的「polars/pandas 算子集合对比」断言
to_remove = [n for n, s in REG._registry.items() if s.template.__module__ == __name__]

# ✅ 正确：完整快照 + 还原，无遗漏
@pytest.fixture(autouse=True)
def _isolate_registry():
    snapshot = dict(REG._registry)
    yield
    REG._registry.clear()
    REG._registry.update(snapshot)
```

**③ 其他铁律**

- 所有 `subprocess.run(...)` 必须带 `timeout=`，避免全量运行时挂死。
- 验证手段：`pytest tests/ -p no:xdist`（顺序）与默认（并行）**都要 0 failed**；可用 `pytest -p no:randomly` 或随机种子复现顺序依赖。
- 可选依赖缺失时**优雅降级**（返回 `None`/回退实现），测试用 `pytest.importorskip` 跳过而非删除。

### 阶段 3: 故障预防机制 (第三周)

#### 3.1 代码审查清单

**PR 合并前必须检查**:
- [ ] 所有测试通过 (CI green)
- [ ] 类型检查通过 (mypy)
- [ ] Lint 通过 (ruff)
- [ ] 测试覆盖率不低于阈值
- [ ] 无新增 `TODO`/`FIXME`
- [ ] 文档已更新 (如有 API 变更)

**审查检查项**:
- [ ] 无 hardcoded 凭据/密钥
- [ ] 无 `print()` 调试代码
- [ ] 异常处理正确 (非 bare except)
- [ ] 异步代码无阻塞调用
- [ ] 数据库操作有事务/回滚

#### 3.2 防御性编程规范

```python
# 1. 输入验证
def process_data(df: pd.DataFrame) -> pd.DataFrame:
    if df is None or df.empty:
        raise ValueError("DataFrame cannot be None or empty")
    if "required_column" not in df.columns:
        raise ValueError("Missing required column")

# 2. 明确的返回类型
def get_user(user_id: int) -> Optional[User]:
    ...

# 3. 日志记录
logger.info(f"Processing {len(items)} items")
try:
    result = risky_operation()
except SpecificException as e:
    logger.error(f"Failed: {e}", exc_info=True)
    raise

# 4. 超时控制
async def fetch_data():
    async with asyncio.timeout(30):
        return await real_fetch()

# 5. 资源清理
def process():
    resource = acquire()
    try:
        return resource.do_work()
    finally:
        resource.release()
```

## 四、降低故障率操作清单

### 4.1 高优先级 (必须执行)

| 操作 | 频率 | 工具 | 防止什么 |
|------|------|------|----------|

| 单元测试 | 每次 PR | pytest | 逻辑错误 |
| 代码审查 | 每次 PR | GitHub PR | 逻辑错误、安全问题 |

### 4.2 中优先级 (强烈推荐)

| 操作 | 频率 | 工具 | 防止什么 |
|------|------|------|----------|
| 测试覆盖率检查 | 每次 PR | pytest-cov | 测试盲区 |
| 集成测试 | 每次 PR | pytest | 模块交互问题 |
| 性能回归测试 | 每周 | pytest-benchmark | 性能退化 |
