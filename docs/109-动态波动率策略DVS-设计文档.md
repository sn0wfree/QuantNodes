## 一、策略概述

### 核心理念
**"平时收租，风暴前买保险"**

DVS是一个双引擎动态期权策略：
1. **Theta引擎**（默认）：卖put spread收权利金
2. **Gamma引擎**（触发式）：买跨式，在波动率爆发时获利

核心创新：
- **IV Crush预警退出**：在IV crush发生前退出买方头寸
- **波面曲面套利选股**：利用`detect_outliers()`找到IV曲面上便宜的合约
- **冷静期机制**：连续IV crush后自动减仓，避免重复踩坑
- **按品种动态delta**：根据各品种流动性特征选择最活跃delta区间

### 与GammaVegaSeller的关系
- **共存**，不替代
- GV提供稳定的theta收入（60%资金）
- DVS提供尾部保护+vol事件收益（40%资金）
- 互补：GV在波动爆发时亏损，DVS在波动爆发时赚钱

## 三、市场状态识别器 (`regime_detector.py`)

### 3.1 五种状态定义

| 状态 | 触发条件 | 引擎 | 操作 |
|------|---------|------|------|
| **CALM** | IV百分位<30%, IV动量平稳, VIX<20百分位 | Theta | 卖put spread |
| **TRANSITION** | IV百分位30-50%, IV缓慢上升 | Theta | 卖put + 买小call翼 |
| **HIGH_VOL** | IV百分位50-75%, 稳定高位 | Theta | 卖铁鹰 |
| **VOL_SPIKE** | IV 5日变化>20%, 期限倒挂, Skew变陡 | Gamma | 买跨式 |
| **COMPRESSION** | IV百分位>75%但回落中 | Theta | 卖宽跨 |

### 3.2 状态识别逻辑

```python
class RegimeDetector:
    """市场状态识别器"""
    
    def compute_regime(self, product, date, iv_panel, vix_series, option_data):
        iv_pct = self._get_iv_percentile(product, date, iv_panel)
        iv_mom_5d = self._get_iv_momentum(product, date, iv_panel, window=5)
        iv_mom_20d = self._get_iv_momentum(product, date, iv_panel, window=20)
        vix_pct = self._get_vix_percentile(date, vix_series)
        term_slope = self._get_term_structure_slope(product, date, option_data)
        skew_z = self._get_skew_zscore(product, date, option_data)
        
        # VOL_SPIKE检测（优先级最高）
        if (abs(iv_mom_5d) > 0.20 and term_slope < 0 and skew_z > 1.5):
            return Regime.VOL_SPIKE
        
        # 其他状态
        if iv_pct < 0.30 and iv_mom_20d < 0.05:
            return Regime.CALM
        elif iv_pct < 0.50 and iv_mom_20d > 0.05:
            return Regime.TRANSITION
        elif iv_pct < 0.75:
            return Regime.HIGH_VOL
        else:  # iv_pct >= 0.75
            if iv_mom_5d < 0:  # IV从高位回落
                return Regime.COMPRESSION
            else:
                return Regime.HIGH_VOL
```

### 3.3 IV Crush事件检测

**触发条件**（两者结合）：

```python
def detect_iv_crush(self, product, date, iv_panel):
    """检测IV crush事件"""
    iv_zscore_now = self._get_iv_zscore(product, date, iv_panel)
    iv_zscore_prev = self._get_iv_zscore(product, date_prev, iv_panel)
    iv_mom_5d = self._get_iv_momentum(product, date, iv_panel, window=5)
    
    # 条件1：IV zscore从极端高位回落
    zscore_drop = (iv_zscore_prev > 1.5 and iv_zscore_now < 1.0)
    
    # 条件2：IV 5日动量为负且跌幅>5%
    mom_negative = (iv_mom_5d < -0.05)
    
    return zscore_drop and mom_negative
```

### 3.4 冷静期机制

```python
class CooldownManager:
    """冷静期管理器
    
    连续IV crush后自动减仓：
    - 第1次：仓位50%，持续cooldown_days天
    - 第2次（冷静期内）：仓位25%
    - 第3次：仓位12.5%
    - 最低不低于min_position_pct（20%）
    """
    
    def __init__(self, cooldown_days=10, min_position_pct=0.20):
        self.cooldown_days = cooldown_days
        self.min_position_pct = min_position_pct
        self.crush_count = 0
        self.last_crush_date = None
    
    def on_iv_crush(self, date):
        """每次检测到IV crush时调用"""
        if self.last_crush_date is None or \
           (date - self.last_crush_date).days > self.cooldown_days:
            self.crush_count = 1  # 新周期
        else:
            self.crush_count += 1  # 冷静期内累加
        self.last_crush_date = date
    
    def get_position_multiplier(self, date):
        """返回仓位乘数：0.5^n，但不低于min_position_pct"""
        if self.last_crush_date is None:
            return 1.0
        days_since = (date - self.last_crush_date).days
        if days_since > self.cooldown_days:
            return 1.0  # 冷静期结束
        multiplier = 0.5 ** self.crush_count
        return max(self.min_position_pct, multiplier)
```

**效果示例**：

| 事件 | crush_count | 仓位乘数 | 持续时间 |
|------|------------|---------|---------|
| 第1次IV crush | 1 | 50% | 10天 |
| 第2次IV crush（10天内） | 2 | 25% | 10天 |
| 第3次IV crush（10天内） | 3 | 20%（最小） | 10天 |
| 冷静期结束 | - | 100% | - |

| > 2000万 | 10 | 机构级别 |

### 4.2 品种评分公式

```python
def score_product(self, product, date, regime, iv_panel, vrp_panel, volume_data):
    """品种评分"""
    
    # 1. VRP评分（0-1）：VRP越高越适合卖方
    vrp = vrp_panel.loc[date, product] if date in vrp_panel.index else 0
    vrp_score = min(1.0, max(0.0, (vrp + 0.1) / 0.2))  # [-0.1, 0.1] -> [0, 1]
    
    # 2. 流动性评分（0-1）：成交量+持仓量
    vol = volume_data.get(product, {}).get(date, 0)
    liq_score = min(1.0, vol / 10000)  # 假设1万手为满分
    
    # 3. IV适配度评分（0-1）：当前状态下的IV是否适合
    iv_pct = self._get_iv_percentile(product, date, iv_panel)
    if regime in [Regime.CALM, Regime.TRANSITION]:
        # 卖方：IV越高越好
        iv_fit_score = iv_pct
    elif regime == Regime.VOL_SPIKE:
        # 买方：IV越低越好
        iv_fit_score = 1.0 - iv_pct
    else:
        iv_fit_score = 0.5
    
    # 4. 数据历史评分（0-1）：>200天为满分
    history_days = self._get_history_days(product, iv_panel)
    history_score = min(1.0, history_days / 200)
    
    # 综合评分
    score = (vrp_score * 0.3 +
             liq_score * 0.2 +
             iv_fit_score * 0.3 +
             history_score * 0.2)
    
    return score
```

### 4.3 品种选择流程

```python
def select_products(self, date, regime, max_products, all_products, ...):
    """选择Top N品种"""
    scores = {}
    for product in all_products:
        scores[product] = self.score_product(product, date, regime, ...)
    
    # 按评分排序，取Top N
    sorted_products = sorted(scores.items(), key=lambda x: x[1], reverse=True)
    selected = [p for p, s in sorted_products[:max_products] if s > 0.3]  # 最低门槛0.3
    
    return selected
```

## 五、曲面套利选股 (`surface_selector.py`)

### 5.1 核心逻辑

先用`detect_outliers()`找便宜/贵的合约，找不到就fallback到品种专属delta。

### 5.2 各品种专属delta

基于流动性数据研究（2023-2025年），所有品种的最活跃OTM delta区间都在0.10-0.30：

| 品种类别 | 代表品种 | 最活跃OTM delta区间 | fallback delta |
|---------|---------|-------------------|---------------|
| 黑色系 | RB, I | 0.10-0.30 | 0.25 |
| 有色 | CU, AL, NI | 0.10-0.25 | 0.25 |
| 贵金属 | AU, AG | 0.10-0.30 | 0.25 |
| 农产品 | M, SR, CF | 0.10-0.25 | 0.25 |
| 化工 | TA, MA, RU | 0.10-0.25 | 0.25 |
| 能源 | SC, FU | 0.15-0.30 | 0.25 |

**统一fallback delta = 0.25**（处于0.20-0.30最活跃区间）。

### 5.3 选股流程

```python
class SurfaceSelector:
    """曲面套利选股器"""
    
    def __init__(self):
        self.smile_analyzer = IVSmileAnalyzer()
        self.skew_analyzer = SkewAnalyzer()
        self.fallback_delta = 0.25
    
    def select_for_strategy(self, product, date, spot, strategy_type, option_data):
        """根据策略类型选择合约"""
        chain = self._load_chain(product, date, option_data)
        if chain is None or chain.empty:
            return None
        
        # 1. 尝试曲面套利选股
        outliers = self._detect_outliers(chain, spot)
        
        if strategy_type == "sell_put":
            return self._select_sell_put(chain, spot, outliers, product)
        elif strategy_type == "buy_straddle":
            return self._select_buy_straddle(chain, spot, outliers)
        elif strategy_type == "sell_iron_condor":
            return self._select_sell_iron_condor(chain, spot, outliers)
        elif strategy_type == "sell_strangle":
            return self._select_sell_strangle(chain, spot, outliers)
        elif strategy_type == "sell_put_spread":
            return self._select_sell_put_spread(chain, spot, outliers, product)
    
    def _select_sell_put(self, chain, spot, outliers, product):
        """卖put选股"""
        # 优先选IV偏高的合约（residual > 0 = 贵的）
        candidates = [o for o in outliers if o['residual'] > 0 and o['delta'] < 0]
        if candidates:
            # 选residual最大的（最贵的）
            best = max(candidates, key=lambda x: x['residual'])
            return self._find_closest_contract(chain, spot, best['delta'], "P")
        
        # fallback: delta-targeting
        return select_put(product, date, spot, target_delta=self.fallback_delta)
    
    def _select_buy_straddle(self, chain, spot, outliers):
        """买跨式选股"""
        # 优先选IV偏低的合约（residual < 0 = 便宜的）
        candidates = [o for o in outliers if abs(o['residual']) > 0.01]
        if candidates:
            # 找IV最便宜的strike
            cheapest = min(candidates, key=lambda x: x['iv'])
            return select_straddle_at_strike(chain, spot, cheapest['strike'])
        
        # fallback: ATM
        return select_straddle(chain, spot)
    
    def _select_sell_iron_condor(self, chain, spot, outliers):
        """卖铁鹰选股"""
        # body选IV高的，wings选IV低的
        put_candidates = [o for o in outliers if o['delta'] < 0]
        call_candidates = [o for o in outliers if o['delta'] > 0]
        
        # body: 选0.25 delta附近的，IV偏高的
        body_put = self._select_sell_put(chain, spot, put_candidates, None)
        body_call = self._select_sell_call(chain, spot, call_candidates, None)
        
        # wings: 选0.05 delta附近的，IV偏低的
        wing_put = select_put(chain, spot, target_delta=0.05)
        wing_call = select_call(chain, spot, target_delta=0.05)
        
        return IronCondor(body_put, wing_put, body_call, wing_call)
    
    def _detect_outliers(self, chain, spot):
        """检测IV曲面异常"""
        if len(chain) < 5:
            return []
        
        strikes = chain['strike_price'].values
        ivs = chain['bs_iv'].values
        
        try:
            outliers = self.smile_analyzer.detect_outliers(strikes, ivs, threshold=1.5)
            return outliers
        except Exception:
            return []
```

### 7.2 止损计算

```python
def check_stop_loss(self, position, current_premium, regime):
    """检查是否触发止损"""
    entry_premium = position.entry_premium
    threshold = self.REGIME_STOP_LOSS[regime]
    
    if position.side == "short":
        # 卖方：溢价上涨触发止损
        loss_pct = (current_premium - entry_premium) / entry_premium
    else:
        # 买方：溢价下跌触发止损
        loss_pct = (entry_premium - current_premium) / entry_premium
    
    return loss_pct >= threshold
```

### 7.3 Gamma引擎预算

```python
def compute_gamma_budget(self, equity, iv_percentile):
    """计算gamma引擎预算"""
    base_budget = 0.15  # 基础15%
    iv_adjustment = max(0, (0.5 - iv_percentile)) * 0.5  # IV越便宜越多
    gamma_budget = min(0.25, base_budget + iv_adjustment)  # 上限25%
    return equity * gamma_budget
```

### 7.4 仓位大小计算

```python
def compute_position_size(self, equity, strategy_type, regime, cooldown_mult):
    """计算仓位大小"""
    # 基础仓位
    if strategy_type == "sell_put_spread":
        base_size = equity * 0.30  # delta目标30%
    elif strategy_type == "buy_straddle":
        base_size = self.compute_gamma_budget(equity, iv_pct)
    else:
        base_size = equity * 0.20
    
    # 应用冷静期乘数
    final_size = base_size * cooldown_mult
    
    return final_size
```

### 8.1 Delta对冲

```python
def compute_delta_hedge(self, portfolio_delta, equity, spot, multiplier):
    """计算Delta对冲量"""
    delta_notional = abs(portfolio_delta) * spot * multiplier
    delta_pct = delta_notional / equity
    
    if delta_pct > 0.10:  # delta敞口>10% NAV
        hedge_qty = int(delta_notional / (spot * multiplier))
        hedge_direction = -1 if portfolio_delta > 0 else 1
        return hedge_qty * hedge_direction
    return 0
```

### 8.2 Vega监控

```python
def check_vega_limit(self, portfolio_vega, equity, limit=0.01):
    """检查Vega敞口是否超限"""
    vega_notional = abs(portfolio_vega) * equity
    return vega_notional > equity * limit
```

## 九、主策略类 (`dynamic_vol_strategy.py`)

### 9.1 类结构

```python
class DynamicVolStrategy(FactorModuleComboStrategy):
    """动态波动率策略
    
    双引擎设计：
    - Theta引擎：卖put spread/铁鹰/宽跨，收theta
    - Gamma引擎：买跨式，赚gamma
    
    核心创新：
    - IV Crush预警退出
    - 波面曲面套利选股
    - 冷静期机制
    """
    
    def __init__(self, config=None, **kwargs):
        super().__init__(**kwargs)
        self.config = config or DynamicVolConfig()
        
        # 初始化各层
        self.regime_detector = RegimeDetector(self.config)
        self.product_scorer = ProductScorer(self.config)
        self.surface_selector = SurfaceSelector()
        self.strategy_router = StrategyRouter(self.config)
        self.risk_manager = RiskManager(self.config)
        self.greeks_hedger = GreeksHedger(self.config)
        self.cooldown_manager = CooldownManager(
            cooldown_days=self.config.cooldown_days,
            min_position_pct=self.config.min_position_pct
        )
        
        # 状态存储
        self._state = {}  # {product: holding_info}
        self._targets_by_date = {}
    
    def precompute_all_targets(self, option_data, iv_panel, vrp_panel, ...):
        """预计算所有日期的目标持仓（批量模式）"""
        dates = iv_panel.index
        
        for date in dates:
            # 1. 识别市场状态
            for product in self.config.products:
                regime = self.regime_detector.compute_regime(product, date, ...)
                
                # 2. 检查IV crush
                if self.regime_detector.detect_iv_crush(product, date, ...):
                    self.cooldown_manager.on_iv_crush(date)
                
                # 3. 选择品种（如果需要）
                # 4. 选股（曲面套利）
                # 5. 路由到策略
                # 6. 计算仓位大小
                # 7. 存储目标持仓
        
        return self._targets_by_date
    
    def target_positions(self, date, data):
        """回测引擎调用：返回目标持仓"""
        return self._targets_by_date.get(date, {})
```

## 十三、复用GV的设计模式

| GV模式 | 借鉴方式 | 改进点 |
|--------|---------|--------|
| Delta目标仓位公式 | `qty = equity * target_pct / (spot * mult * delta)` | 直接复用 |
| 溢价止损 | `(cur_premium - entry_premium) / entry_premium` | 增加状态差异化 |

| `_delta_of()` + GreeksCache | 缓存回退机制 | 改用`get_or_compute()` |
| `selector.py`合约选择 | `select_put/call/straddle` | 增加曲面感知层 |
| `OptionOnlyGV`模式 | 纯期权回测 | 直接复用 |
| `full_metrics()` | 指标计算 | 直接复用 |
