## 一、数据基础设施

### 1.1 tick 同步脚本修复 (`tick_ftp_check.py`)

**背景**: 历史缺口 8 个月（SHFE 2026-01-06 / GFEX/INE 2026-02-27），同步脚本每天只净增 1 个文件。

**根因**（干跑 4 轮逐层挖掘）：
1. **模式 A（死链级联）**：`auto_init()` 只查 `sftp is None`，检测不到 socket 已断但引用仍在 → 1085 个文件同一毫秒 "Socket is closed" 全失败
2. **模式 B（僵死挂起）**：无 channel timeout → 单个文件挂起 3h45m 吃掉整个下载窗口
3. **paramiko prefetch EOF 死锁**：`sftp.get()` 在文件末尾 prefetch 缓冲区边界卡死 → 通道超时只杀死后台线程，主线程永久等待
4. **目标目录缺失**：叶子路径场景下 `os.makedirs` 缺失（全树扫描掩盖了此隐患）

**修复（6 处改动）**：
- `connect()` 加 `timeout=30 / banner_timeout=30 / auth_timeout=30` + `chan.settimeout(60)`
- `_ensure_connected()` / `_force_reconnect()`：socket 真活探测（不再依赖 `is None`）
- `download()` 重试 ×3 + 指数退避 + 异常分层（传输级→重试，连接级→上抛）
- `.part` 原子下载（先写临时文件再 rename，防半成品被误判为完成）
- 批量下载按交易所分组隔离（单组故障不连坐）
- 扫描错误传播（不完整清单直接 raise）
- **弃用 `sftp.get()`**，改 `sftp.open()` + 顺序 1MB `copyfileobj`（根治 prefetch 死锁）

**干跑验证**：
- 第 1 轮：暴露目录缺失 bug
- 第 2 轮：暴露 prefetch 死锁（settimeout 无效）
- 第 3 轮：暴露 EOF 竞态（32768×N 缓冲区边界卡死）
- 第 4 轮：14/14 成功，280s，unzip -t 全过

**实际效果**：手动触发精准补下 3 个损坏文件（增量逻辑 + 断线重连实战验证）

## 四、过滤手段探索

### 4.1 DD 回撤控制 — ❌ 净负

连续型 + 尾部保险两种变体均测试。结论：后视机制，锁底踏反弹；降 vt 严格优于所有 DD 控制变体。报告 §5.36 附近（未单独立节，结果已记录在子策略手册）。

### 4.2 宏观边际过滤（DXY/VIX/US10Y）— ❌ 边际

信号：20 日边际变化 z-score → tanh，shift(1) 防前视。组合级 + 类别级两种设计。

最优变体（US10Y 组合级）仅 Sharpe +0.05，DXY 过滤净负。根因：宏观冲击先传导进价格/波动/量价，D.1 已前瞻定价。报告 **§5.36**。

### 4.3 P1-B 相关性危机检测器 — ✅ 通过并集成

**信号**：类内 60 日滚动两两相关均值（结构性信号，与 D.1 正交：全样本相关 0.103）

**机制**：阈值门控 `m = 1 − k × max(0, sig−θ) / (1−θ)`

**深度测试（7 项）**：

| 测试 | 结果 |
|------|------|
| 窗口敏感性 (30/60/90/120) | 差异 ±0.02 Sharpe，不敏感 |
| θ×K 精细网格 (36 组合) | Pareto: θ=0.60 K=1.00 → Sharpe +0.12, DD +1.66pp |
| 换手成本 | 反而降低（0.0829→0.0752，年化 0.253%→0.227%） |
| Top5 回撤事件 | 全部改善；2026 最大 +2.16pp |
| filter vs vt 降档（同 Sharpe） | **filter 严格优于 vt 调整**（同 Sharpe 0.93，DD -9.84% vs -9.02%） |
| 对齐池复测 | 不适用（分散化已充分，filter 恶化 DD） |
| D.1 正交性 | 相关 0.103，完全正交可叠加 |

**集成**（commit `e30a6276`）：
- `d_pipeline.py`：`compute_correlation_signals` + `apply_correlation_overlay` + 3 个新参数
- 默认关闭（`correlation_k=0`）；41 资产推荐 θ=0.60, k=1.00
- 219 单测全过

**关键洞察**：无阈值线性版效率极差（全天候均匀拖累）；阈值版只在危机时段介入，效率提升 5 倍。
