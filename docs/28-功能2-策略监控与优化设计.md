# 功能2: 策略监控与优化 - 架构设计

## 一、概述

### 1.1 用户场景

"监控这个策略的样本外表现，如果跑偏了就优化"

### 1.2 核心能力

| 子模块 | 功能 | 技术选型 |
|--------|------|----------|
| 调度层 | 定时/事件驱动的策略执行调度 | APScheduler |
| 监控层 | 策略绩效监控、漂移检测、告警 | KS检验 + scipy |
| 版本管理层 | 策略配置版本控制、变更追踪、回滚 | Git |

### 1.3 实施范围

核心功能优先：调度 + 监控 + 版本管理的核心逻辑，不含UI和告警推送。

## 四、调度层设计

### 4.1 StrategyScheduler

基于APScheduler的策略调度器，支持三种触发方式：

- **cron**: `add_cron_job(name, "0 18 * * 1-5", config_path)` — 每个交易日18:00执行
- **interval**: `add_interval_job(name, interval_minutes=60, config_path)` — 每60分钟执行
- **date**: `add_date_job(name, run_date, config_path)` — 指定时间执行

### 4.2 StrategyRunner

被调度器调用的策略执行器：

1. 加载YAML配置 (ConfigLoader)
2. 执行回测 (ConfigBacktestRunner)
3. 采集绩效指标 (MetricsCollector)
4. 保存运行记录 (StrategyRunRepository)
5. 执行漂移检测 (DriftDetector)
6. 如有异常，生成告警 (Alerter)

## 五、监控层设计

### 5.1 漂移检测算法

#### KS检验 (收益分布漂移)

```python
from scipy.stats import ks_2samp

def detect_ks_drift(current_returns, baseline_returns, threshold=0.05):
    """检测收益率分布是否发生变化"""
    statistic, p_value = ks_2samp(current_returns, baseline_returns)
    if p_value < threshold:
        return DriftAlert(alert_type="ks_test", p_value=p_value)
    return None
```

#### 夏普比率下降检测

```python
def detect_sharpe_drop(current_sharpe, baseline_sharpe, drop_pct=0.3):
    """检测夏普比率是否显著下降"""
    if current_sharpe < baseline_sharpe * (1 - drop_pct):
        return DriftAlert(alert_type="sharpe_drop")
    return None
```

#### 最大回撤超标检测

```python
def detect_drawdown_breach(current_dd, max_allowed_dd):
    """检测最大回撤是否超过阈值"""
    if abs(current_dd) > max_allowed_dd:
        return DriftAlert(alert_type="drawdown_breach")
    return None
```

### 5.2 基线计算

基线指标 = 策略最近252个交易日(1年)的绩效指标均值。

## 六、版本管理层设计

### 6.1 Git版本控制

每个策略对应Git仓库中的一个目录：

```
~/.quantnodes/strategies/
├── dual_ma/
│   ├── .git/
│   ├── dual_ma_v1.0.yaml
│   ├── dual_ma_v1.1.yaml
│   └── dual_ma_current.yaml
├── momentum/
│   └── ...
```

### 6.2 版本保存流程

1. 复制YAML配置到 `strategies/{name}/` 目录
2. `git add` + `git commit -m "version {version}: {description}"`
3. 返回commit hash

### 6.3 版本对比

使用 `difflib` 对比两个YAML配置的差异，输出结构化diff。
