# 22 - 算子扩展机制设计

## 1. 背景

ConfigExecutor 的 OperationConfig dispatch 硬编码了 65 个算子，但 factor_functions registry 有 137 个。用户可能需要使用 registry 中未硬编码的算子，或定义全新的自定义算子。

## 2. 设计目标

| 目标 | 说明 |
|------|------|
| 覆盖全部 registry 算子 | OperationConfig 可直接使用 137 个 registry 算子 |
| 支持用户自定义算子 | 从外部 .py 文件动态加载并注册 |
| 向后兼容 | 现有 YAML 配置无需修改 |
| 明确优先级 | 硬编码 > fallback > custom |

## 3. 架构

```
ConfigExecutor._apply_operator(op)
  │
  ├── 硬编码 dispatch（优先）
  │     ├── _apply_ts_operator(category, input_exprs, params)
  │     ├── _apply_sec_operator(category, input_exprs, params)
  │     ├── _apply_math_operator(category, input_exprs, params)
  │     └── _apply_composite_operator(category, input_exprs, params)
  │
  ├── fallback: get_operator() 从 registry 查找
  │     └── op_func(*input_exprs, **params)
  │
  └── 最终兜底: return input_exprs[0]
```

## 4. 通用 Fallback

在 `_apply_operator()` 的 4 个硬编码 dispatch 之后，增加 fallback：

```python
def _apply_operator(self, op):
    # ... 现有硬编码分支（如果匹配则 return）...

    # fallback: 从 registry 查找
    try:
        from QuantNodes.factor_node.factor_functions import get_operator
        op_func = get_operator(category)
        if op_func is not None:
            return op_func(*input_exprs, **params)
    except Exception:
        pass

    return input_exprs[0]
```

**效果**：`rolling_quantile`、`regress`、`decay_linear` 等未硬编码的 registry 算子可通过 OperationConfig 直接使用。

## 5. Custom Operators 加载

### 5.1 YAML 配置格式

```yaml
# 简单格式（向后兼容，默认分类 point）
validation:
  custom_operators:
    - "/absolute/path/to/my_ops.py"

# 详细格式（推荐，显式指定分类）
validation:
  custom_operators:
    - source: "/absolute/path/to/my_ops.py"
      category: "time_series"
      functions: ["custom_momentum_zscore"]  # 可选，不填则自动发现 custom_* 函数
```

### 5.2 自定义算子文件格式

```python
# /path/to/my_custom_ops.py
import polars as pl

def custom_momentum_zscore(f, window=20, zscore_window=60, **kwargs):
    """自定义动量 Z-Score"""
    momentum = f / f.shift(window) - 1
    return (momentum - momentum.rolling_mean(zscore_window)) / momentum.rolling_std(zscore_window)

def custom_decay_linear(f, window=10, **kwargs):
    """自定义线性衰减"""
    weights = list(range(1, window + 1))
    total = sum(weights)
    return f.rolling_mean(window) * (window / total)
```

### 5.3 加载流程

```python
def _load_custom_operators(self, custom_operators):
    """加载自定义算子"""
    for entry in custom_operators:
        # 解析配置（支持 str 和 dict 两种格式）
        if isinstance(entry, str):
            source_path = entry
            category = "point"
            functions = None
        else:
            source_path = entry["source"]
            category = entry.get("category", "point")
            functions = entry.get("functions")

        # importlib 动态加载
        spec = importlib.util.spec_from_file_location("custom_ops", source_path)
        module = importlib.util.module_from_spec(spec)
        spec.loader.exec_module(module)

        # 注册算子
        for name in dir(module):
            if name.startswith("_"):
                continue
            if functions and name not in functions:
                continue
            if not functions and not name.startswith("custom_"):
                continue

            func = getattr(module, name)
            if callable(func):
                register_operator(category, name=name)(func)
```

### 5.4 分类映射

| YAML category | executor dispatch | registry 分类 |
|---------------|-------------------|---------------|
| `time_series` | `_apply_ts_operator` | `time` |
| `section` | `_apply_sec_operator` | `section` |
| `math` | `_apply_math_operator` | `point` |
| `composite` | `_apply_composite_operator` | `point` / `multi_section` |

Custom 算子注册到 `_OPERATOR_REGISTRY["custom"]`，fallback 通过名称全局查找。

## 6. 优先级规则

1. **硬编码 dispatch 最高**：如果 category 匹配 if/elif 分支，直接返回
2. **Fallback 次之**：从 registry 查找，覆盖 137 个已有算子
3. **Custom 算子**：通过 `register_operator()` 注册到 registry，被 fallback 发现
4. **最终兜底**：返回 `input_exprs[0]`

## 7. 文件变更

| 文件 | 变更 |
|------|------|
| `executor.py` | `_apply_operator()` 增加 fallback；新增 `_load_custom_operators()` |
| `executor.py:run()` | 执行前调用 `_load_custom_operators()` |
| `loader.py:check_coverage()` | 加载 custom_operators 后再检查覆盖度 |

## 8. 测试计划

| 测试场景 | 验证点 |
|----------|--------|
| fallback 使用 registry 算子 | `rolling_quantile` 等未硬编码算子正常工作 |
| custom_operators 加载（简单格式） | str 格式加载，自动发现 `custom_*` 函数 |
| custom_operators 加载（详细格式） | dict 格式，指定 category 和 functions |
| custom_operators 分类映射 | 不同 category 的 custom 算子路由到正确 dispatch |
| 优先级测试 | 同名算子时硬编码优先 |

| 路径不存在时报错 | 优雅错误信息 |
