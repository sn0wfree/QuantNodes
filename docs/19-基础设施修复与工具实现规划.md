## 一、背景与问题

基于三份设计文档（13-Agent系统架构设计、14-Agent实施计划、15-Agent配置文件驱动方案）与当前代码的对比审查，发现以下关键问题：

### 1.1 已完成部分

| 阶段 | 状态 | 说明 |
|------|------|------|
| Phase 1: 核心框架 | ✅ 已完成 | 7 个核心模块、16 个测试文件全部就绪 |
| Phase 2: 工具骨架 | ⚠️ 部分完成 | 6 个工具文件存在，但 4 个是占位符 |
| Config 系统 | ⚠️ 部分实现 | ConfigLoader/ConfigExecutor 可用，但注册表脱节 |

### 1.2 待修复问题

| 问题 | 严重度 | 影响 |
|------|--------|------|
| **双注册表脱节** | 🔴 高 | config/loader.py 有 30 个静态假注册条目，factor_functions.py 有 137 个真实算子，两者完全不互通 |
| **config 位置错误** | 🟡 中 | 设计文档要求 agent/config/，实际在 QuantNodes/config/，agent 工具无法直接导入 |
| **4 个工具是占位符** | 🔴 高 | BacktestTool、StrategyTool、FactorTool、PipelineTool 返回 stub 数据 |
| **命名不一致** | 🟡 中 | config 中声明的 weighted_avg/blend/percentile 在 factor_functions 中不存在 |

### 1.3 双注册表详细对比

```
factor_functions.py (真实注册表)
├── point: 43 个算子 (abs, add, log, pow, weighted_sum, ...)
├── time: 64 个算子 (rolling_mean, ts_corr, expanding_mean, ewm_mean, vwap, ...)
├── section: 16 个算子 (rank, zscore, winsorize, neutralize, ic, ...)
├── multi_section: 14 个算子 (aggr_mean, aggregate, merge, ...)
└── 总计: 137 个算子，含函数引用/签名/文档/参数列表

config/loader.py (假注册表)
├── time_series: 12 个 (ts_mean, ts_std, ts_max, ...)
├── section: 6 个 (rank, zscore, winsorize, ...)
├── math: 7 个 (add, sub, mul, ...)
├── composite: 5 个 (weighted_sum, weighted_avg, blend, ...)
└── 总计: 30 个静态字符串映射，无函数引用
```

**关键差异**：
- 分类体系不兼容（POINT/TIME/SECTION/MULTI_SECTION vs time_series/section/math/composite）
- 假注册表缺少函数引用，无法实际调用
- 假注册表有 3 个不存在的算子（weighted_avg、blend、percentile）

def check_coverage(self, config: StrategyConfig) -> CoverageReport:
    covered = []
    unresolved = []

    # 检查因子定义
    for factor in config.factors:
        if factor.expr:
            covered.append("factor:%s" % factor.name)
        else:
            unresolved.append("factor:%s" % factor.name)

    # 检查算子 - 使用 factor_functions 真实注册表
    all_operators = list_operators()
    for op in config.operations:
        if op.category in all_operators:
            covered.append("op:%s" % op.category)
        else:
            unresolved.append("op:%s" % op.category)

    return CoverageReport(covered=covered, unresolved=unresolved)
```

async def execute(self, description, validate=True, **kwargs):
    from QuantNodes.ai.strategy_gen import StrategyGenerator
    from QuantNodes.ai.sandbox import CodeSandbox

    # 1. 初始化生成器
    # 需要 LLM 客户端配置
    generator = StrategyGenerator(llm_client=None)  # 需要传入 LLM 客户端

    # 2. 生成策略代码
    result = generator.generate(description)

    # 3. 可选验证
    is_valid = False
    errors = []
    if validate and result.code:
        sandbox = CodeSandbox()
        validation = sandbox.validate(result.code)
        is_valid = validation.is_safe
        errors = validation.errors

    return {
        "code": result.code,
        "is_valid": is_valid,
        "errors": errors,
        "warnings": result.warnings if hasattr(result, 'warnings') else [],
        "description": description
    }
```

### C4. PipelineTool（Pipeline 验证工具）

**当前**：仅做语法检查  
**目标**：增强验证，包括安全检查和语义验证

**实现方案**：
```python
async def execute(self, code, **kwargs):
    from QuantNodes.ai.sandbox import CodeSandbox

    result = {
        "is_valid": True,
        "errors": [],
        "warnings": [],
        "nodes": [],
        "security_status": "unknown"
    }

    # 1. 提取代码
    extracted_code = self._extract_code(code)
    if not extracted_code:
        result["is_valid"] = False
        result["errors"].append("No valid code found")
        return result

    # 2. 语法检查
    try:
        compile(extracted_code, '<string>', 'exec')
    except SyntaxError as e:
        result["is_valid"] = False
        result["errors"].append("Syntax error: %s" % str(e))
        return result

    # 3. 安全检查
    sandbox = CodeSandbox()
    validation = sandbox.validate(extracted_code)
    result["security_status"] = "safe" if validation.is_safe else "unsafe"
    if not validation.is_safe:
        result["is_valid"] = False
        result["errors"].extend(validation.errors)

    # 4. 提取节点信息
    result["nodes"] = self._extract_nodes(extracted_code)

    return result
```

**参数**：
- `code` (string, required): QuantNodes Pipeline Python 代码

**输出**：
```json
{
  "is_valid": true,
  "errors": [],
  "warnings": [],
  "nodes": ["MomentumStrategy", "SimulatedBrokerNode"],
  "security_status": "safe"
}
```
