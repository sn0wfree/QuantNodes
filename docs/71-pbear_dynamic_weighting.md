## 3. 为什么动态加权反而更差?

### 根本原因: 策略间高度相关

v7.10, v9macro, v1.0 三策略均源于同一 momentum 信号, 只是执行方式不同:

```
相关性矩阵 (日收益):
           v1.0   v7.10   v9macro
v1.0       1.00    0.85    0.82
v7.10      0.85    1.00    0.94
v9macro    0.82    0.94    1.00
```

**三策略本质上是同一信号的三种执行变体** → 动态切换权重 = 在同一信号的不同变体间轮动, 无法获得真正的风险分散.

### 具体机制

1. **Bull 信号 → 切向 v7.10**: 增加 AnnRet, 但同时增加 vol 和 MaxDD
2. **Bear 信号 → 切向 v1.0**: 降低 vol, 但同时降低 AnnRet
3. **两种方向都不改变 Sharpe**: Sharpe = AnnRet/Vol, 两端同比例缩放

### 信息冗余验证

| Layer | 信号 | 效果 | 结论 |
|-------|------|------|------|
| Layer 1 | v7.10 单策略 | Sharpe 1.238 | 最强单策略 |
| Layer 2 | v7.10 + v9 macro | 无增量 | 信息冗余 |
| Layer 3 | v7.10 + 动态权重 | Sharpe 降 | 权重切换无增量 |
| **Layer 0** | **静态 Vol-parity** | **Sharpe 1.535** | **风险多样性唯一有效** |

## 4. 唯一有效路径: 静态风险权重
