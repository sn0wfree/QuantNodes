## 一、背景与目标

### 需求来源
将序列化能力提升到 BaseNode 层，使**所有节点都支持序列化**，实现：
- ✅ 策略逻辑可持久化保存到文件/数据库
- ✅ 节点 Pipeline 可跨进程/机器传输
- ✅ AI 生成的策略可以序列化保存和重建
- ✅ 只序列化**逻辑配置**，不包含运行时数据

### 核心原则
1. **纯逻辑序列化** - 只保存配置和结构，不保存执行状态
2. **往返一致** - `serialize → deserialize` 结果等价
3. **复用现有框架** - 直接复用 `serialization.py` 的多格式序列化方案
4. **安全第一** - 反序列化使用白名单机制，防止代码注入
5. **递归支持** - 复合节点（Pipeline/IfNode 等）自动递归序列化子节点

## 二、设计决策（已确认）

### 关键决策：接口命名

| 决策项 | 选择 | 理由 |
|--------|------|------|
| 序列化接口 | `serialize()` / `deserialize()` | 语义清晰，与 to_info() 分离 |
| 监控接口 | `to_info()` | 与序列化接口区分 |
| 注册装饰器 | `@serializable` | 替代旧的 `@register_node` |
| 多格式封装 | 独立函数 | 不污染 BaseNode 类 |

### 接口职责划分

| 接口 | 用途 | 触发时机 |
|------|------|---------|
| `serialize()` | 实例方法，保存/重建 | 手动调用 |
| `deserialize()` | 类方法，从配置重建 | 手动调用 |
| `to_info()` | 监控/调试 | 运维系统调用 |

### 序列化 vs 信息导出

| 维度 | `serialize()` | `to_info()` |
|------|--------------|-------------|
| 用途 | 持久化/传输/重建 | 监控/调试 |
| 频率 | 低 | 高 |
| 内容 | type, name, config, 子节点 | + node_id, state, stats |
| 运行时数据 | ❌ 不含 | ✅ 包含 |

## 三、架构设计

### 3.1 Serializable Mixin

```python
# QuantNodes/core/serializable.py

class Serializable(Generic[T]):
    """可序列化对象的 Mixin 基类"""

    @classmethod
    @abstractmethod
    def _from_dict_impl(cls, data: Dict[str, Any]) -> T:
        """子类实现具体反序列化逻辑"""
        pass

    def serialize(self) -> Dict[str, Any]:
        """序列化对象配置"""
        return {
            "type": self.__class__.__name__,
            **self._get_serializable_fields(),
        }

    def _get_serializable_fields(self) -> Dict[str, Any]:
        """子类返回需要序列化的额外字段"""
        return {}

    @classmethod
    def deserialize(cls: Type[T], data: Dict[str, Any]) -> T:
        """从字典反序列化重建对象"""
        if not isinstance(data, dict):
            raise TypeError(f"Expected dict, got {type(data)}")

        type_name = data.get("type")
        if not type_name:
            raise ValueError("Missing 'type' in data")

        target = _SERIALIZABLE_REGISTRY.get(type_name, cls)
        return target._from_dict_impl(data)
```

### 3.2 BaseNode 序列化框架

```python
# 节点类注册表
_SERIALIZABLE_REGISTRY: Dict[str, Type] = {}

def serializable(cls: Type[T]) -> Type[T]:
    """装饰器：注册可序列化类"""
    _SERIALIZABLE_REGISTRY[cls.__name__] = cls
    return cls


@serializable
class BaseNode(QuantNodesBase, Serializable['BaseNode'], ABC, Generic[T, R]):

    def _get_serializable_fields(self) -> Dict[str, Any]:
        """子类扩展：返回需要序列化的额外字段"""
        return {}

    @classmethod
    def _from_dict_impl(cls, data: Dict[str, Any]) -> 'BaseNode':
        """子类实现具体反序列化逻辑"""
        raise NotImplementedError

    def to_info(self) -> Dict[str, Any]:
        """导出运行时信息（用于监控/调试）"""
        return {
            'node_id': self.node_id,
            'name': self.name,
            'class': self.__class__.__name__,
            'state': self.state.value,
            'config': self.config,
            'stats': self.stats.to_dict() if self.stats else None,
        }
```

### 3.3 复合节点序列化示例

**Pipeline**:
```python
@serializable
class Pipeline(BaseNode):

    def _get_serializable_fields(self) -> Dict[str, Any]:
        return {"nodes": [node.serialize() for node in self.nodes]}

    @classmethod
    def _from_dict_impl(cls, data: Dict) -> 'Pipeline':
        nodes = [BaseNode.deserialize(n) for n in data["nodes"]]
        return Pipeline(
            nodes=nodes,
            name=data.get("name"),
            config=data.get("config", {})
        )
```

**IfNode**:
```python
@serializable
class IfNode(BaseNode):

    def _get_serializable_fields(self) -> Dict[str, Any]:
        result = {
            "condition": self.condition.serialize(),
            "true_branch": self.true_branch.serialize(),
        }
        if self.false_branch:
            result["false_branch"] = self.false_branch.serialize()
        return result

    @classmethod
    def _from_dict_impl(cls, data: Dict) -> 'IfNode':
        from QuantNodes.core.expression import Expression

        condition = Expression.deserialize(data["condition"])
        true_branch = BaseNode.deserialize(data["true_branch"])
        false_branch = BaseNode.deserialize(data["false_branch"]) if data.get("false_branch") else None

        return IfNode(
            condition=condition,
            true_branch=true_branch,
            false_branch=false_branch,
            name=data.get("name"),
            config=data.get("config", {})
        )
```

## 五、多格式序列化支持

复用 `serialization.py` 中的现有方案：

```python
# QuantNodes/core/serialization.py

def serialize_node_json(node: BaseNode, indent: int = 2) -> str:
    """JSON 序列化"""
    return json.dumps(node.serialize(), indent=indent, ensure_ascii=False)

def serialize_node_compact(node: BaseNode, compress_level: int = 6) -> bytes:
    """JSON + zlib 压缩序列化"""
    json_bytes = serialize_node_json(node, indent=None).encode('utf-8')
    return zlib.compress(json_bytes, level=compress_level)

def serialize_node_msgpack(node: BaseNode) -> bytes:
    """msgpack 序列化"""
    import msgpack
    return msgpack.packb(node.serialize(), use_bin_type=True)

def deserialize_node_json(data: Union[str, bytes]) -> BaseNode:
    """从 JSON 反序列化"""
    if isinstance(data, bytes):
        data = data.decode('utf-8')
    return BaseNode.deserialize(json.loads(data))

def deserialize_node_compact(data: bytes) -> BaseNode:
    """从紧凑格式反序列化"""
    json_bytes = zlib.decompress(data)
    return deserialize_node_json(json_bytes)

def deserialize_node_msgpack(data: bytes) -> BaseNode:
    """从 msgpack 反序列化"""
    import msgpack
    return BaseNode.deserialize(msgpack.unpackb(data, raw=False))

def deserialize_node_auto(data: Union[str, bytes]) -> BaseNode:
    """自动检测格式并反序列化"""
    if isinstance(data, str):
        return deserialize_node_json(data)

    # 尝试 zlib
    if len(data) >= 2 and data[0:2] == b'x\x9c':
        try:
            return deserialize_node_compact(data)
        except Exception:
            pass

    # 尝试 msgpack
    if data and 0x80 <= data[0] <= 0x8f:
        try:
            return deserialize_node_msgpack(data)
        except Exception:
            pass

    # 尝试 JSON
    return deserialize_node_json(data)
```

### 便捷方法绑定

```python
# 在 BaseNode 类上绑定（可选，方便使用）
```

```python
def serialize_node_encrypted(node: BaseNode, password: str) -> bytes:
    """加密序列化 - 保护敏感策略"""
    plaintext = node.serialize()
    return serialize_encrypted(plaintext, password)

def deserialize_node_encrypted(data: bytes, password: str) -> BaseNode:
```

## 八、使用示例

```python
from QuantNodes.core import Pipeline, IfNode, Cond, BaseNode

# 1. 构建 Pipeline
pipeline = Pipeline([
    FactorComputeNode(),
    IfNode(
        condition=Cond('sharpe') > 1.5,
        true_branch=HighSharpeStrategy(),
        false_branch=LowSharpeStrategy(),
    ),
    BacktestNode()
])

# 2. 序列化
config = pipeline.serialize()
json_str = json.dumps(config, indent=2)

# 3. 反序列化重建
loaded_config = json.loads(json_str)
loaded_pipeline = BaseNode.deserialize(loaded_config)

# 4. 执行（完全等价）
result = loaded_pipeline.execute(input_data)

# 5. 监控用 to_info（不用于重建）
info = pipeline.to_info()
# {'node_id': 'Pipeline_abc123', 'state': 'success', 'stats': {...}, ...}
```
