### 2.2 权重网格 (11 个组合)

#### A. 等权基础
- **Equal 1/3** (1/3 + 1/3 + 1/3)

#### B. v1.0 加重 (防御)
- **v1 重 0.50**: v1=0.50, v9=0.25, v7=0.25
- **v1 重 0.40**: v1=0.40, v9=0.30, v7=0.30
- **v1 重 0.30**: v1=0.30, v9=0.35, v7=0.35
- **v1 重 0.20**: v1=0.20, v9=0.40, v7=0.40
- **v1 重 0.10**: v1=0.10, v9=0.45, v7=0.45

#### C. v7.10 加重 (进攻)
- **v710 重 0.60**: v7=0.60, v1=v9=0.20
- **v710 重 0.70**: v7=0.70, v1=v9=0.15
- **v710 重 0.80**: v7=0.80, v1=v9=0.10
- **v710 重 0.90**: v7=0.90, v1=v9=0.05

#### D. 风险平价 (Vol-parity)
- 倒数波动率加权: `w_i = (target_vol / N) / vol_i`, 归一化 sum=1
- 目标年化 vol 8%, N=3, 每只策略分配 8%/3≈2.67%

### 2.3 月度再平衡

```python
rebal_freq = 'M'  # 月度
rebal_dates = common_dti.to_series().resample('M').last().index
```

月度调仓在调仓日 reset 权重, 中间持有至下次调仓日。**避免过度 turnover 同时保持组合平衡**。

## 6. v1.0 locked 在组合中扮演的角色

### 6.1 关键特质

v1.0 locked 的 Sharpe 1.596 (单) 在 3 策略组合中发挥 4 个作用:
1. **降低回撤**: 52% 权重时, 组合 MaxDD -4.72% (vs 单 v7.10 -14.95%)
2. **稳定 NAV**: 让组合更像"低风险资产+alpha 加成"
3. **修复回撤速度**: 把单 v7.10 的 136 天回撤转移到组合的 136 天 (实际是 v1.0 的 302 天缓解)
4. **风险预算自然化**: v1.0 的低 vol 让权重自适应

### 6.2 实际 vol-parity 权重的含义

```python
volparity_w = {
    'v1.0': 0.66,       # 极低 vol 0.04 → 高权重
    'v9macro': 0.20,    # 中等 vol 0.20 → 中权重
    'v710': 0.15,       # 中等 vol 0.27 → 低权重 (但仍 15%!)
}
```

实际 vol-parity 发现:
- v1.0 的 vol 是 0.04 (极低)
- v9macro vol 0.20 (中等)
- v710 vol 0.27 (较高)
- 因为 v710 vol 高 (15%), v710 的 25% 权重分配降到 15%
- 所以聪明的"风险加权"自然重仓低 vol 策略

## 8. 工程教训

### 8.1 组合策略 vs 单策略的本质

| 视角 | 单策略 (v7.10) | 组合 (Vol-parity) |
|------|-----------------|---------------------|
| 设计目标 | 最大 alpha | 风险调整后 alpha |
| Sharpe | 1.238 | **1.535** |
| 风险 | 14.95% MaxDD, 136 天恢复 | 4.72% MaxDD, 136 天恢复 |
| 适合 | 实验室 / 最大收益 | 实盘 / 风险管理 |

### 8.2 多源组合 vs 单源的对比

之前 docs/69 验证的"v7.10 + Layer 2 叠加"是**信息冗余**, 但本实验"3 单策略组合"是**风险源多样性**, 后者改善 Sharpe 而前者损害。

**关键区别**: 信息叠加 vs 风险组合
- 信息叠加: macro 信号 × 4 → 没有真实独立信息 → 损害
- 风险组合: 不同 strategies → 真正的低相关 → 改善

### 8.3 Vol-parity 的反直觉胜利

直觉: v7.10 是 alpha, 占更多权重更好。
现实: v1.0 占 65% 权重 (因为 vol 极低), 反向提供了稳定性。
这是**风险平价**的自然力量。
