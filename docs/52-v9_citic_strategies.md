## 4 个中信策略实现要点

### 4.1 中信里昂全天候 (All-Weather)

**方法学**: 风险平价 × 增长/通胀象限

```python
# 增长/通胀 → 4 象限
QUADRANT_TILT = {
    ('up', 'down'):   {'broad': 1.30, 'sector': 1.20, 'overseas': 1.10, 'gold': 0.60},
    ('up', 'up'):     {'broad': 1.00, 'sector': 1.15, 'overseas': 1.10, 'gold': 1.10},
    ('down', 'up'):   {'broad': 0.70, 'sector': 0.80, 'overseas': 0.90, 'gold': 1.50},
    ('down', 'down'): {'broad': 0.85, 'sector': 0.80, 'overseas': 0.95, 'gold': 1.30},
}

# 资产分类
CITIC_ETF_CLASSIFICATION = {
    'broad':    ['510300', '510500', '510050', '159915', '588000', '159901'],
    'sector':   [...23 个行业 ETF...],
    'overseas': [...12 个海外/QDII...],
    'gold':     ['518880', '518800', '159985'],
}
```

**结果**: Sharpe 0.348, 年化 5.8%, MaxDD -22.6%

### 4.2 中信大类资产配置 (Macro 5 因子)

**方法学**: 5 宏观因子滚动 z-score → 综合得分 → 战术权重

| 因子 | 方向 | 说明 |
|------|------|------|
| 增长 | + | 宏观增长因子 > 0 → 风险资产偏好 |
| 通胀 | 0 | 排除 (对股/债方向相反) |
| 信贷 | - | 信用利差↑ → 流动性收紧 |
| 汇率 | - | 人民币↑ → 利好股 |
| 利率 | + | 期限利差走阔 → 利好股 |

风险资产占比在 30%~80% 间线性插值.

**结果**: Sharpe 0.249, 年化 4.3%, MaxDD -20.3%

### 4.3 中信多因子选股 (5 因子打分)

**方法学**: 5 因子横截面打分 (类似 BARRA 但用收益类代理)

| 因子 | 方向 | 计算 |
|------|------|------|
| Momentum | + | 过去 52 周累计收益 (skip 4 周) |
| Volatility | - | 26 周 std (低波特质) |
| Quality | + | 26 周 Sharpe = 收益/波动率 |
| Size | - | 4 周均振幅 (proxy, 大盘特质) |
| Value | + | 52-104 周反转 (取负 → 利好反转) |

```python
score = z(mom) - z(vol) + z(qual) - z(size) + z(value)
# 每周选 Top-10 候选, softmax 加权 (候选池 50% 权重)
# 剩余 33 个等权 (底仓)
```

**注**: 严格 BARRA 需要市值/PB/PE/ROE 基本面数据, 本策略用收益代理因子, 实质是风格横截面打分.

**结果**: Sharpe 0.615, 年化 9.0%, MaxDD -18.0% (中信组最优)

## 关键结论

1. **银河方案-动态仓位 仍是 v9 最强策略** (Sharpe 1.23, 远超所有 4 个中信策略)
2. **中信多因子选股** 在 4 个中信策略中最强 (Sharpe 0.62, 年化 9.0%, MaxDD -18.0%)
3. **中信里昂全天候 和 大类资产配置** 仅略强于等权基准, 没产生显著 alpha
4. **中信行业轮动** 表现不及预期, 选股信号太嘈杂, 反而拖累

## 改进方向

1. **多因子选股**: Top-K=10 候选池过小, 可试 K=5, 15, 20
2. **大类资产配置**: 当前 5 因子等权, 可加 IC 加权或主成分降维
3. **行业轮动**: 月频调仓可能更稳定, 加反转/估值辅助
4. **全天候**: 象限切换太频繁 (周频), 可加平滑

## 与 v9 银河归因的关联

Brinson 归因 (见 docs/51) 显示 v9 银河方案-动态仓位的 **71% alpha 来自仓位效应** (而非选股).

本次中信多因子选股策略 (Sharpe 0.62) 仅相当于**纯选股** (固定仓位 100%):
- 银河方案-动态仓位 = 选股 + 仓位
- 多因子选股 ≈ 仅选股
- 缺口 = 仓位贡献

**结论**: 中信策略若叠加动态仓位 (类似 v8/v9 已有的 `pos = (0.7 - 0.5·z_score).clip(0.2, 1.0)`), 预期可提升至 Sharpe 1.0+ 水平. 这是 v10 候选方向.
