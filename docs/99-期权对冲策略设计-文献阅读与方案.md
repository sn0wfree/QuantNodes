## 一、文献清单与核心逻辑

### 1.1 《期权与 CTA 信号融合: 凸性溢价与非线性杠杆》

**核心定理**: 期权跑赢期货的充要条件是 `Gamma > Theta`, 即
标的实际波动幅度 > 1 个隐含波动标准差 (σ_implied).

- 巨幅波动 (>1.5σ): 低 delta 香草期权最优 (凸性爆发)
- 大幅波动 (0.5~1.5σ): 价差期权 (Put Spread) 优于香草和期货
- **固定市值再平衡机制**: 期权市值跌 → 买更多 (低吸), 暴涨 → 卖部分 (高抛).
  数学上等价于凹函数资金管理, 自动对波动率"低买高卖", 长期降低凸性持仓成本

**对方案的意义**:
- 理论支撑 put 尾部保护 (凸性组合)
- 固定市值再平衡 = 降低长期 theta 磨损的机制 (MVP 后延)

### 1.2 《趋势策略的凸性》

**核心结论**: 简单/EMA 趋势策略期望收益 ≈ f(长期已实现方差 − 短期已实现方差).

- 二次项 (趋势信号²) 主导收益增长, 正凸性
- 常数项 = 短期波动率风险溢价 (成本)
- 趋势存在时收益由二次项主导; 无趋势时收益为负 (高换手 + 短期波动损耗)

**对方案的意义**:
- 支持 fut_v1 趋势跟踪的凸性本质 (买入波动)
- 解释趋势策略在震荡市亏损的机制, 非新增强

### 1.3 《基于领先滞后关系的交易策略》

**核心方法**: 用路径签名 / **Levy 面积** 检测资产对的领先-滞后关系.

- 领先-滞后矩阵 (对称/反对称): `L_ij > 0` 表示 i 领先 j
- 领先分数 = 行和; 领先者 = 趋势强的品种
- 板块内配对: 做多滞后者 + 做空领先者 (截面市场中性)

**作者自认不足**:
- 利用领先者信号交易滞后者, 本质是做空趋势
- 策略有尾部风险
- 信号有效性依赖资产池内高相关性

**对方案的意义**:
- 独立的新 CTA 策略线, 与 fut_v1 相关性低, 可作组合分散化来源
- MVP 阶段不纳入, 记为后续候选

### 1.4 《多周期、多资产的响应式协方差矩阵预测》

**核心方法**: EWNW 估计量 + 多衰减因子混合 + 横截面全局波动因子 + PCA 收缩.

- 混合衰减因子 (快/中/慢) → 响应性与稳定性平衡
- 全局波动因子 → 对系统性风险快速同步反应
- PCA 收缩 → 保留主要风险因子, 降低大型矩阵噪声
- 参数估计: 凸优化 (QLIKE / MSE)

**对方案的意义**:
- 组合级风险管理和仓位分配工具, 非直接信号
- 可后续用于 fut_v1 + 对冲层的资金分配

### 1.5 《从脆弱到反脆弱: 大宗商品 VRP》(最重要)

**核心论断**: 大宗商品 VRP 是**偶发性**的 (区别于权益的结构性 VRP).

- 权益 VRP 结构性: 投资者天然做多, 持续买 put 对冲 → 隐含波动率长期高于已实现
- 商品 VRP 偶发性: 与市场**物理缓冲能力** (库存) 绑定

**风险金字塔模型** (类 CDO 分层):
- 底层 (劣后级): **库存** = 时间期权 (跨期价差调整消化供需错配)
- 中层 (中间级): **物流/替代** = 空间期权 + 形式期权
- 顶层 (优先级): **系统性冲击** = VRP 产生来源

**月差结构 = 市场脆弱度温度计**:
- 深度 Backwardation (近月 > 远月): 库存紧张 → 市场脆弱 → VRP 酝酿
- Contango (近月 < 远月): 库存充裕 → 市场相对安全 → VRP 小

**投资应用**:
- 做空 VRP (卖波动): 缓冲充足时 (高库存 / Contango)
- 做多 VRP (买保险): 缓冲将尽时 (极低库存 / 深 Backwardation)

**对方案的意义**:
- **直接挑战"低 IV 买保险"的假设**: 商品 VRP 偶发, 买 put 时机应看市场脆弱度
  (Backwardation), 而非仅 IV 低位
- 月差择时可作为 IV 分位择时的对照信号 → 这正是 A/B 对照的核心动机

## 三、MVP 对冲策略方案 (已确认)

### 3.1 决策 (用户确认)

| 决策 | 选择 |
|------|------|
| 择时信号 | **方案 2**: IV 分位 + 月差 A/B 对照 (timing_mode 参数化) |

| 合约结构 | 纯 Put (单腿虚值尾部保护) |

### 3.2 核心算法 (填入 compute_hedge_targets)

对每个交易日 t、每个净多头品种 p:

```
1. 净多头检测: cta_positions[p] > net_threshold → 候选
2. 合约选择:   select_put(p, t, px, target_delta, min_days, max_days)
3. 择时系数 (timing_mode 对照):
   - 'iv':    iv_coefficient(iv_pct)     → 1.0/0.5/0.0
   - 'basis': basis_coefficient(backwardation_pct) → 深贴水买 / 升水不买
   - 'both':  min(iv_coef, basis_coef)   → 两者均允许才买
   - 'none':  1.0 (无择时基线)
4. 数量: qty = 预算 / (premium × multiplier), 取整手
        预算 = hedge_ratio × 净敞口名义值
5. 展期/到期: 到期结算或到期前 roll_days 天滚动
```

### 3.3 择时信号详细定义

**方案 A — IV 分位** (已实现, iv_coefficient):
- IV 分位 < 30% → 1.0 (全额买, 便宜保险)
- 30%~70%  → 0.5 (减半)
- > 70%    → 0.0 (不买)

**方案 B — 月差/Backwardation** (需新增 basis_coefficient):
- 用 `inter_contract_spread.spread_1_2` (近月 − 次月)
- 正值 = Backwardation (贴水, 市场脆弱 → 买 protect)
- 负值 = Contango (升水, 市场安全 → 不买)
- 构造 rolling 分位 (复用 add_percentile), 深贴水 (分位高) 强化保护

**关键洞察**: 方案 A 与方案 B 方向可能相反 —
深 Backwardation 常伴随高 IV (市场脆弱), 此时 A 不买 (IV 高) 而 B 买 (贴水深).
这正是 A/B 对照的价值: 检验哪种择时更能捕捉尾部风险.

### 3.4 需要新增/修改的文件

1. `hedge_layer.py`: 实现 `compute_hedge_targets` + 新 `basis_coefficient`
   + `HedgeConfig` 加 `timing_mode: 'iv'|'basis'|'both'|'none'`
2. `hedge_data.py` (新): 加载 inter_contract_spread → 逐品种月差面板 + 分位
3. `selector.py`: 暴露 multiplier (当前返回 0.0, 数量计算需从 registry 取乘数)
4. 测试: `test_options_hedge_data.py` (月差面板) + `test_hedge_layer.py`
   (compute_hedge_targets 各分支)

### 3.5 验证指标 (与 fut_v1 基线 A/B)

- NAV / Sharpe / MaxDD / 最差单日 / 期权年化成本 / 对冲收益比
- 关键: 对冲收益 > 权利金成本 (文献 1.5 警告商品 VRP 偶发)
- 覆盖 2022 前期权未上市缺口 (部分品种 RB 2022-12 起) → 对冲覆盖不全需注明

### 3.6 A/B 结果 (2023-01 ~ 2025-12, 727 天, hedge_ratio=0.10)

| mode | Sharpe | AnnRet | MaxDD | 最差单日 | 成本/年 |
|------|--------|--------|-------|---------|--------|
| **baseline** (无对冲) | 1.209 | 0.140 | -0.111 | -4.88% | — |
| none (总是买) | 0.861 | 0.112 | -0.111 | -5.12% | -4.98% |
| iv (IV 分位择时) | 0.926 | 0.117 | -0.108 | -4.54% | -3.36% |
| basis (月差择时) | 1.124 | 0.133 | -0.113 | -5.00% | -2.33% |
| **both (双择时 min)** | **1.147** | 0.135 | -0.113 | -4.66% | **-1.76%** |

**核心发现**:
1. **纯 Put 尾部保护 = 净拖累**: 所有对冲模式 Sharpe < 基线
2. **择时大幅降低成本**: both (1.76%/年) 比 none (4.98%/年) 省 65%
3. **both 最优**: IV 低 + 月差贴水同时满足才买, 最少买入, 最接近基线
4. **iv 模式改善最差单日**: -4.54% vs 基线 -4.88% (唯一改善尾部)
5. **MaxDD 几乎不变**: 对冲未改善最大回撤 (基线 -0.111, both -0.113)

**结论**: 印证文献 1.5 论断 — 商品 VRP 偶发, 买 put 成本 > 保护收益.
CTA 策略本身已具正凸性 (文献 2), 追加 put 对冲在当前参数下不可行.

**后续方向**:
- 固定市值再平衡 (文献 1): 降低 theta 磨损, 可能翻转成本收益比
- Put Spread (文献 1): 卖出更虚值 put 降低净成本
- 更低 hedge_ratio (如 0.05): 降低成本, 测试边际保护效果
- Call 保护净空头: CTA 净空头时的对称保护
