# 91-产业链上下游因子调研

> 调研商品期货产业链上下游关系因子 (利润/比价/传导), 基于现有 DuckDB 数据的可落地性。

## 一、产业链全景 (可落地品种)

### 1. 黑色系 (煤焦矿钢)
```
JM(焦煤) → J(焦炭) → [I(铁矿) + RB(螺纹)/HC(热卷)]
```
- **盘面利润 (RB)**: RB - 1.6×I - 0.5×J (吨钢利润近似)
- **盘面利润 (HC)**: HC - 1.6×I - 0.5×J
- **焦化利润**: J - 1.33×JM

### 2. 能化系
```
SC(原油) → FU/BU(燃料/沥青)
PX → TA(PTA) → PF(短纤)
MA(甲醇) → PP/L/V(烯烃)
C(玉米) → CS(淀粉)
```
- **PTA 加工费**: TA - 0.655×PX
- **短纤利润**: PF - 0.855×TA - 0.13×EG
- **MTO 利润**: PP - 3×MA (甲醇制烯烃)

### 3. 油粕系
```
A(大豆) → M(豆粕) + Y(豆油)
RM(菜粕) → OI(菜油)
```
- **压榨利润**: M×0.78 + Y×0.18 - A
- **菜籽压榨**: OI×0.4 + RM×0.6 - 菜籽价

### 4. 农产品
```
C(玉米)/M(豆粕) → LH(生猪)  饲料成本
C(玉米) → CS(淀粉)
```
- **养殖利润代理**: LH - 3.5×(C×0.7 + M×0.3)

### 5. 有色
```
CU/AL 冶炼 → 下游加工
AU(金) / AG(银)  贵金属比价
```
- **金银比**: AU/AG
- **铜铝比**: CU/AL

## 二、因子类型设计

| 类型 | 定义 | 逻辑 | 数据 |
|---|---|---|---|
| **盘面利润** | 下游 - 上游×系数 | 利润极值回归 (高利润→扩产→回落) | 连续面板 |
| **比价因子** | A/B 比值 z-score | 比价均值回归 / 趋势 | 连续面板 |
| **利润动量** | 利润变化方向 | 利润趋势持续 | 连续面板 |
| **上下游传导** | 上游收益对下游的领先相关性 | 成本传导时滞 | 连续面板 |
