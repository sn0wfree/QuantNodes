# CTA资金分配优化实验报告（2026-09-03）

> 脚本: `scripts/cta_allocation_optimization.py` | 结果: `reports/cta/allocation_optimization.csv`

## 1. 动机

**当前最优组合 (45/5/15/10/10/5/5/5)** 实现了 Sharpe 2.70 / Calmar 4.50 / **MaxDD -2.46%**，但**年化收益仅 11.10%**。

子策略总占比55%，子策略Sharpe加权平均0.46远低于主CTA的2.38，导致**年化收益大幅稀释**（主CTA单独19.00% → 组合11.10%）。

**核心矛盾**: 子策略降低了回撤但也稀释了收益。本报告探索如何在不降低年化的前提下，提高Sharpe和Calmar。

## 5. 关键发现: Sharpe-AnnuRet 权衡

```
Sharpe ↑↑, AnnRet ↓↓: 等权重55%子策略 (当前最优)
Sharpe →, AnnRet ↑: 杠杆+精简子策略 (新推荐)  ✓ 目标
Sharpe ↓, AnnRet ↑↑: 杠杆无子策略 (主CTA+杠杆)
```

**新方案在保持主CTA-Style高Sharpe的同时用杠杆放大年化**——是真正回答用户问题的方案。

## 6. 杠杆成本敏感性

主CTA 1.40倍杠杆意味着40%超额敞口，年化资金成本3%扣除:
- 杠杆1.40 vs 1.00: 年化损失 = 40% × 3% = 1.2% (年化)
- 实际: 新方案年化16.14% vs 主CTA 1.0倍杠杆19.00% 损失2.86pp
- 损失来源: 杠杆成本1.2% + 子策略稀释1.66% = 2.86pp

**杠杆成本可控**——即使资金成本上行至5%（极端），新方案年化仍能保持15%+。

```
子策略: CU溢价TC 31.5% + IH50动40×OI10 13.5%
总资金: 100%, 总敞口: 132%
```

### 7.2 决策建议

| 决策维度 | 选择 |
|---------|------|
| **风险预算优先** (MaxDD<-3%) | 当前最优 45/5/15/10/10/5/5/5 |
| **风险-收益均衡** (Sharpe+AnnRet双高) | **新推荐 杠杆1.40+55%CTA+CU+IH** ⭐ |
| **年化收益优先** (Sharpe足够时) | 主CTA单独 (Sharpe 2.38已足够) |

**主CTA单独**仍然是Sharpe 2.38/Calmar 2.93的高质量策略，**子策略组合的真正价值在于风险预算（MaxDD降低）**，而非Sharpe提升。

**新推荐方案**填补了"高Sharpe + 高年化"组合的空白——同时实现:
- Sharpe接近主CTA单独(2.38 vs 2.38)
- 年化接近主CTA单独(16.14% vs 19.00%)
- MaxDD显著低于主CTA单独(-4.32% vs -6.48%)
- Calmar显著高于主CTA单独(3.74 vs 2.93)
