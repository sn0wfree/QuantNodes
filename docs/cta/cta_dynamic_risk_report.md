## 1. 背景与修正

### 1.1 成本口径修正（重要bug）

e87a0ce0的杠杆扫描把主CTA**全部资金**视为借款扣3%成本（0.55×3%=1.65pp年化），
正确口径只对**借入的超额部分**计息（0.55×(1.5-1)×3%=0.83pp）。

修正后各杠杆方案年化收益整体上移约0.8-1pp，最优配置也发生变化（主CTA占比从55%上移到65-70%的score区间）。

| **自适应子策略权重** (滚动Sharpe减半) | 全面正贡献: Sharpe+0.20, AnnRet+0.9pp | ✅采用（本轮最大惊喜）|

## 2. 动态杠杆机制

```
主CTA滚动60日年化vol:
  vol ≤ 8%  → 杠杆 = 1.5（上限, 用户确认）
  vol ≥ 12% → 杠杆 = 1.0（下限）
  8% < vol < 12% → 线性插值

借款成本 = w_main × (lev_t - 1) × 3% / 252 (逐日计息)
```

自适应子权重机制：
```
子策略滚动60日Sharpe < 全期中位数×0.5 且 < 0 → 权重减半
（ZN/T10y/rbi等低Sharpe子在逆风期自动降权, 恢复后自动加回）
```

## 7. 遗留风险

1. **动态杠杆在低vol+负收益期放大亏损**（2018年-0.29%）——低vol≠正收益，可加"vol低且近20日收益<0时杠杆回1.0"的复合条件（下轮验证）
2. **自适应权重的换手成本**未计入子策略NAV（子策略NAV本身已含成本，但权重切换本身不产生交易）——实际无额外成本 ✓
3. **杠杆资金成本3%假设**需实盘确认
