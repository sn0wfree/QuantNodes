## 2. 动态杠杆机制

```
主CTA滚动60日年化vol:
  vol ≤ 8%  → 杠杆 = 1.5（上限, 用户确认）
  vol ≥ 12% → 杠杆 = 1.0（下限）
  8% < vol < 12% → 线性插值

借款成本 = w_main × (lev_t - 1) × 3% / 252 (逐日计息)
```

自适应子权重机制：
```
子策略滚动60日Sharpe < 全期中位数×0.5 且 < 0 → 权重减半
（ZN/T10y/rbi等低Sharpe子在逆风期自动降权, 恢复后自动加回）
```

## 8. 自适应子权重机制调研（2026-09-03 补充）

> 脚本: `scripts/cta_adaptive_sensitivity.py` | 组件: `scripts/cta_shared/portfolio_tools.py`

### 8.1 机制原因（4项实证）

**① 降权期=逆境，正常期=顺境（逆境识别有效）**

| 子策略 | 降权占比 | 降权期年化 | 正常期年化 |
|--------|---------|-----------|-----------|
| ZN库存 | 31.4% | -10.90% | +10.50% |
| CU溢价TC | 25.6% | -11.26% | +14.44% |
| IH50动40×OI10 | 34.2% | -12.81% | +18.12% |
| T10y OI变化5 | 42.9% | -5.71% | +12.00% |
| rbi_steel | 32.1% | -9.42% | +7.71% |
| jjm_coke | 40.7% | -9.90% | +8.93% |
| ym_oilmeal | 38.4% | -10.65% | +11.06% |

ZN分年降权占比与亏损年份精确吻合（2019年43%降权↔-2.5%、2022年57%↔-3.8%、2023年44%↔-1.5%）。

**② 经济原因**: 子策略α是regime依赖的（单品种单因子），信号失效期有持续性（市场状态切换而非单日噪声），60日滚动Sharpe能捕捉。降权=对信号置信度的贝叶斯式实时更新。ZN/T10y等"间歇性α"策略触发频率最高（38-43%）。

**③ 踏空反弹成本存在但净效应为正**: IH50降权后30日+7.97% vs 正常期+5.87%（V型反弹模式，踏空半仓损失）；T10y降权后+1.70%（正确避损）。净算术：降权期亏损减半的收益 > 踏空反弹的半仓损失。

**④ IS/OOS均匀贡献（非单一regime驱动）**: 逐年贡献差全部为正（8/8年），IS累计+3.38% / OOS累计+3.10%。

### 8.2 参数敏感性（统一实现重跑，替代作废的调研5初版）

| 变体 | Sharpe | AnnRet | MaxDD | Calmar | OOS-Shp |
|------|--------|--------|-------|--------|---------|
| 固定权重（无自适应）| 2.579 | 15.75% | -3.94% | 4.00 | 2.209 |
| 自适应 0.7×w 窗口60 | 2.703 | 16.29% | -3.92% | 4.15 | 2.335 |
| **自适应 0.5×w 窗口60 ★主推** | **2.781** | **16.66%** | -3.91% | 4.26 | 2.414 |
| 自适应 0.5×w 窗口120 | 2.705 | 16.26% | -3.90% | 4.17 | 2.384 |
| 自适应 0.5×w 窗口40 | 2.841 | 17.04% | -3.92% | 4.34 | 2.493 |
| 自适应 0.3×w 窗口60 | 2.855 | 17.02% | -3.90% | 4.37 | 2.489 |

**关键观察**：
- **5/5 自适应变体全部优于固定权重**——跨参数域稳健，机制本身有效而非参数碰巧
- 参数呈**平滑单调梯度**（cut越小越好0.3>0.5>0.7；窗口越短越好40>60>120）——无孤峰，无过拟合迹象
- 激进参数（0.3或窗口40）收益更高但按先验决策**不采纳**（保守0.5+60已确认，防后视选参）

### 8.4 通用组件留存

`scripts/cta_shared/portfolio_tools.py`（可复用）：
- `adaptive_factor(ret, window, cut)` — 单策略自适应权重因子（PIT合规：expanding median只用历史）
- `adaptive_factors(rets, skip_cols)` — 面板版（跳过主策略列）

- `yearly_diff(a, b)` — 两组合逐年差分解

```python
)

```
