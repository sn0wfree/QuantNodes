## 1. 策略间相关性（关键发现）

|  | 主CTA | ZN库存 | CU溢价TC |
|--|------|------|------|
| 主CTA | 1.000 | 0.078 | **0.029** |
| ZN库存 | 0.078 | 1.000 | **-0.068** |
| CU溢价TC | 0.029 | -0.068 | 1.000 |

**关键**：子策略与主CTA天然低相关（0.029-0.078），**ZN与CU轻微负相关**（-0.068）——子策略间本身互补。这是组合优化的理想起点。

## 3. 推荐组合

**80% 主CTA + 5% ZN库存 + 15% CU溢价TC**
- **Sharpe 2.512**（全期最高）
- OOS Sharpe **2.001**（vs 主CTA单独 1.799，+0.20）
- **MaxDD -4.45%**（vs 主CTA单独 -6.48%，**改善31%**）
- Calmar **3.69**（vs 主CTA单独 2.93，**+26%**）
- 年化收益 16.4%（主CTA单独 19.0%，损失 2.6%）

**这是风险预算型组合**：以 2.6% 的年化收益损失换 31% 的MaxDD改善和 26% 的Calmar提升——对实盘资金管理极有价值。

## 4. 注意事项

1. **M经纪持仓被排除**：之前cta_broker_holding.py的OOS Sharpe 0.581存在PIT bug（无shift(1)），修正后Sharpe -0.262，止损归档
2. **子策略资金小**：ZN仅5%, CU仅15%——小资金高分散
3. **未含EC双口径调整**：合并实验用的是final_nav_lump（含EC版，Sharpe 2.53）。剔EC保守口径下Sharpe会略低但MaxDD更好
4. **相关性的稳定性**：ZN×CU=-0.068基于2018-2025历史，未来相关性可能变化（regime shift风险）
5. **OOS验证价值**：最优组合OOS Sharpe 2.001是真正的"未被利用"指标，应作为实盘落地主要参考

## 5. 实盘建议

| 项 | 推荐 |
