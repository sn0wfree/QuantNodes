## 1. 测试背景

此前所有子策略NAV用 close-to-close 收益（信号T日收盘→T+1日收盘建仓），实盘可在T+1日开盘执行。本测试量化两种执行口径差异，**意外审计出两个数据口径伪影子策略**。

## 3. 执行口径测试（真实数据下）

### 3.1 口径定义（严格对齐）

```
close口径: 信号T-2收盘 → T-1收盘建仓 → 持仓[T-1收盘, T收盘]
open口径:  信号T-2收盘 → T-1开盘建仓 → 持仓[T-1开盘, T开盘]
           ret_df = ret_open.shift(1), ret_open[t] = open[t+1]/open[t] - 1
```

### 3.2 执行口径差异（真实口径下）

- **商品期货（有夜盘）**: open vs close 差异 -0.04 ~ +0.16 —— 轻微（夜盘吸收隔夜信息）
- **金融期货（无夜盘）**: T10y -0.03 轻微；IH50 -0.32（但本身伪影应止损）
- 组合层面差异被进一步稀释（R0-R3方案 open vs close 差±0.02）

**结论: open执行（真实执行）在渐进A方案下完全可行**。

## 6. 经验教训

1. **对账PASS≠数据正确**——复刻了同样的错误口径也会PASS；口径审计必须独立于复刻
2. **随机合约拼接的伪影机制**：keep-last跨合约的价差变化被close-to-close收益捕捉，形成虚假动量/OI相关性
3. **夜盘的执行优势**：商品期货open执行损失轻微（夜盘消化隔夜信息），金融期货需单独评估
4. **vol_target_backtest的ret_df参数**：支持close/open双口径回测，已入库（f1463404扩展）
