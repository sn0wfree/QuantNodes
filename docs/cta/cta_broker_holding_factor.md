## 1. 数据源

| 字段 | 含义 |

## 2. 为什么这是最有希望的新α来源

1. **国内独有聪明钱信号**：头部期货公司（中信/国泰君安/东证等）的客户净持仓变化 = 国内机构资金真实方向
2. **日频+PIT极简**：盘后数据次日直接可用（vs CFTC周频+3日滞后、库存日频+1天）
3. **业界验证**：基于头部经纪持仓的"跟单"策略在国内业内真实存在且长期有效
4. **恰好覆盖主CTA核心品种**：CU（有色之王）+ M（农产品之王），流动性最好
5. **信号维度丰富**：头部净持仓水平/变化率、集中度CR5、多空分歧度、散户vs机构差

---

## 3. 因子设计（5维度）

| 因子 | 定义 | 经济逻辑 |
|------|------|---------|
| **F1: 头部净持仓占比** | CR5经纪净持仓/总持仓 的52日z-score | 机构方向（水平） |
| **F2: 头部调仓变化** | CR5经纪净持仓5日变化 的26日z-score | 机构调仓方向（跟单核心） |
| **F3: 持仓集中度** | CR5持仓库容占比 | 高集中度=主力控盘=趋势强 |
| **F4: 多空分歧度** | 前5多头经纪 vs 前5空头经纪 的对冲比 | 机构分歧度→趋势质量 |
| **F5: 散户-机构差** | 尾部经纪净持仓方向 - 头部净持仓方向 | 散户反向指标 |

**合约处理**（Step 1确认）：
- 方案A：按symbol_prefix汇总全合约（品种级总持仓）
- 方案B：只用主力合约行
- 方案C：全合约汇总 + 主力合约单列对比
- 预选：方案A（品种级，与价格信号对齐最简单）

## 4. 方法论（CFTC/库存因子教训固化）

| 步骤 | 内容 | 止损线 |
|------|------|--------|
| Step 1 | 数据探查+合约处理确认 | - |
| Step 2 | 5因子工程（CU/M两品种） | - |
| Step 3 | IC检验+五分位分层（**不做线性IC方向判断**） | - |
| Step 4 | **IS/OOS方向一致性检验**（IS=2020-2022, OOS=2023-2026） | **一致率<60%止损** |
| Step 5 | IS定方向回测（OOS独立） | OOS Sharpe<0.15止损 |
| Step 6 | 与主CTA合并评估（独立资金池） | Sharpe提升<0.05不合并 |

**关键教训（from CFTC负结果）**：
- 线性IC显著≠方向可交易（CU/AU/AG线性IC t=-12~-16但方向IS/OOS翻转33%）
- 五分位分层的方向一致性才是可交易性的真实度量
- 品种×因子对独立评估（不做统一方向假设）
- IS期价差>|5%|才认为方向可靠

## 5. 预期与风险

### 预期
- 因子-品种对（2品种×5因子=10对）中2-3对方向稳健
- OOS Sharpe 0.3-0.6（参照锌库存0.47）
- 与主CTA低相关（基本面/持仓面 vs 技术面）

### 风险
1. **数据仅CU/M两品种**——覆盖度低，只能作为子品种策略（类似锌）
2. **经纪持仓可能反映"跟随者"而非"聪明钱"**——头部经纪的客户结构未知（散户大户多则反指标）
3. **2020起数据**——IS期只有2年，方向判断样本少
4. **合约汇总的语义问题**——跨合约持仓加总可能引入换月噪声（多头移仓=空头减仓的假信号）
5. 2022-2026市场结构变化的时变风险（CFTC已证）
