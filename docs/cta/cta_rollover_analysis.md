# CTA换月建模现状与盲区（2026-09-02）

## 核心发现

**当前回测完全未建模换月冲击（实证确认）**：
- `roll_cost_bps` 配置项存在（默认0）
- `SlippageEngine.load_roll_dates` 从 `main_contract_mapping` 加载换月日
- **但该表数据严重不全** —— 实测只有IF/IC/IM（金融期货），黑色/有色/化工等所有实物品种均空
- 启用roll_cost_bps=5/10bp 实测Sharpe 几乎无变化（2.432/2.430 vs 无2.433），因为换月日清单空 → 0天×cost=0

## 为什么这是盲区：smoothed数据的"未来数据幻觉"

CTA策略回测用 `smoothed_*_daily` 表（back-adjusted连续合约）：
- 原始主合约换月日有跳价（RB实证：73天>2%，部分15%+）
- smoothed已用历史gap**反向修正**未来价格 → 序列平滑、跳价消失
- 策略PnL用 `pos.shift(1) × smoothed_ret` 计算 → **看起来无换月影响**
- 但实盘真实执行：近月平仓 + 远月开仓，承受近远价差（与smoothed修正方向相反）
- **回测PnL与真实PnL的差异 = roll_cost_bps，默认0 = 系统性低估**

## 实证：RB换月跳价

| 指标 | 值 |
|------|-----|
| 主合约大跳价日(>2%) | 73天 (1年内) |
| 跳价幅度 | 2%-17%（多在15日/17日附近，合约到期日） |
| smoothed价格 | 平滑（被回测调整吸收） |

## 当前机制（代码完整，但缺数据）

```python
# cta_slippage.py
def compute(self, product, date, notional, price):
    base = self.model.compute(...)  # 基础滑点
    # 换月成本: 在换月日起 roll_days 天内分摊
    if self.roll_cost_bps > 0 and product in self._roll_dates:
        for roll_date in self._roll_dates[product]:
            if 0 <= (date - roll_date).days < self.roll_days:
                base += abs(notional) * self.roll_cost_bps / 10000 / self.roll_days
                break
    return base
```

- 引擎完整
- 数据缺失：`main_contract_mapping`表只有金融期货

## 对品种PnL贡献的影响评估

### 当前实现的根本局限

```python
roll_daily = abs(notional) * self.roll_cost_bps / 10000 / self.roll_days  # 默认5天
```

**低估真实换月冲击**：
1. **均摊到5天**：真实换月成本应集中在换月日一次性发生，不是均摊
2. **单边only**：真实换月=近月平仓+远月开仓=双倍交易成本
3. **未考虑合约乘数**：换月冲击应与近远月价差×合约乘数成正比（黑色/有色单次换月可达几十-上百元/吨）

### 改进实现：lump-sum一次性冲击模型（2026-09-02）

`SlippageEngine` 新增 `roll_model: 'amortized' | 'lump'`：
- amortized: 换月日起roll_days天内均摊（默认5天，旧行为）
- **lump: 换月日当天一次性扣除 `2 × roll_cost_bps`（近月平+远月开双倍交易）**

ComboConfig加 `roll_model: str = "amortized"` 配置项。

### lump模型实证（按品种校准成本，tv=1.5）

| 模型 | roll_cost | Sharpe | MaxDD | Calmar |
|------|-----------|---------|-------|--------|
| 无roll | 0 | 2.4335 | -5.83% | 3.527 |
| amortized | 10bp | 2.4300 | -5.84% | 3.520 |
| amortized | 50bp | 2.4163 | -5.87% | 3.492 |
| **lump** | **10bp** | **2.0892** | **-6.54%** | **2.904** |
| lump | 20bp | 2.0793 | -6.56% | 2.887 |
| lump | 30bp | 2.0693 | -6.58% | 2.870 |

### 重大发现

**lump vs amortized（同为10bp）**：
- Sharpe 2.43 → **2.09（-0.34）**
- MaxDD -5.84% → **-6.54%（-0.7pp）**
- Calmar 3.52 → **2.90（-0.62）**

**真实换月冲击约是amortized模型的10倍**！原因是amortized均摊到5天×20%时间 = 等效日成本极低，而lump反映真实"换月日单日大冲击"。**之前的amortized回测严重低估了换月成本**。

**lump内部10/20/30bp差距小（-0.02 Sharpe）**——说明单次换月冲击已被10bp充分代表，再加成本只是叠加。
