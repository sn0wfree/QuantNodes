## 1. 研究设计

**假设**：CFTC持仓（managed money投机/producer-merchant商业）是商品α来源，通过国际→国内价格传导，可作为周频子策略。

**架构**（按用户决策）：
- 独立周频子策略（不做日频前向填充）
- 3因子: F1=mm_net_pct z-score(52周), F2=commercial净持仓 z-score, F3=MM-COM spread
- PIT规则: report_date(周二持仓) + 3交易日 = 周五发布可用
- IS(2018-2021)定方向 → OOS(2022-2025)验证

**映射**（10个国际品种→国内）：
```
COMEX GOLD→AU, SILVER→AG, COPPER→CU
CBOT CORN→C, SOYBEANS→A, SOY OIL→Y
ICE SUGAR→SR, COTTON→CF
ICE WTI→SC, NYMEX NATGAS→PG(弱映射)
```
覆盖度: 10/66品种（17%），核心流动性品种。

## 2. 过程中的3个技术bug（已修复）

1. **z-score窗口错位**：在日频ffill面板上用52**天**窗口（应为周频52周）→因子每天微变→换手爆炸(26967x)→成本吞掉全部收益
2. **换手公式错误**：`turnover.sum().mean()×252`跨行求和后再年化→天文数字假象（正确: 日均总换手×252≈65x）
3. **IC方向误导**：线性IC(+0.03~0.05, t=4~16)与分位数分层的真实结构矛盾——CU/AU的F2实为**反向**（低位→+0.43%/5日），AG正向，品种间方向不一致被线性corr平均掩盖

## 5. 负结果根因分析

1. **方向时变**：因子-品种方向在IS/OOS间翻转率33%——CFTC持仓的预测结构在2022年后变化（商品市场资金结构/中国需求周期变化）
2. **传导链噪声**：国际COT→国际价格→国内价格，两跳传导每环节稀释信号
3. **线性IC陷阱**：IC显著(t=4~16)但方向不稳定的典型表现——**IC检验不足以确认可交易性，必须做IS/OOS方向一致性检验**
4. 拥挤度反转类信号对**极端行情敏感**（2020-03/2022-06），sign策略在中间区域磨损
