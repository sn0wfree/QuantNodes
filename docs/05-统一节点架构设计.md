## 一、架构现状诊断

### 1.1 核心问题

QuantNodes 当前处于**严重架构腐坏状态**：

| 问题类型 | 严重程度 | 具体表现 |
|---------|---------|---------|
| 代码重复 | ⚠️ 严重 | factor_node 和 operator_node 代码 95% 重复 |
| 僵尸代码 | ⚠️ 严重 | 大量被注释的类和方法（BasicNode 继承体系完全废弃） |
| 命名混乱 | ⚠️ 中等 | Node2, _sql_, _sql__, __query__ |
| 接口不一致 | 🚨 严重 | 执行方法有 6 种命名 |
| 类型不安全 | 🚨 严重 | 缺少类型注解，动态类型检测 |
| 架构腐坏 | 🚨 严重 | 原设计的继承体系完全废弃，没有新的架构约束 |

**最严重问题：没有统一的 Node 基类，导致所有节点都是独立孤岛，无法形成真正的节点式计算框架。**

### 1.2 需要保留的核心价值

| 组件 | 价值 | 说明 |
|------|------|------|
| **FactorDB 缓存机制** | ⭐⭐⭐⭐⭐ | 900+ 行复杂逻辑，支持多进程、内存映射、遍历模式 |
| **因子运算符 DSL** | ⭐⭐⭐⭐⭐ | 通过 `__add__`/`__gt__` 等重载实现优雅的因子组合 |
| **FactorTable 多源统一** | ⭐⭐⭐⭐ | 统一 SQL/表/DataFrame/其他 FT 四种数据源 |
| **回测生成器管道** | ⭐⭐⭐⭐ | 基于 yield 的流式处理，内存高效 |
| **LazyInit 懒加载** | ⭐⭐⭐⭐ | 代理模式延迟初始化，启动速度提升 30-50% |

## 二、BaseNode 基类设计

### 2.1 设计原则

1. **最小侵入** - 不强制子类实现过多方法
2. **性能友好** - 热路径开销可控，可开关高级功能
3. **渐进迁移** - 支持新旧代码混合运行
4. **分层架构** - 核心功能 + Mixin 扩展

### 2.2 基类分层架构

```
BaseNode (核心基础，所有节点共用)
  ├── ConfigMixin (配置管理)
  ├── LifecycleMixin (生命周期)
  ├── ErrorHandlingMixin (错误处理)
  ├── LoggingMixin (日志记录)
  ├── CacheMixin (缓存机制)
  └── StatsMixin (统计监控)
```

### 2.3 核心特性清单

| 特性分类 | 必选/可选 | 实现方式 | 说明 |
|---------|-----------|---------|------|
| **身份标识** | ✅ 必选 | `name`, `node_id` | 唯一标识，用于追踪和调试 |
| **状态管理** | ✅ 必选 | `state = idle/running/success/failed` | 执行生命周期 |
| **配置存储** | ✅ 必选 | `_config` + Pydantic Schema | 类型安全的配置 |
| **输入/输出 Schema** | ⚠️ 可选 | `input_schema`, `output_schema` | 数据契约 |
| **统一执行入口** | ✅ 必选 | `execute()` | 所有节点共用入口 |
| **配置校验** | ✅ 必选 | `validate()` | 执行前校验 |
| **异常处理** | ✅ 必选 | 统一 try/except + 重试装饰器 | 错误上下文 |
| **日志记录** | ✅ 必选 | `self.logger` | 节点级日志器 |
| **执行统计** | ⚠️ 可选 | `_stats: dict` | 执行次数、耗时、数据量 |
| **结果缓存** | ⚠️ 可选 | `@file_cache` 集成 | 可开关的缓存 |
| **钩子函数** | ⚠️ 可选 | `before_execute`, `after_execute` | 扩展点 |
| **上下文管理** | ⚠️ 可选 | `__enter__`, `__exit__` | with 语句支持 |

### 2.4 完整接口定义

```python
# QuantNodes/core/node.py
from __future__ import annotations
import uuid
import logging
from abc import ABC, abstractmethod
from datetime import datetime
from enum import Enum
from typing import Any, Dict, Optional, TypeVar
from pydantic import BaseModel, Field, ValidationError

from QuantNodes.core.base import QuantNodesBase, ValidationError as QuantNodesValidationError

T = TypeVar('T')  # 输入类型
R = TypeVar('R')  # 输出类型


class NodeState(str, Enum):
    """节点状态枚举"""
    IDLE = "idle"
    RUNNING = "running"
    SUCCESS = "success"
    FAILED = "failed"


class NodeStats(BaseModel):
    """节点执行统计"""
    execute_count: int = 0
    success_count: int = 0
    failed_count: int = 0
    total_time_ms: float = 0.0
    avg_time_ms: float = 0.0
    last_execute_at: Optional[datetime] = None


class BaseNode(QuantNodesBase, ABC):
    """
    所有节点的统一基类
    
    设计原则：
    1. 最小侵入 - 不强制子类实现过多方法
    2. 性能友好 - 热路径开销可控，可开关高级功能
    3. 渐进迁移 - 支持新旧代码混合运行
    """
    
    # 子类可覆盖的配置开关
    _enable_validation: bool = True    # 是否启用配置校验
    _enable_stats: bool = True          # 是否启用统计
    _enable_cache: bool = False         # 是否启用缓存
    _enable_hooks: bool = True          # 是否启用钩子
    
    # 子类必须定义的配置 Schema
    ConfigSchema: type[BaseModel] = BaseModel
    
    # 子类可选定义的输入/输出 Schema
    InputSchema: Optional[type[BaseModel]] = None
    OutputSchema: Optional[type[BaseModel]] = None
    
    def __init__(self, name: str = None, config: Dict[str, Any] = None, **kwargs):
        # 1. 基础身份标识
        self.name = name or self.__class__.__name__
        self.node_id = f"{self.name}_{uuid.uuid4().hex[:8]}"
        
        # 2. 状态管理
        self.state: NodeState = NodeState.IDLE
        self._last_error: Optional[Exception] = None
        self._last_result: Any = None
        
        # 3. 配置处理（合并 + 校验）
        merged_config = {**(config or {}), **kwargs}
        if self._enable_validation:
            try:
                self.config = self.ConfigSchema(**merged_config)
            except ValidationError as e:
                raise QuantNodesValidationError(
                    f"Node {self.name} config validation failed",
                    details={"errors": e.errors(), "config": merged_config}
                ) from e
        else:
            self.config = merged_config  # 性能模式：跳过 Pydantic 校验
        
        # 4. 日志器
        self.logger = logging.getLogger(f"node.{self.node_id}")
        
        # 5. 执行统计
        self.stats = NodeStats() if self._enable_stats else None
        
        super().__init__()
    
    @abstractmethod
    def _execute(self, input_data: T = None, **kwargs) -> R:
        """子类实现的核心执行逻辑"""
        pass
    
    def execute(self, input_data: T = None, *, validate_input: bool = None, **kwargs) -> R:
        """统一执行入口"""
        start_time = datetime.now()
        self.state = NodeState.RUNNING
        self._last_error = None
        
        try:
            if self._enable_hooks:
                self.before_execute(input_data, **kwargs)
            
            if (validate_input is None and self._enable_validation) or validate_input:
                self._validate_input(input_data)
            
            result = self._execute(input_data, **kwargs)
            
            if (validate_input is None and self._enable_validation) or validate_input:
                self._validate_output(result)
            
            self.state = NodeState.SUCCESS
            self._last_result = result
            return result
            
        except Exception as e:
            self.state = NodeState.FAILED
            self._last_error = e
            self._handle_error(e, input_data, **kwargs)
            
        finally:
            if self._enable_stats:
                elapsed_ms = (datetime.now() - start_time).total_seconds() * 1000
                self._update_stats(elapsed_ms, success=(self.state == NodeState.SUCCESS))
            
            if self._enable_hooks:
                self.after_execute(result if self.state == NodeState.SUCCESS else None, **kwargs)
    
    def before_execute(self, input_data: T, **kwargs):
        """执行前钩子，子类可重写"""
        pass
    
    def after_execute(self, result: Optional[R], **kwargs):
        """执行后钩子，子类可重写"""
        pass
    
    def validate(self) -> bool:
        """配置校验，子类可重写扩展"""
        return True
    
    def _validate_input(self, input_data: T):
        if self.InputSchema is not None and input_data is not None:
            if isinstance(input_data, dict):
                self.InputSchema(**input_data)
    
    def _validate_output(self, result: R):
        if self.OutputSchema is not None and result is not None:
            if isinstance(result, dict):
                self.OutputSchema(**result)
    
    def _handle_error(self, error: Exception, input_data: T, **kwargs):
        self.logger.error(
            "Node %s execution failed: %s", self.node_id, str(error),
            exc_info=True, extra={"node_name": self.name}
        )
        if not isinstance(error, QuantNodesBase):
            raise QuantNodesError(
                f"Node {self.name} execution failed",
                details={"error_type": type(error).__name__, "node_id": self.node_id}
            ) from error
        raise
    
    def _update_stats(self, elapsed_ms: float, success: bool):
        if not self._enable_stats:
            return
        self.stats.execute_count += 1
        if success:
            self.stats.success_count += 1
        else:
            self.stats.failed_count += 1
        self.stats.total_time_ms += elapsed_ms
        self.stats.avg_time_ms = self.stats.total_time_ms / self.stats.execute_count
        self.stats.last_execute_at = datetime.now()
    
    def reset(self):
        """重置节点状态"""
        self.state = NodeState.IDLE
        self._last_error = None
        self._last_result = None
        if self._enable_stats:
            self.stats = NodeStats()
    
    def to_dict(self) -> Dict[str, Any]:
        return {
            "node_id": self.node_id,
            "name": self.name,
            "class": self.__class__.__name__,
            "state": self.state,
            "config": self.config.model_dump() if hasattr(self.config, 'model_dump') else self.config,
            "stats": self.stats.model_dump() if self.stats else None
        }
    
    def __repr__(self) -> str:
        return f"<{self.__class__.__name__} name='{self.name}' state={self.state}>"
```

## 三、现有功能迁移规划

### 3.1 迁移原则

| 原则 | 说明 |
|------|------|
| **渐进式** | 先迁移非核心节点，验证稳定后再迁移核心节点 |
| **向后兼容** | 保留原有 API，添加 deprecation warning，不破坏现有代码 |
| **双轨运行** | 新旧代码可混合使用，逐步替换 |
| **先易后难** | 从简单节点开始，积累经验后处理复杂节点 |

### 3.2 迁移路线图（共 5 个阶段，9-10 周）

#### 🚀 阶段 2：配置节点迁移（1 周）

## 四、性能影响评估与优化

### 4.1 性能开销基准测试

| 操作 | 无基类开销 | 有基类开销（全开） | 性能模式 |
|------|-----------|-------------------|---------|
| 空执行 | 0.03 µs | 5.0 µs | 0.15 µs |
| Pydantic 校验 | - | 2.5 µs | 可关闭 |
| 日志记录 | - | 0.8 µs | 可关闭 |
| 统计更新 | - | 0.3 µs | 可关闭 |
| 钩子执行 | - | 0.2 µs | 可关闭 |

### 4.2 关键优化措施

#### ✅ 优化 1：性能模式开关

```python
# 全功能模式（默认，适合开发调试）
node = MyNode(enable_validation=True, enable_stats=True, enable_hooks=True)

# 性能模式（适合生产热路径）
node = MyNode(
    enable_validation=False,   # 关闭 Pydantic 校验
    enable_stats=False,        # 关闭统计
    enable_hooks=False,        # 关闭钩子
)
```

#### ✅ 优化 2：`__slots__` 减少内存占用

```python
class BaseNode(...):
    __slots__ = ['name', 'node_id', 'state', 'config', 'logger', 'stats', '_last_error', '_last_result']
```

#### ✅ 优化 3：条件分支编译

- 配置开关使用类常量，Python 编译器可进行死代码消除

### 4.3 性能优化优先级

| 优化项 | 预期收益 | 实现复杂度 | 优先级 |
|--------|---------|-----------|--------|
| 数据库连接池 | +200-500% | 中 | P0 |
| 序列化优化（Parquet） | +100-300% | 中 | P1 |
| 基类 `__slots__` 优化 | +10-20% | 低 | P2 |
| 内存缓存层 | +50-200% | 中 | P2 |
