# 103. 对角线生命周期期权策略设计 (Diagonal Lifecycle)

> 状态: 设计定稿 (2026-08-16)
> 关联: docs/102 (裸买期权负结论), docs/101 (因子库), docs/99 (期权对冲设计)
> 前置验证: 动态转换严格反弹确认 中位 +17.5% / 胜率 65.7% (35 样本)

## 一、动机

docs/102 与本系列验证确立的物理事实: 中国商品期权**买方 theta 成本系统性高于信号收益**——
裸买 OTM Call (中位 -44%)、Call Spread (中位 -31%)、尾部保护 (MaxDD 反而恶化)、
纯日历价差 (中位 -9.7%) 全部证伪。

唯一有效的买方结构是**严格反弹确认后的动态转换** (中位 +17.5%, 胜率 65.7%):
低权利金建仓 → 反弹确认 → 释放 gamma。

本文将"单次动态转换"扩展为**全生命周期管理**: 用卖近月收 theta 对冲远月持有成本,
用日频 gamma scalping 收割已实现波动, 用远月 OTM 保留尾部不对称收益。

## 二、策略结构 (做多方向, 顶部对称后补)

```
Phase 1 — 底部入场 (loc<0.15 且 fut_v1 空头)
  买 near OTM call (15-40d, strike≈1.00×spot)   ← 高gamma, 捕捉反弹启动
  买 far  OTM call (45-75d, strike≈1.00×spot)   ← 低theta, 保留尾部收益

Phase 2 — 反弹确认 (5日内 标的>入场价×1.002 且 <×1.03)
  卖 near ATM call (同near窗口, strike≈入场spot)  ← short theta/vega
  → far long + near short = 对角线价差
  → near OTM 底仓继续持有 (止盈/到期退出)

Phase 3 — Gamma Scalping (日频)
  每日: 组合 delta = Σ(qty × delta × mult) / equity
  若 |delta| > scalp_threshold → 期货调回 0
  (卖高买低, 日频近似收割凸性)

Phase 4 — 退出
  near 卖腿: 到期前 7 天 roll (平旧卖新) 或信号消失平仓
  far 底仓: 到期前 7 天平仓; 权利金 +50% 止盈
  near OTM 底仓: 权利金 +50% 止盈 / 到期退出
  止损规则 (v2 修正): 止损仅对裸卖腿生效 — 买权腿风险已定义为权利金, 不止损;
    卖腿在有买权保护 (存活买腿手数 ≥ 卖腿手数) 时同样不止损,
    仅当保护消失 (买腿全平/到期) 变为裸卖后才启用 -30% 止损
```

## 三、三腿 P&L 逻辑

| 腿 | 合约 | gamma | vega | theta | 作用 |
|----|------|-------|------|-------|------|
| 底仓 | near OTM long | +高 | +中 | -高 | 反弹启动主收益 |
| 卖腿 | near ATM short | -高 | -中 | +高 | 回收 theta, 对冲底仓衰减 |
| 远仓 | far OTM long | +低 | +高 | -低 | 尾部不对称收益 |

净敞口: theta 接近中性 (卖腿对冲底仓), vega 净多 (远月), gamma 由 scalping 兑现。

## 四、与已验证结论的对照

## 五、实现

- 策略: `QuantNodes/strategy/cta/options/diagonal_lifecycle.py`
  - 状态机: `flat → entered → diagonal → exiting`
  - 持仓: `{product: {legs: [{symbol, qty, kind, entry_px, expiry}]}}`
  - 复用 `reversal_ambush.py` 的 loc 检测 / 内存链选择; `greeks.py` 反解 delta
- 回测: `scripts/diagonal_lifecycle_bt.py`

## 六、验证指标

| 指标 | 目标 | 实际 |
|------|------|------|

## 七、风险

1. 近月卖腿 short gamma: 快速反转亏损 → 组合 delta 日频调整 + 止损
2. 日频 scalping 粒度粗: 错过日内波动 → 阈值参数扫描
3. 流动性: 远月合约成交稀薄 → 只选 volume/OI>0 合约
4. 顶部对称未实现: 下跌波动结构不同, 需单独验证后再加

## 八、实现结果与扫描结论 (2026-08-16)

### 8.1 基础设施

- `scripts/build_option_greeks_cache.py`: 并行 (16核) 全量预计算期权 greeks →
  `data/cache/option_greeks.parquet` (2.43M option-days, 88.8% valid, 94MB, 5.4min)
- `greeks_cache.py`: parquet 全量加载 O(1) 查 (product, symbol, date) → delta/gamma/vega/theta/iv/strike/expiry/spot
- 回测提速: precompute 91s → 74s; 参数扫描变体共享缓存, 不再重复反解
- **关键修正**: parquet 用真实 underlying 合约价算 delta (vs 之前主力连续价),
  使 delta 计算更准确 → Sharpe 1.94 → 2.01

### 8.2 参数扫描结果 (delta 市值口径, fut_v1 Sharpe 2.09)

| 变体 | Sharpe | 结论 |
|------|--------|------|
| delta_notional 15% | **2.07** | 最小敞口最优 |
| delta_notional 30% | 2.01 | |
| delta_notional 50% | 1.90 | 敞口越大越拖累 |
| 30% 单腿 (无 far) | 1.90 | far 腿有帮助 |
| 30% 关 scalping | 2.01 | scalping 中性 |
| 30% far_share 0.3 | 1.99 | |
| 30% far_share 0.7 | 2.02 | far 占比高略优 |

### 8.3 核心结论 (负)

1. **对角线生命周期期权层 alpha 为负且随规模单调放大** — 最好的 delta.15 仍低于基线 (2.07 vs 2.09)
2. **gamma scalping 中性** (有/无均为 2.01): 期货调 delta 不创造收益, 只是换了一种暴露
3. **far 腿微正** (单腿 1.90 → 三腿 2.01): 远月尾部收益真实存在但不足以扭转整体
4. **止损规则修正验证**: 保护性不止损 (sl_exits=0) 后 Sharpe 不变 (1.94-1.96) →
   止损宽度/对象不是拖累来源
5. 与 docs/102 结论完全一致: **中国商品期权买方 theta 成本 > 捕获的 gamma/vega 收益**,
   生命周期管理/scalping/对角线结构均无法逆转

### 8.4 后续方向 (基于负结论)

- 放弃"买入期权增强"路线; 如需期权参与:
  - 卖方路线 (高 IV 卖 spread 收 theta, 正 carry)
  - 或仅作尾部保护对冲 (接受负期望, 用预算限制成本)
