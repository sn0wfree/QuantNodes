# 前端可视化升级与回测历史浏览

> **编号**: 27
> **状态**: 📋 计划中 (未实施)
> **范围**: QuantNodes 2.8.0 → 2.9.0 前端增强
> **参考**: QuantDinger-Vue 设计思路 (Source-Available, 代码自写不复制)
> **依赖**: Vue 3 + Ant Design 4 + ECharts 5 + vue-echarts (现有)

---

## 一、背景

QuantNodes 当前前端功能完整但视觉表现力不足：
- Dashboard 使用原生 `a-statistic`，缺乏趋势可视化
- Backtest ResultView 使用合成数据渲染 equity curve，非真实回测结果
- 无历史回测记录浏览页面 (ConfigEditor 中标记 "coming soon")
- 缺少多因子评分雷达图、排名列表等量化专用可视化组件

借鉴 QuantDinger-Vue 的 ECharts 封装思路（不复制代码），补充 6 个通用可视化组件 + 增强 3 个现有页面。

#### C1: RadarChart.vue

```
Props:
  dimensions: Array<{name: string, value: number, max?: number}>
  score?: number           // 中心总分
  color?: string           // 填充色 (默认 #1890ff)

渲染:
  ECharts radar chart
  - 5 轴 (默认: 技术/基本面/风险/收益/稳定性)
  - 半透明填充 + 边框线
  - 中心显示 score 文字

默认维度 (可覆盖):
  技术分析  75/100
  基本面    60/100
  风险控制  80/100
  收益表现  85/100
  稳定性    70/100
```

#### C2: MiniArea.vue

```
Props:
  data: number[]           // 数据点
  color?: string           // 线色 (默认 #1890ff)
  height?: number          // 高度 (默认 40)

渲染:
  ECharts line chart
  - 无坐标轴, 无 tooltip
  - 渐变填充 (线色 → 透明)
  - 平滑曲线

用途: Dashboard 行情 sparkline, 收益趋势
```

#### C3: MiniBar.vue

```
Props:
  data: number[]           // 数据点
  positiveColor?: string   // 正值色 (默认 #52c41a)
  negativeColor?: string   // 负值色 (默认 #ff4d4f)
  height?: number          // 高度 (默认 40)

渲染:
  ECharts bar chart
  - 无坐标轴, 无 tooltip
  - 正值绿色, 负值红色

用途: Dashboard 成交量, 日收益柱状图
```

#### C4: TrendIndicator.vue

```
Props:
  value: number            // 变化值 (如 15.2 或 -3.1)
  label: string            // 标签 (如 "年化收益")
  prefix?: string          // 前缀 (如 "$")
  suffix?: string          // 后缀 (如 "%")
  decimals?: number        // 小数位 (默认 2)

渲染:
  ↑/↓ 箭头 (正绿/负红) + 数值 + 标签

用途: Dashboard KPI 卡片, Backtest 结果
```

#### C5: RankList.vue

```
Props:
  items: Array<{name: string, value: number, rank?: number}>
  maxItems?: number        // 最多显示条数 (默认 10)
  valueFormatter?: Function // 数值格式化

渲染:
  序号(灰) + 名称 + 横向进度条(ECharts bar) + 数值
  按 value 降序排列

用途: 因子收益排名, 策略 Sharpe 排名
```

#### C6: NumberInfo.vue

```
Props:

  subtitle?: string        // 副标题
  trend?: number           // 趋势值 (正/负, 渲染 TrendIndicator)
  prefix?: string
  suffix?: string

渲染:
  标题(12px 灰) + 数值(24px bold) + 趋势箭头

用途: Dashboard / Backtest Result 统计卡片
```

## 四、后端 API 增强

### 4.1 新增端点

| 端点 | 方法 | 说明 | 返回 |
|------|------|------|------|
| `/backtest/{id}/equity` | GET | 真实 equity_curve | `[{date, equity, benchmark?}]` |
| `/backtest/{id}/trades` | GET | 交易列表 | `[{date, symbol, side, price, quantity, pnl, commission}]` |
| `/backtest/{id}` | DELETE | 删除历史记录 | `{"ok": true}` |

### 4.2 增强端点

**`GET /backtest/history`** 新增查询参数:

| 参数 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `search` | str | "" | 策略名模糊搜索 |
| `min_sharpe` | float | null | 最低 Sharpe 筛选 |
| `sort_by` | str | "created_at" | 排序字段 (created_at/total_return/sharpe_ratio/max_drawdown) |
| `sort_order` | str | "desc" | asc/desc |

### 4.3 数据持久化增强

**当前**: `.agent/backtest_history.jsonl` 仅存储 summary + config_info

**增强**: 每条记录追加存储:
```json
{
  "config_yaml": "...",
  "warnings": [...],
  "errors": [...],
  "output_files": {...}
}
```

**equity_curve 持久化**: 从 `output_files` 中的 equity JSON/parquet 文件读取，不重复存储。
