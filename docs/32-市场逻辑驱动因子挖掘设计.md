# 市场逻辑驱动的因子挖掘设计

> **论文参考**:AlphaLogics: A Market Logic-Driven Multi-Agent System for Scalable and Interpretable Alpha Factor Generation(arXiv 2603.20247)
> **配套项目**:QuantNodes v3.0.0
> **状态**:设计完成,等待分阶段实施
> **文档版本**:v1.0(2026-06-27)

---

## 0. 背景与动机

### 0.1 AlphaLogics 论文核心洞见

论文把**市场逻辑(market logic)**——即因子背后"为什么有效"的可解释假设——当作**显式、可编译、可迭代优化的一等对象**,而不是只优化因子表达式本身。这同时获得"可解释性 + 可扩展性 + 跨周期稳健性"。

### 0.2 三阶段闭环

| 阶段 | 名称 | 作用 |
|------|------|------|
| 1 | Market Logic Mining | 从历史公开因子库(Alpha101/191/158/360)反向抽取市场逻辑,构建初始逻辑库 ℋ_init |
| 2 | Guided Factor Generation(内层循环) | 在固定逻辑 H 下,把 H 编译成可执行约束 Γ(限定变量/算子族/参数范围/符号方向),用 LLM 生成满足 Γ 的因子,回测反馈驱动优化 |
| 3 | Market Logic Generation(外层循环) | 当某条逻辑下的因子不再改进时,聚合该逻辑名下所有因子的回测证据,在**逻辑层面**给出优化方向,生成/重构新逻辑并入逻辑库 |

逻辑表示为 `H = ⟨𝒞, ℬ⟩`,其中:

- `𝒞`:条件谓词的合取/析取,每条谓词 `(variable, op, threshold, weight)`,作用在市场变量上
- `ℬ = (y, d, h)`:行为三元组,分别指定 target(预测目标,如 forward return)、direction(方向 +1/-1)、horizon(持有期/天数)

### 0.3 论文关键实证(作为本项目设计依据)

- **Γ 约束生成 > 自由生成**(Figure 3,3 个 LLM × 2 个市场均成立)
- **逻辑库越大,因子质量单调提升**(Figure 5,1→6 个逻辑)
- **持久化逻辑 > 一次性逻辑**(Table 3,后者随轮次退化,前者稳步提升)
- **逻辑反向重建因子一致性 >92%**(Table 2,验证逻辑抽取的质量)
- **CSI 500 AR=16.72%(IR=1.53),S&P 500 AR=13.75%(IR=1.27)**,显著优于 AlphaAgent 等 SOTA

### 0.4 本项目动机

QuantNodes 已经具备实现上述闭环的全部底层基建,但**缺少"逻辑"层作为一等对象**——目前的因子挖掘流程只在公式层面迭代优化。本设计把 `WikiLogic` 升级为可编译、可优化的市场逻辑对象,在不破坏现有 `AlphaPipeline` 的前提下,把"市场逻辑驱动"作为可选增强接入。

### 4.1 WikiLogic Schema 升级(PR-1)

**目标**:把 `WikiLogic` 从"自由文本逻辑"升级为含结构化字段的可编译对象,完全向后兼容。

**文件**:`QuantNodes/research/wiki.py`(扩展,PR-1 不破坏现有调用方)

**新增字段**:

```python
@dataclass
class LogicPredicates:
    """𝒞: 条件谓词列表"""
    conditions: List[LogicCondition]  # 合取(AND),每个 condition 含 variable/op/threshold/weight
    combinator: str = "AND"  # "AND" | "OR"(仅 AND 实现,OR 留接口)

@dataclass
class LogicCondition:
    """单条谓词 (v, op, θ, w)"""
    variable: str         # 市场变量名(对齐 OperatorVocab 的输入名,如 "close", "volume")
    op: str               # 算子名(对齐 OperatorMetadata.name,如 "ts_corr", "ts_mean")
    threshold: float      # 阈值 θ
    window: Optional[int] = None  # 时序算子的窗口 d
    weight: float = 1.0   # 权重 w(默认 1.0)

@dataclass
class LogicBehavior:
    """ℬ = (y, d, h): 行为三元组"""
    target: str           # "forward_return_1" / "forward_return_5" / "forward_return_20"
    direction: int        # +1(信号方向与目标一致)/ -1(反向)
    horizon: int          # 持有期天数(对应 forward_returns)

@dataclass
class WikiLogicStructured:
    """H_struct: 规范化后的结构化逻辑(可编译)"""
    predicates: LogicPredicates
    behavior: LogicBehavior
    operator_whitelist: Optional[List[str]] = None  # 允许的算子族(None = 全开)
    parameter_ranges: Optional[Dict[str, List[float]]] = None  # {算子名: [min, max]}
    sign_constraint: Optional[int] = None  # +1(整体为正)/ -1(整体为负)/ None(无约束)

@dataclass
class LogicPerformanceEvidence:
    """聚合的 per-logic 回测证据 E^Logic"""
    n_factors_explored: int = 0
    best_ir: float = 0.0
    best_ic: float = 0.0
    best_factor_id: Optional[str] = None
    mean_ir: float = 0.0
    refinement_round: int = 0  # 哪一轮聚合的证据
    timestamp: Optional[str] = None

@dataclass
class WikiLogic:  # 扩展(原字段保留,全部新增字段为可选 + default)
    # === 原有字段(不变)===
    name: str
    content: str
    source: LogicSource
    extracted_formula: Optional[str] = None
    source_detail: Dict[str, str] = field(default_factory=dict)
    related_strategies: List[str] = field(default_factory=list)
    related_factors: List[str] = field(default_factory=list)
    validation_status: str = "pending"
    wiki_page_name: Optional[str] = None
    created_at: Optional[str] = None
    metadata: Dict[str, Any] = field(default_factory=dict)

    # === 新增:结构化字段(PR-1)===
    structured: Optional[WikiLogicStructured] = None  # H_struct(可编译)
    performance_evidence: Optional[LogicPerformanceEvidence] = None  # E^Logic 聚合
    parent_logic: Optional[str] = None  # 衍生自的逻辑名(用于追溯重构链)
    refinement_round: int = 0  # 第几轮外层优化生成/重构
```

### 4.3 Logic→Γ 编译器(PR-2,论文证明收益最大)

**目标**:把 `WikiLogicStructured` 编译为可执行约束 `Γ`,注入到因子生成与校验流程。

**文件**:`QuantNodes/research/quant_alpha/logic_mining/compiler.py`(新建)

**Γ 数据结构**:

```python
@dataclass
class CompiledConstraint:
    """Γ: 编译后的可执行约束"""
    operator_whitelist: Set[str]           # 允许的算子名集合
    operator_blacklist: Set[str] = field(default_factory=set)  # 显式禁止(可选)
    parameter_ranges: Dict[str, Tuple[float, float]] = field(default_factory=dict)
    sign_constraint: Optional[int] = None  # +1 / -1 / None
    forbidden_combinations: List[Tuple[str, ...]] = field(default_factory=list)
    variable_whitelist: Optional[Set[str]] = None  # 允许的市场变量(open/close/volume/...)

    def validate(self, formula: str) -> Tuple[bool, Optional[str]]:
        """校验 formula 是否满足所有约束,返回 (passed, reason)"""

    def render_for_prompt(self) -> str:
        """生成可注入 LLM prompt 的人类可读描述"""
```

**编译规则**(从 `WikiLogicStructured` → `CompiledConstraint`):

| 输入字段 | 编译结果 |
|---------|---------|
| `predicates.conditions[].variable` | → `variable_whitelist`(并入) |
| `predicates.conditions[].op` | → `operator_whitelist`(并入),加入该算子的"必选"语义 |
| `predicates.conditions[].window` | → `parameter_ranges[op] = (window, window)`(固定) 或加入范围 |
| `behavior.direction` | → `sign_constraint = direction` |
| `behavior.horizon` | → 元数据,影响 forward_returns 选择(在评估侧使用) |
| `operator_whitelist`(显式) | → 覆盖默认,作为最终白名单 |
| `parameter_ranges` | → `parameter_ranges`(合并) |

**校验逻辑**:

```python
def validate(self, formula: str) -> Tuple[bool, Optional[str]]:
    # 1. 解析 formula 抽取使用的算子(复用 parser.ALLOWED_OPERATORS + AST 扫描)
    used_ops = extract_operators(formula)
    used_vars = extract_variables(formula)

    # 2. 白名单检查
    for op in used_ops:
        if op not in self.operator_whitelist:
            return False, f"operator '{op}' not in whitelist"

    # 3. 参数范围检查(从 formula 字面量提取数值参数)
    for op, args in parse_op_args(formula):
        if op in self.parameter_ranges:
            for arg in args:
                lo, hi = self.parameter_ranges[op]
                if not (lo <= arg <= hi):
                    return False, f"{op} arg {arg} not in [{lo}, {hi}]"

    # 4. 变量白名单
    if self.variable_whitelist:
        for v in used_vars:
            if v not in self.variable_whitelist:
                return False, f"variable '{v}' not in whitelist"

    # 5. 符号方向(启发式:从字面 -1 因子或外层 sign/sign_neg 推断)
    if self.sign_constraint is not None:
        if not check_sign_hint(formula, self.sign_constraint):
            return False, f"sign_constraint {self.sign_constraint} not satisfied"

    return True, None
```

**Early-stop 算法**(对齐论文 Algorithm 1):

```python
best_metric = -inf
patience_counter = 0
while patience_counter < T_early:
    # 1. idea → formula(受 Γ 约束)
    formulas = generate_and_validate(...)
    # 2. 回测
    evaluations = evaluate(formulas)
    # 3. 取最佳
    current_metric = best(evaluations, key=lambda e: e.metric(inner_loop_objective))
    if current_metric > best_metric:
        best_metric = current_metric
        patience_counter = 0
        collect_logic_evidence(current_metric)
    else:
        patience_counter += 1
    if patience_counter >= T_early:
        break
    # 4. 反馈 → 下一轮 idea
    reflection = reflect(evaluations)
return aggregate_logic_evidence()
```

### 4.5 外层循环 + 持久化(PR-4)

**目标**:当某条逻辑下内层饱和,聚合证据 → 在逻辑层重构/新增 → 入库 → 跨轮持久化复用(论文 Table 3 关键)。

**文件**:

- `QuantNodes/research/quant_alpha/workflow/alpha_logics.py`(新建,外层编排)
- `QuantNodes/research/quant_alpha/logic_mining/generator.py`(新建,2 个 agent)
- `.agent/agents/market-logic-generator.md`(新建)
- `.agent/agents/market-logic-refinement.md`(新建)

**两个外层 Agent**:

| Agent | 输入 | 输出 | 作用 |
|-------|------|------|------|
| `MarketLogicGeneratorAgent` | `ℋ_lib`(当前全部逻辑)+ `H_current` + `H_hist` + `ℰ_hist`(evidence 历史) | 新 `H_new` | 在初始轮只基于 `ℋ_init` 发散生成;后续轮基于 `ℋ_lib` + 历史证据做有方向的生成/重构 |
| `MarketLogicRefinementDirectionAgent` | `H_current` + `ℋ_hist` + `ℰ_hist` + `fb^Logic_hist` | 逻辑层反馈 `fb^Logic` | 综合所有该逻辑名下因子的回测表现,识别"逻辑过宽/过窄/与市场结构错配"的部分,给出重构方向 |

**外层循环**(对齐论文 Algorithm 2):

```python
class AlphaLogicsWorkflow:
    def __init__(self, config: AlphaLogicsConfig, ...): ...

    def run(self) -> AlphaLogicsResult:
        lib = self.wiki.list_logics()  # ℋ_init
        h_current = self.generator.generate(lib, history=[], evidence=[])  # 首轮
        lib.append(h_current)

        h_hist = [h_current]
        e_hist = []  # ℰ_hist
        fb_hist = []  # fb^Logic_hist
        h_best = h_current
        e_best = None

        for t in range(config.max_outer_rounds):
            # === 内层 ===
            inner = AlphaGptWorkflow(config=self._inner_config(h_current))
            inner_result = inner.run()
            e_logic = self._aggregate_evidence(inner_result)  # LogicPerformanceEvidence
            e_hist.append(e_logic)

            # === 反馈 ===
            fb = self.refinement_agent.run(h_current, h_hist, e_hist, fb_hist)
            fb_hist.append(fb)

            # === 选最优 ===
            if e_best is None or e_logic.best_ir > e_best.best_ir:
                h_best = h_current
                e_best = e_logic
                # 持久化到 Wiki(跨轮复用)
                self.wiki.update_logic_evidence(h_best.name, e_best)

            # === 生成下一条 ===
            h_new = self.generator.generate(
                lib, h_current, h_hist, e_hist, fb_hist
            )
            h_hist.append(h_new)
            lib.append(h_new)
            h_current = h_new

        return AlphaLogicsResult(best_logic=h_best, best_evidence=e_best, library=lib)
```

**持久化**(论文 Table 3 关键):

- 每轮 `h_best` 与 `e_best` 通过 `WikiFactorProxy.update_logic_evidence` 写回 Wiki Logic 页
- 后续轮 `MarketLogicGeneratorAgent` 从 `ℋ_lib` 读取历史逻辑与 evidence,实现"持久化复用"
- 跑完一轮完整外层后,`best_factor_id`(该逻辑下最佳因子)关联到对应 `WikiFactor`

## 5. 数据流与接口契约

### 5.1 内层循环(对齐论文 Algorithm 1)

```
Input:
  H: WikiLogic(固定)
  D_train, D_val(数据切分)
  J: 标量目标(默认 IR)
  T_early: early-stop 阈值

Output:
  E^Logic: LogicPerformanceEvidence
  R*_val: 最佳 validation 指标

Flow:
  H_struct = normalize(H)             # L2FC-Agent: WikiLogic → WikiLogicStructured
  Γ = compile_to_constraint(H_struct) # LogicToFinanceConstraintAgent

  c = 0; R* = None; fb_factor = None
  while c < T_early:
    F = formula_translator(Γ | fb_factor)   # 受 Γ 约束
    F = gamma_validate(F)                    # 违规丢弃
    (R_train, R_val) = backtest(F; D_train, D_val)
    if R* is None or J(R_val) > J(R*):
      R* = R_val; c = 0
      fb_factor = factor_feedback(H_struct, F, R_val)  # 跨候选对比
    else:
      c += 1
  E^Logic = aggregate_evidence(evaluations)
  return E^Logic, R*
```

### 5.2 外层循环(对齐论文 Algorithm 2)

```
Input:
  ℋ_init: 初始逻辑库(从 Logic Mining 或 Wiki 读取)
  D_train, D_val
  T: max outer rounds
  J: 标量目标(同内层)

Output:
  H*: 最优逻辑

Flow:
  ℋ_lib = ℋ_init
  H_current = generator(ℋ_lib)
  ℋ_lib.append(H_current)
  H_hist = [H_current]; ℰ_hist = []; fb_hist = []
  H_best = H_current; ℰ_best = None; t = 0
  while t < T:
    (E^Logic, R*) = inner_loop(H_current; D_train, D_val)
    ℰ_hist.append(E^Logic)
    fb_logic = refinement_agent(H_current, H_hist, ℰ_hist, fb_hist)
    fb_hist.append(fb_logic)
    if ℰ_best is None or J(R*) > J(ℰ_best):
      H_best = H_current; ℰ_best = R*
      wiki.update_logic_evidence(H_best.name, ℰ_best)  # 持久化
    H_new = generator(ℋ_lib, H_current, H_hist, ℰ_hist, fb_hist)
    H_hist.append(H_new)
    ℋ_lib.append(H_new)
    H_current = H_new; t += 1
  return H* = H_best
```

## 8. 风险与范围边界

### 8.1 风险

| 风险 | 应对 |
|------|------|
| LLM 调用成本与延迟 | 默认 mock;真实 LLM 仅在 `LLM_PROVIDER` 环境变量显式设置时启用 |
