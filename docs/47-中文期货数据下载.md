# 中文期货/期权日线下载器

一键下载中国全部 6 家期货交易所的日线数据，写入本地 Parquet + ClickHouse。

## 交易所覆盖

| 交易所 | 代码 | 产品数 | 主力连续 | 数据来源 |
|---|---|---|---|---|
| 中国金融期货交易所 | CFFEX | IF/IC/IH/TF/TS/IM + IO/HO 期权 | 6 个股指/国债期货 | CFFEX 官网 ZIP + AKShare |
| 上海期货交易所 | SHFE | cu/al/zn/pb/ni/sn/au/ag/rb/wr/hc/bu/fu/sp/ru 等 | 16 个商品期货 | SHFE JSON+XLS |
| 大连商品交易所 | DCE | a/b/c/m/y/p/pp/l/v/eb/eg/pg/j/jm/i 等 | 17 个商品期货 | AKShare Sina 主力连续 (DCE 官网反爬) |
| 郑州商品交易所 | CZCE | CF/SR/TA/MA/RM/OI/PF/SA/UR/FG/AP/CJ/ZC 等 | 23 个商品期货 | AKShare |
| 上海国际能源交易中心 | INE | sc/lu/nr/bc | 4 个商品期货 | AKShare |
| 广州期货交易所 | GFEX | si/lh/carbon | 3 个商品期货 | AKShare |

## 安装

```bash
pip install 'quantnodes[futures-cn]'
# 或直接:
pip install akshare>=1.15,<2 requests pandas
```

## 用法

```bash
# 下载全部交易所主力连续 (约 88 个合约)
python scripts/download_chinese_futures.py --main-only

# 指定交易所 + 全量模式
python scripts/download_chinese_futures.py --exchanges CFFEX SHFE --mode full

# 只下载 CFFEX + 不自写 ClickHouse
python scripts/download_chinese_futures.py --exchanges CFFEX --no-clickhouse

# 测试接口可用性 (不下数据)
python scripts/download_chinese_futures.py --test-auth

# 预览计划 (不下载)
python scripts/download_chinese_futures.py --dry-run
```

### CLI 参数

| 参数 | 说明 | 默认 |
|---|---|---|
| `--exchanges` | 目标交易所 (空格分隔) | 全部 6 家 |
| `--mode full` | 全量重下 | incremental |
| `--main-only` | 只下载主力连续合约 | — |
| `--no-main` | 跳过主力连续合约 | — |
| `--no-parquet` | 不写 Parquet | — |
| `--no-clickhouse` | 不写 ClickHouse | — |
| `--rate-min / --rate-max` | 限速范围 (秒/请求) | 3 / 5 |
| `--dry-run` | 预览计划 | — |
| `--test-auth` | 测试接口可用性 | — |

## 数据架构

### 输出目录

```
data/chinese_futures/
├── main/              # 主力连续合约 Parquet (product0.parquet)
│   └── CFFEX/IF/IF0.parquet
├── daily/             # 具体合约日线 Parquet
│   └── CFFEX/IF/IF2409.parquet
├── _meta/             # 元数据 (下载范围、增量状态)
└── _log/              # 下载日志
```

### ClickHouse Schema (可选)

5 张表: `fut_instruments` / `fut_daily_kline` / `fut_main_contract_mapping` / `fut_trading_calendar` / `fut_download_log`

> **注意**: 默认 CH 用户 `data` 只有 SELECT 权限。如需开启 CH 写入，请管理员执行：
> ```sql
> GRANT CREATE, INSERT ON quote.* TO data;
> ```

### Parquet 列

| 列 | 类型 | 说明 |
|---|---|---|
| `exchange` | str | 交易所代码 |
| `product_id` | str | 产品代码 (如 IF) |
| `symbol` | str | 合约代码 (如 IF2409) |
| `full_symbol` | str | 全局唯一代码 (如 CFFEX.IF2409) |
| `trade_date` | date | 交易日 |
| `open/high/low/close` | float | 价格 |
| `settle/pre_settle/pre_close` | float | 结算价 |
| `volume` | int | 成交量 |
| `open_interest` | int | 持仓量 |
| `amount` | float | 成交金额 |
| `delta` | float | 期权 Delta (仅期权合约) |
| `source` | str | 数据来源 (cffex/shfe/akshare) |

## 数据来源说明

### CFFEX (优先级最高)
- 官方月度 ZIP: `http://www.cffex.com.cn/sj/historysj/{YYYYMM}/zip/{YYYYMM}.zip`
- 含所有 CFFEX 品种 (IF/IC/IH/TF/TS/IM 期货 + IO/HO 期权)
- GBK 编码 CSV, 每交易日一个文件, 含 Delta 列
- 无鉴权, 需限速

### SHFE
- 月度 XLS 文件: `https://www.shfe.com.cn/reports/tradedata/datadownload/download.json`
- 年度 ZIP -> 月度 XLS (含中文/英文双表头)
- 无鉴权

### AKShare (备份 + 主力连续)
- `get_futures_daily(exchange, symbol)` — 具体合约日线
- `futures_zh_daily_sina(symbol="IF0")` — 主力连续合约
- **DCE** 具体合约日线不可用 (AKShare 被反爬 412)
- 主力连续共 82 个 (product_id + "0") 可用

### 限速策略
- 每域名 3-5 秒间隔 (可调)
- 429 时指数退避 (1s → 2s → 4s)
- User-Agent 轮换
