### 1.6 实盘笔记: 四阶段仓位管理

笔记描述的策略:
1. **趋势初期**: 买OTM call + spread, 平仓盈利期货 → 保收益+增gamma
2. **趋势中期**: 加大期权、减期货, 期货抗theta → delta恒定/可控
3. **高VIX**: 加put对冲, 控制delta, 实值期权roll → 风险控制
4. **风险时**: 优先平仓期货 → 快速减仓

**与VRP Router的关系**: 我们只做了"建仓→持有→平仓", 没有"趋势中期加仓"和"高VIX加保护"。

## 二、验证方向定义

### 方向A: 卖方 + Delta 对冲

**假设**: 裸卖方左尾-18%是因为无delta对冲; 加对冲后左尾可控, theta收入变为净收益。
**验证方法**:
- 卖call spread的同时, 用期货对冲delta暴露
- 对冲频率: 每日(或delta超阈值)
- 对比: 裸卖 vs delta对冲版, 看MaxDD改善和Sharpe变化

### 方向B: 波动率见顶回落卖方时机

**假设**: VRP高但还在上升时卖方不划算; 等VRP开始回落再卖(降波利润)。
**验证方法**:
- 计算VRP的变化率(dVRP/dt)
- VRP高(>0.7) 且 开始回落(dVRP<0) → 卖方
- 对比: 高VRP立即卖 vs 高VRP且回落再卖

### 方向C: 超跌 + 波动率见顶回落确认

**假设**: 超跌时波动率通常暴涨, 等波动率见顶回落再买call, 窗口更精准。
**验证方法**:
- 超跌(mom20<0) + VRP高位(>0.6) + VRP开始回落 → 买call spread
- 对比: 超跌无确认 vs 超跌+波动率见顶确认

### 方向D: T±N 事件统计框架

**假设**: 特定事件(国庆/政策)前后价格有统计规律, 可设计事件驱动策略。
**验证方法**:
- 已有国庆窗口数据(2021+65%, 2024+61%, 2023无效)
- 扩展: 统计连续3日下跌后T+1~T+20分布, 找右侧入场点

### 方向E: Gamma-Vega 联合窗口

**假设**: 大跌时gamma和vega同时放大, 此时买入期权收益最丰厚。
**验证方法**:
- 识别"gamma高 + vega高"窗口(如大跌后)
- 对比该窗口买入call spread的收益 vs 全样本

## 五、分步建仓验证 (2026-08-16, 修正早前误判)

### 背景
早前模拟将所有批次用平均成本统一在 T+7 平仓(模拟 bug), 误判"分步建仓无效"。
修正为**每批次独立建仓/独立持有/独立平仓**后, 结论反转。

### 严谨验证结果 (卖 put spread, 连续3日跌+VRP>0.5, GOOD品种 I/AG/CU/SR/TA/RU/M)

| 方案 | 中位 | 均值 | 胜率 |
|------|------|------|------|
| A: 一次性 (T日全仓, 持7日) | +38.0% | +2.8% | 66.9% |
| **B: 跌时加仓 (T日1/3 + T+1继续跌加1/3 + T+2继续跌加1/3)** | **+44.4%** | **+11.5%** | **70.8%** |
| C: 时间固定 (T+1/T+2 各1/3) | +36.9% | +6.7% | 65.9% |
| D: 反弹加仓 (T+反弹才加) | +28.3% | -1.6% | 62.3% |

### 持有期 × 建仓方式

| 持有 | 一次性中位/胜率 | 跌时加仓中位/胜率 | 提升 |
|------|-----------------|-------------------|------|
| 3日 | +21.5%/63.8% | +28.5%/69.9% | +7.0%/+6.1pp |
| 5日 | +31.5%/66.4% | +36.6%/71.2% | +5.1%/+4.8pp |
| 7日 | +38.0%/66.9% | +44.4%/70.8% | +6.4%/+3.9pp |
| 10日 | +46.2%/68.8% | +54.7%/72.8% | +8.5%/+4.0pp |

### 为什么跌时加仓有效

1. **卖 put spread 盈利 = 市场不再下跌/IV回落**
2. 跌时加仓 = 在 put 价格更高(恐慌加剧)时卖出更多 → **平均入场价格更好**
3. 每次"继续跌"意味着更深超卖 → 反弹概率更高 → 加仓批次胜率更高
4. 批次分布: 52% 只建1批, 26% 建2批, 21% 建3批 (真正加仓占47%)

### 反直觉: 反弹加仓最差

- 反弹时加仓 = put 价格已回落 → 平均入场价格更差 → 胜率最低(62.3%)
- 与"追涨"同理: 卖方应在恐慌高潮(价格最高)时卖出, 而非恐慌消退后

### 落地规则

```
Gamma-Vega 卖方信号 (分步建仓版):
  触发: 连续3日跌 + VRP分位>0.5 + 品种∈{I,AG,CU,SR,TA,RU,M}
  建仓: T日 1/3 仓位; T+1继续跌加 1/3; T+2继续跌加 1/3
  持有: 每批次独立持有 7日 后平仓
  结构: 卖 ATM put spread (ATM - OTM 0.88)
  结果: 中位+44%, 胜率71%, 均值+11.5%
```

### 分步建仓 vs 一次性: 最终结论

- 分步(跌时加仓) **优于** 一次性: 中位+44% vs +38%, 胜率71% vs 67%, 均值转正(+11.5%)
- 前提是**每批次独立核算** (不能用平均成本统一平仓)
- 加仓条件 = 继续下跌 (非反弹), 与买方追涨逻辑相反

### 组合层面验证 (2026-08-16)

独立信号(中位+44%)与组合叠加结果矛盾:

| delta 市值 | 组合 Sharpe | MaxDD | 说明 |
|------------|------------|-------|------|
| 0.10 | 2.06 | -9.2% | 仍低于基线 2.09 |
| 0.15 | 2.03 | -9.2% | |
| 0.20 | 2.00 | **-9.7%** | |
| 0.30 | **1.94** | **-11.5%** | 越加越差 |

**根本原因**:
1. **方向冲突**: fut_v1 是趋势策略, 连续大跌后通常持空头; GammaVegaSeller 卖 put spread 是"市场不再跌"偏置 → 与 fut_v1 空头互相抵消
2. **左尾风险**: 组合层面卖 put spread 在极端行情(跳空/单边续跌)的亏损, 抵消大部分胜率优势
3. **摩擦成本**: 每批次独立建仓/平仓(9460笔), 手续费侵蚀

**最终结论**: 
- 分步建仓(跌时加仓)在**独立信号层面**确实优于一次性(+44% vs +38%)
- 但**作为 fut_v1 叠加层, 任何卖方结构都不可行** — 方向冲突 + 左尾
- 这印证 docs/105 §3.3 + docs/106 结论: 中国商品期权卖方只能独立运作, 不能叠加趋势策略

### 六、裸卖 OTM put + delta 管理 (2026-08-16, 最优方案)

**策略逻辑**:
- 触发: 连续3日跌 + VRP>0.5 + good_products
- 开仓: 一次性裸卖 OTM put (|delta|~0.3, strike 1.05×spot)
- delta 管控: delta 市值超 15% NAV 时, 买 ATM call 降敞口 → 逐步变 spread
- 持有: 到期 (卖权吃时间价值), 但加 30% 止损控左尾

**组合回测结果 (fut_v1 + 本策略)**:

| delta | Sharpe | AnnRet | MaxDD | Calmar | hedge次数 | stops |
|-------|--------|--------|-------|--------|----------|-------|
| 0.10 | 2.21 | 24.7% | -9.2% | 2.69 | 7 | 120 |
| 0.15 | 2.24 | 25.3% | -9.2% | 2.75 | 142 | 120 |
| **0.25** | **2.33** | **27.0%** | **-9.8%** | **2.77** | 228 | 120 |
| 0.35 | 2.34 | 28.3% | -11.8% | 2.41 | 229 | 120 |

**最优: delta=0.25, Sharpe 2.33 (+0.24 vs 基线, +0.16 vs VRP Router)**

关键要素:
1. **裸卖 OTM put (|delta|<0.3)**: 享受高 IV 恐慌溢价, theta 收入
2. **delta cap 15%**: 买权降敞口, 防止过度暴露
3. **持有到期**: 卖权吃时间价值, 但止损控左尾
4. **一次性开仓**: 简单有效, 不需要分步

组合 Sharpe 2.33 = 基线 2.09 + 本策略贡献 +0.24 → **本次系列研究最优结果**
