# 95. CTA 多因子策略规格与杠杆分析

> 状态: 定稿 (2026-08-12)

## 一、策略概述

多因子 CTA 策略: 106 因子库 → 77 个方向信号因子 → 7 模块 → 因子级
TV-PR 学权重 → 模块级 inv_vol 聚合 → 信号动量过滤 → 波动率目标仓位
→ 单一资金池回测.

**基准配置** (推荐):
```python
FactorModuleComboStrategy(config=ComboConfig(
    aggregation="tvpr",            # 组内: 因子级 expanding TV-PR 学权重
    module_weighting="inv_vol",    # 组间: 模块滚动波动率倒数加权
    momentum_filter_window=60,     # 信号动量过滤: 组合信号 60 日均 < 0 → 空仓
    momentum_filter_coef=0.0,
    target_vol=0.15,               # 目标年化波动率 (1x 杠杆)
    max_leverage=3.0,              # vol_target 权重上限
    leverage_hard_cap=0.0,         # 组合总杠杆硬上限 (0=关闭)
))
```

## 二、架构

```
品种池: 72 个有交易量品种 (日均量 ≥ 1 万手, 静态固定, 产业链配方全覆盖)
   │ load_continuous_main (OHLCV+OI)
   ▼
7 模块 (77 因子, 去重后):
   趋势动量 22 / 均值回归 15 / 量能资金流 24 / 事件日历 6
   / 期限基差 2 / 宏观 3 / 产业链 5
   │ 组内聚合 (aggregation):
   │   equal   等权平均 Σsig/n ∈ [-1,1]
   │   inv_vol 滚动信号波动率倒数加权
   │   regression 滚动 OLS 学权重
   │   tvpr    expanding TV-PR 学时变权重 (λ_tv=0.5, λ_l1=0) ★推荐
   ▼
组合层 (module_weighting):
   fixed   固定权重 (默认等权 1/7)
   inv_vol 模块滚动波动率倒数加权 ★推荐
   │ 信号动量过滤 (momentum_filter_window=60): 组合信号 60 日均 < 0 → 空仓
   ▼
执行层:
   sign → vol_target_positions (target_vol, vol_lookback=20, max_leverage)
   → 市场级波动危机过滤 VolRiskFilter (全市场 HV z>1 → ×0.5)
   → 杠杆硬限 (leverage_hard_cap, 可选)

   → 方向变化才调仓 → run_cta_backtest (单一资金池 200 万)
```

## 三、关键机制

### 3.1 组内 TV-PR (因子级)

- X (T,N,K): 组内因子信号面板; Y (T,N): 品种未来 1 日收益
- β_t = expanding TV-PR (ADMM): min Σ(r-Xβ)² + λ_tv Σ|Δβ| + λ_l1 Σ|β|
- 模块信号 = Σ_k β_t,k × X_t,i,k; β 正负自由 (负 β = 因子信号反用)
- λ_tv=0.5 (β 平滑); λ_l1=0 (组内稀疏实验 0.01-0.05 均劣, 全保留)
- 无前视: expanding 窗口, 每 21 天更新, 测试验证前段 β 一致性

### 3.2 组间 inv_vol

- 模块信号滚动 252 天 std 的倒数 → 逐日归一化权重 (和=1)
- 无前视 (rolling), 前 252 天等权 fallback

### 3.3 信号动量过滤 (极端风险核心)

- 组合信号 (未 sign) 过去 N 日均值 < 0 → 该品种空仓 (系数 momentum_filter_coef)
- 窗口 30-120 全优于 baseline, 60 最优 (docs/94 §10.7)
- 2022 商品回撤 -18.7% → -3.8% (关键效果)

### 3.4 杠杆硬限 (leverage_hard_cap)

- 问题: max_leverage=3 只 clip vol_target 权重, 实际组合总杠杆
  (gross/equity) 可超 3 倍 (手数取整 + 等分资金 + 多品种叠加)
- 方案: 两遍法迭代 — 第一遍回测拿 NAV → 逐日杠杆 → 权重等比缩放
  → 手数 floor 缩放兜底 → 重跑, 直至 max 杠杆 ≤ cap
- 效果: cap=3.0 时 max 3.2 (价格跳空余量), p95 2.77 完全合规

## 四、业绩表现 (72 品种, 2018-2025, 单一资金池 200 万)

### 4.1 杠杆分析 (用户问询)

| 配置 | Sharpe | AnnRet | Vol | MaxDD | Calmar | OOS* | 杠杆中位 | p95 | max |
|---|---|---|---|---|---|---|---|---|---|
| 1x (target_vol=0.15, 无硬限) | 1.813 | 0.131 | 0.072 | -0.106 | 1.234 | 1.471 | 2.10 | 2.76 | 3.36 |
| 2x (target_vol=0.30, 无硬限) | 1.740 | 0.209 | 0.120 | -0.115 | 1.814 | 1.564 | 2.12 | 3.30 | **5.20** |
| **2x + 硬限 3.0** | **1.830** | **0.196** | **0.107** | -0.141 | 1.388 | 1.241 | 1.96 | 2.77 | **3.21** |

*OOS = 2022-2025 段 Sharpe (全样本 NAV 切段统计).

**结论**:
1. **2 倍杠杆 (target_vol=0.30) 收益显著提升**: AnnRet 0.131 → 0.209
   (+60%), Vol 0.072 → 0.107, Sharpe 保持 1.74-1.83
2. **无硬限时杠杆可超 3 倍 (max 5.20)** — max_leverage 参数不是总杠杆硬限
3. **加硬限 cap=3.0 后 max 3.21** (p95 2.77 合规), Sharpe 反而最高 (1.830),
   但 MaxDD -0.141 略深于无硬限 (-0.115) — 高杠杆日被削减的取舍
4. Calmar 对比: 无硬限 2x 最高 (1.814), 硬限后 1.388 (回撤略深)

**推荐**: 2 倍杠杆 + 硬限 3.0 (Sharpe 最高且杠杆合规);
若追求 Calmar 可接受无硬限 2x 或 1x (Calmar 1.23).

### 4.2 基准 1x 完整指标

- 换手率: 年化 3.52 倍 (低换手, 方向变化才调仓)
- 成本: 1bp 拖累 39% 收益; 10bp 拖累 392% (敏感性见 docs/94 §10.7)
- 尾部: VaR95 -0.67%, CVaR95 -1.06%, 最差单日 -2.58% (2025-04-07)
- 最长回撤 531 天 (2022 为主)
