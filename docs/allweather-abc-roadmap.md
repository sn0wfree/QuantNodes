## 二、三个方向

### A. 落地达标版（收益优先）

**A1. csi_1000 工具化**
- 主选：**512100（中证1000ETF）**——2017-01 上市，全历史，无杠杆
- 备选：IM0 期货（2022-07 上市，有杠杆/基差）——仅作后期替代说明

**A2. 融资/杠杆成本建模**（所有后续实验的基础）
- 问题本质：gross 1.3-2.1x 的成本不能一概而论
  - ETF 腿：超配需融资（两融 ~5-6%）
  - 期货腿：天然杠杆（保证金 ~15%），成本 = 保证金占用机会成本（回购 ~2%），**非全额名义**
- 实现两口径：
  - 简单版：`borrow = (gross−1).clip(0) × r_repo`
  - 结构化版：ETF 超配按名义 × r_etf；期货腿按名义 × margin_ratio(0.15) × r_repo
- 引擎参数（默认关闭，向后兼容）：`financing_rate` / `futures_margin_ratio`

**A3. 达标版净收益确认** + NAV 导出 + 报告

### B. 提升资产池（Sharpe 之路）

**B1. 候选资产扩池**（akshare 拉取 + 审计）
候选 ETF：512100 / 510500 / 588000 / 159949 / 511090 / 511260 / 518880 / 159985 / 159980 / 513030 / 513520
（按上市日期筛选，保留历史充分的）

**B2. 数据质量审计**（复用 `data_audit.py` 5 Phase 框架）

**B3. 候选池设计（4 个对照）**

| 池 | 构成 | 假设 |
|----|------|------|
| P0 参照 | 对齐池 11 资产（§5.30 口径） | 基准 |
| P1 对齐+补充 | P0 + 512100 + 510500 + 588000 + 海外 | 15-16 资产，商品 <10% |
| P2 宽基核心 | 宽基(300/500/1000/创业板/科创50) × 海外(纳指/标普/日经/德国) × 债券(t/tf/ts/30年) × 黄金 × 少量商品(cu/sc/m) | 均衡型 |
| P3 41资产降商品 | 不换资产，**class_erc 层压缩商品类预算上限** | 配置层改良 |

**B4. 对照评估**（含阶段1成本口径）：Sharpe / MaxDD / Calmar / N_eff / 类别风险贡献 / 分段

### C. P1-B 生产决策

- 关键问题：**新池更分散 → P1-B 可能不适用**（对齐池已证不适用）
- 在最优池上重跑 P1-B 网格（θ ∈ {0.60,0.65,0.70} × k ∈ {0.6,0.8,1.0}）
- 产出：**按池给出启用建议**（可能结论：仅商品占比高的池启用）

## 四、已定决策（含默认假设）

| # | 问题 | 决策 | 理由 |
|---|------|------|------|
| 1 | 融资口径 | **两版都算**（结构化为主，简单版对照披露） | 诚实对比，避免口径争议 |
| 2 | 融资利率 | ETF 超配 5%（两融）/ 期货保证金 2%（回购） | 保守且贴近实际 |
| 3 | 池方向 | P0-P3 全做对照 | 实验成本低，避免过早收窄 |
| 4 | 历史长度 | 接受缩短（动态池：面板自然渐进纳入） | min_obs=60 门槛已支持 |
| 5 | P1-B 默认值 | **保持默认关闭**；阶段4 按池验证后决定 | 不预设结论，数据说话 |

## 五、验收标准

1. **A**：达标版净收益（含融资成本）数字确认，NAV 文件导出，csi_1000 有可交易工具

3. **C**：P1-B 在最终池上的启用建议（含触发频率/换手增量）

## 六、风险与回退

| 风险 | 对策 |
|------|------|
| 新 ETF 历史太短（多数 2019+） | 动态池（渐进纳入）；对照时统一口径披露 |
| 池扩充后 HRP 退化（N 过大） | N_eff 监测；必要时限制资产数 ≤20 |
| 融资建模改动破坏现有行为 | 新参数默认关闭（rate=0）；219 单测回归 |
| csi_1000 工具历史不足 | 512100（2017+）为主，IM 仅作补充说明 |
| 阶段3 未找到更优池 | 回退：P3 配置层改良（不换资产）作为保底方案 |
