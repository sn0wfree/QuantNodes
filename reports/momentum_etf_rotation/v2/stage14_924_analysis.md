---

## 1. 背景

### 1.1 924事件

2024年9月24日，国务院新闻发布会宣布一揽子刺激政策：
- 降准0.5个百分点
- 降低存量房贷利率
- 统一房贷最低首付比例至15%
- 创设货币政策工具支持股票市场

**市场反应**：
- 上证指数9月24日当天涨幅 **+4.15%**
- 创业板指9月24日当天涨幅 **+5.54%**
- 9月整月涨幅：沪深300 **+28.87%**，创业板 **+48.11%**

### 1.2 策略目标

动量ETF轮动策略（v1.0 hybrid+VT+Cost配置）：
- Calmar 1.60（vs CICC 0.76）
- 最大回撤 -3.93%（vs CICC -18.78%）
- 年化收益 6.28%

## 5. 根因分析

### 5.1 动量信号偏好海外/商品

**2024年8月动量得分**：
- S&P500 (513500): +0.5128
- 纳指100 (513300): +0.4504
- 纳指 (513100): +0.4001
- 黄金 (518880): +0.1370
- 沪深300 (510300): **-0.2242**

**原因**：
- 2020-2024年，海外ETF涨幅远超A股（+168.6% vs +67.9%）
- 黄金持续上涨（+134.9%），动量信号持续偏好
- A股2024年8月前表现平淡，动量得分为负

### 5.2 A股宽基上限约束

**DiversificationCaps规则**：
```python
a_share_broad: int = 2      # A股宽基每类最多2只
a_share_sector: int = 2     # A股行业每类最多2只
a_share_total: int = 3      # A股宽基+行业总共最多3只
```

**影响**：
- 即使9月底动量信号切换到A股，策略最多只能配3只A股ETF
- 无法捕捉创业板+48%的涨幅（最多配1只创业板ETF）

### 5.3 月度调仓频率

**调仓机制**：
- 每月最后一个交易日调仓
- 924是9月24日（周三）
- 最早调仓日：9月30日（周一）

**影响**：
- 924当天无法调仓
- 9月25-27日的涨幅（约+15%）无法捕捉
- 9月30日调仓时，A股已上涨约+25%

### 5.4 动量信号滞后

**90天回看窗口**：
- 924前90天（6月26日-9月23日）A股表现平淡
- 924当天涨幅（+4.69%）在90天窗口中占比仅约5%
- 需要持续上涨才能改变动量得分

**信号响应时间**：
- 924当天：得分仍为负（-0.31）
- 924后3天（9月27日）：上证50转正（+0.13）
- 9月底：A股得分转正（+0.22）
- 10月底：创业板得分最高（+0.39）

## 8. 结论

### 8.1 核心发现

1. **策略结构性低配A股**：A股宽基仅2.68%，远低于HS300的100%
2. **动量信号偏好海外/商品**：2020-2024年海外涨幅远超A股
3. **A股宽基上限限制**：最多3只，无法捕捉创业板+48%涨幅
4. **月度调仓频率**：924是月中事件，最早9月30日调仓
5. **动量信号滞后**：90天窗口需要时间反映924涨幅

### 8.2 错过的涨幅

- **理论最大涨幅**：21.06%（9月底全配A股宽基）
- **策略实际涨幅**：2.19%
- **差距**：18.87%
- **原因分解**：A股低配60% + 上限约束25% + 调仓频率10% + 信号滞后5%

### 8.3 优化方向

| 优先级 | 优化内容 | 预期效果 | 风险 |
|--------|----------|----------|------|
| 高 | 事件检测机制 | 捕捉+3-5% | 误触发 |
| 中 | A股动量加速器 | 提高A股配置 | 增加波动 |
| 低 | 调仓频率优化 | 更快响应 | 交易成本 |

### 8.4 风险提示

1. **过拟合风险**：针对924优化可能破坏其他时期表现
2. **交易成本增加**：事件检测可能增加调仓频率
3. **分散化损失**：提高A股配置可能增加集中度风险
4. **未来不可预测**：924是政策驱动事件，难以提前预判
