**结论**:
- v4A 和 v4B 相关性 0.78-0.90, **同涨同跌**, 没有真正的分散价值

### 1.2 v4 的 3 年"沉船期" (2021-09 到 2024-09)

|------|------|------|-----------|---------|

**3 年沉船期, v3 只掉 14% (短且快恢复), v4A 掉 49% (3 年深套)**

**根因**:
- A 股 2021-09 开始风格切换: 成长/创业板崩盘, 红利/低波抗跌
- v4A 的 60d 动量选股在风格切换时反应慢

## 三、5 个 Meta-Strategy 候选方案

### 方案 1: Regime-Based Allocator (RBA)

**核心思想**: HMM 检测 regime, 按 regime 切换权重

```python
def meta_rba(regime):
    if regime == 0:  # bear
        return {'v3': 0.9, 'v4A': 0.05, 'v4B': 0.05, 'cash': 0.0}
    elif regime == 1:  # transition
        return {'v3': 0.8, 'v4A': 0.1, 'v4B': 0.1, 'cash': 0.0}
    else:  # bull
        return {'v3': 0.5, 'v4A': 0.25, 'v4B': 0.25, 'cash': 0.0}
```

**优点**: 理论清晰, 学术依据强
**缺点**: HMM 95% 都在 transition, RBA 退化为 80/15/5 静态
**预期**: **失效**, 不推荐

### 方案 2: Volatility Targeting (VT) ⭐ 最直接

**核心思想**: 监测 v4 实际波动率, 超阈值就降仓

```python
def meta_vt(vol_60d, target_vol=0.12):
    scale = min(1.0, target_vol / vol_60d)
    return {'v3': 0.5 * scale, 'v4A': 0.3 * scale, 'v4B': 0.2 * scale, 'cash': 1 - scale}
```

**优点**: 直接解决 -49% DD, 数学严密
**缺点**: 风险: 熊市降仓后, 反弹踏空
**预期**: **高潜力, 推荐**

### 方案 3: Rolling 60d Sharpe Allocator (RSA)

**核心思想**: 每个子策略看过去 60d Sharpe, 加权

```python
def meta_rsa(sharpes):
    # sharpes = {'v3': 0.8, 'v4A': 1.2, 'v4B': 0.5}
    pos_sharpe = {k: max(0, s) for k, s in sharpes.items()}
    total = sum(pos_sharpe.values())
    if total == 0:
        return {'v3': 0.5, 'v4A': 0.25, 'v4B': 0.25, 'cash': 0.0}
    return {k: v/total for k, v in pos_sharpe.items()}
```

**优点**: 完全数据驱动, 自适应
**缺点**: 反应慢 (60d lag), 容易追涨杀跌
**预期**: **中等, 待验证**

### 方案 4: 趋势确认 Allocator (TCA) ⭐⭐ 最实用

**核心思想**: 只在 v4 自身趋势向上时增持 v4

```python
def meta_tca(nav_v4, ma_60):
    if nav_v4 > ma_60:
        # v4 趋势向上, 增持
        return {'v3': 0.5, 'v4A': 0.25, 'v4B': 0.25, 'cash': 0.0}
    else:
        # v4 趋势向下, 切回 v3
        return {'v3': 0.85, 'v4A': 0.075, 'v4B': 0.075, 'cash': 0.0}
```

**优点**: 简单, 直接避开 v4 沉船期
**缺点**: 60d MA 滞后, 2021-09 顶部才切换
**预期**: **高潜力, 推荐**

### 方案 5: 综合 (TCA + VT + base mix)

```python
def meta_combo(nav_v4, ma_60_v4, vol_60d, target_vol=0.12):
    # 1. TCA: 趋势过滤
    if nav_v4 < ma_60_v4:
        base = {'v3': 0.85, 'v4A': 0.075, 'v4B': 0.075}
    else:
        base = {'v3': 0.5, 'v4A': 0.25, 'v4B': 0.25}
    
    # 2. VT: 波动率缩放
    scale = min(1.0, target_vol / vol_60d)
    return {k: v * scale for k, v in base.items()} | {'cash': 1 - scale}
```

**优点**: 三重保险 (趋势 + 波动 + 基底), 鲁棒
**缺点**: 复杂, 需要 60d MA + 60d vol
**预期**: **最高潜力, 最推荐**

## 七、风险与缓解

1. **趋势切换滞后**: 60d MA 滞后, 2021-09 顶部才切换
   - 缓解: 加 5d 价格 vs 20d MA 的快速触发器

2. **VT 反弹踏空**: 熊市降仓后, V 型反弹错过
   - 缓解: VT 缓出, 用 20d 阶梯式降低, 不是瞬间清仓

3. **过拟合**: 参数可能过拟合 A 股 2018-2026
   - 缓解: 简化参数, 用 2-3 个核心参数; 留 2026 H2 验证

4. **交易成本**: TCA 频繁切换可能增加换手率
   - 缓解: 加 5% 切换阈值缓冲, 加周频切换限制

## 八、结论

**v4 单独跑不行**, 但作为 v3 的"卫星"策略, **通过 TCA + VT 调节**, 可以:
- 在反弹年贡献 +5-15% 收益 (vs v3)
- 在下跌/震荡年不拖累 (切到 v3 主导)
- DD 控制在 v3 的 1.2x 以内 (-15% vs -14%)
