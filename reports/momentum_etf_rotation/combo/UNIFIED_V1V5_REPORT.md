## 3. 关键发现

### 3.1 v1.0 locked 是 OOS 最佳 (Calmar 1.79)

**全期对比**:
- v0.0 baseline: 8.77% ann, 10.60% vol, Calmar 0.539
- v0.1 +VT: 4.33% ann, 4.92% vol, Calmar 0.642
- v0.2 +TF: 7.80% ann, 9.87% vol, Calmar 0.479
- **v1.0 locked: 4.96% ann, 4.42% vol, Calmar 0.853** ⭐

**OOS 对比 (2022-2026)**:
- v1.0 locked OOS Calmar **1.791**, Sharpe **1.51**, DD -1.94%
- 是 OOS 唯一 Sharper > 1.5 的策略

**演进贡献度** (OOS Calmar):
| 阶段 | OOS Calmar | 增量 |
|------|-----------|------|
| v0.0 baseline | 0.484 | 起点 |
| + Stage 9-B (TF) | 0.509 | +0.025 |
| + Stage 9-C (VT) | 0.492 | (与 TF 互斥) |
| **+ Stage 12A (hybrid)** | **1.791** | **+1.30** ⭐⭐⭐ |

**Stage 12A 斜率×R² 混合动量是最大突破**, 单点贡献 +1.30 OOS Calmar。

### 3.2 v5 量价是年化最高 (14.45%)

v5 用 11 量价因子 (华西论文), 单独运行时年化最高, OOS Calmar 0.488 属于中等。**最高收益 ≠ 最佳风险调整**。

**v5 vs v3 vs v1.0 三角关系**:
- v5: 高收益 (14.45%), 中等 Calmar (0.745)
- v3: 均衡 (6.01%, 0.443)
- v1.0: 低收益 (4.96%), 极高 Calmar (0.853 OOS 1.79)

**v3 与 v5 相关性 0.65** (中等), **v1.0 与 v5 相关性 0.42** (最低) → v1.0 + v5 是分散度最高的组合。

### 3.3 v4 因子择时在 52 池统一时间中表现差

- v4 style: 5.08% ann, OOS Calmar 0.131
- v4 factor: 1.97% ann, OOS Calmar **-0.085** (亏损)

**根因** (见前文 v4 诊断):
1. 5 风格组高度相关 (0.86-0.90) → 选股≈噪声
2. IC 84-94% 低于阈值 → 因子择时≈随机
3. Regime 70% 时间退化为单因子 (value only)

### 3.4 成本对长期 Calmar 影响小 (< 0.04)

| 策略 | 口径 A Calmar | 口径 B Calmar | 差值 |
|------|-------------|-------------|------|
| v0.0 baseline | 0.484 | 0.490 | -0.006 |
| v0.1 +VT | 0.492 | 0.496 | -0.005 |
| v1.0 locked | 1.791 | 1.813 | -0.022 |
| v3 | 0.778 | 0.778 | 0.000 |
| v5 | 0.488 | 0.488 | 0.000 |

月调仓 + 5bp 成本对长期表现影响很小, 主要成本来自调仓日的换手率 (v1.0 OOS 1.791→1.813 损失最大)。

### 3.5 推荐组合 (口径 A)

| 组合 | 全期 Calmar | OOS Calmar | OOS Sharpe |
|------|------------|------------|-----------|
| v1.0 80% + v5 20% | **1.079** | **0.886** | 0.84 |

```
v0.0 baseline (Stage 8) — Calmar 0.484
  │ + Stage 9-B 趋势过滤 (HS300 MA200, bear=0.7)  → 0.509
  │ + Stage 9-C 波动率目标 (target=0.15)         → 0.492
  │ + Stage 12A 斜率×R² 混合动量                 → 1.791 ⭐⭐⭐
  v1.0 locked
  │ + Stage 16A 多策略组合 (动量+反转+行业轮动)   → v3 OOS 0.778
  │ + Stage 18 风格轮动                          → v4 style 0.131 (失败)
  │ + Stage 18 IC 因子择时                       → v4 factor -0.085 (失败)
  │ + Stage 22 11 量价因子 (华西论文)             → v5 OOS 0.488
  v5 量价
```

## 6. 结论

1. **v1.0 locked 是 OOS 最佳** (Calmar 1.79, Sharpe 1.51, DD -1.94%) — 适合风险厌恶型实盘
2. **v3 + v5 是攻守兼备的进攻组合** (Calmar 0.71-0.84 OOS)
3. **v1.0 + v5 20-30% 是综合最优** (利用低相关性 0.42)
4. **v4 因子择时/风格轮动在统一池中失败** — IC 信号噪声过大
5. **Stage 12A (斜率×R²) 是 v1.0 突破关键** — 单点贡献 +1.30 OOS Calmar
6. **未来方向**:
   - 把 v3 多策略框架扩展, 加 v5 量价作为第 4 子策略
   - v1.0 的 VT 框架可包装 v5 (波动率目标对 v5 也有帮助)
   - v4 因子可改为多窗口 v5 量价因子的 regime 检测 (而非 IC 驱动)
