## 二、最优方案: v9 组合评分

### 2.1 信号逻辑

```
总分 = 50 (中性基线)
     + GDP动量↑: +15分 (经济增长改善)
     + CPI动量↓: +15分 (通胀压力缓解)
     + VIX低:    +15分 (市场平静)
     + 信用改善: +10分 (信用利差收窄)
     + 期限正常: +10分 (利率环境健康)
     + 趋势上行: +10分 (价格动量)

总分 > 60 → 满仓 (100%)
总分 40-60 → 半仓 (50%)
总分 < 40 → 空仓 (0%)
```

| 空仓 (<40) | 22.6% | 213周 | 多因子共振看空 |

## 三、为什么这个方案有效?

### 3.1 信号构成分析

| 因子 | 权重 | 响应速度 | 作用 |
|------|------|---------|------|
| GDP动量 | ±15 | 慢 (月频) | 长期方向 |
| CPI动量 | ∓15 | 慢 (月频) | 通胀环境 |
| VIX | +15 | **快 (日频)** | 市场情绪 |
| 信用利差 | ±10 | **快 (周频)** | 信用风险 |
| 期限利差 | +10 | 中 | 利率环境 |
| 价格趋势 | +10 | **快 (周频)** | 动量确认 |

**关键**: VIX + 信用利差 + 价格趋势 是**快速指标**, 能在市场转折时及时响应。GDP/CPI 是**慢速指标**, 提供长期方向确认。

### 3.2 与之前方案的对比

| 方案 | 问题 | 解决方案 |
|------|------|---------|
| 纯HP滤波趋势 | 信号滞后1-2年 | 改用13周动量 |
| 纯GDP/CPI | 信号太慢 | 加入VIX/信用/趋势 |
| 纯VIX | 缺乏宏观方向 | 加入GDP/CPI动量 |
| 纯趋势跟踪 | MaxDD太大 | 加入宏观过滤 |

## 五、结论

**v9 组合评分择时** 是一个有效的宏观择时方案:

1. **风险控制显著**: MaxDD 从 -27.7% 降至 -11.2% (改善 16.4pp)
2. **收益略降但可接受**: AnnRet 从 3.64% 降至 2.92% (仅降 0.72pp)
3. **风险调整后更优**: Calmar 从 0.131 升至 0.259 (几乎翻倍)
4. **信号响应快速**: VIX + 信用 + 趋势的快速响应弥补了 GDP/CPI 的滞后
5. **可与 v8 集成**: 作为大方向过滤器, 与 v8 Jump Model 互补
