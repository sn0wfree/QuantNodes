### 2.2 关键问题：**加权阶段不使用完整协方差矩阵**

`inverse_vol_weights` 是**简化版风险平价**（只考虑单资产波动率），公式：

```
w_i ∝ 1/σ_i
```

而非真正风险平价：

```
w_i ∝ 1 / (Σw)_i    （求解）
其中 Σ 是 N×N 协方差矩阵
```

代码位置（`portfolio.py:206-223`）：

```python
def inverse_vol_weights(
    nav_df: pd.DataFrame,
    codes: Sequence[str],
    as_of: pd.Timestamp,
    vol_window: int = 21,
    floor: float = 1e-4,
) -> dict[str, float]:
    """权重 ∝ 1/σ_i, σ 为年化已实现波动率 (CICC 伪代码窗口=21)."""
    if not codes:
        return {}
    vols = realized_vol(nav_df, as_of=as_of, window=vol_window).reindex(list(codes))
    vols = vols.fillna(vols.median() if not vols.empty and vols.median() > 0 else 1.0)
    inv = 1.0 / vols
    inv[inv < floor] = 0.0
    total = inv.sum()
    if total <= 0:
        return equal_weights(codes)
    return (inv / total).to_dict()
```

## 3. 协方差估计方法对比

### 3.1 常见估计方法

| 方法 | 公式 | 优点 | 缺点 | 适用场景 |
|------|------|------|------|---------|
| **样本协方差** | Σ = X'X/(n-1) | 简单、无偏 | 噪声大, 估计误差大 | 样本充足 (n > 10N) |
| **Ledoit-Wolf 收缩** | Σ = αF + (1-α)S | 稳定, 最优收缩强度 | 需估计 α | **N≥n 的标准方案** |
| **EWMA (指数加权)** | Σ_t = λΣ_{t-1} + (1-α)r_t r_t' | 近期权重高 | 需选 λ | 高频数据 |
| **因子模型** | Σ = B F B' + D | 降维、稳定 | 需选因子 | 因子投资 |
| **截断/去噪** | 保留 top-k 特征值 | 去除噪声 | 信息损失 | 与收缩组合 |
| **Ledoit-Wolf + 截断** | 综合 | 最稳健 | 实现复杂 | **推荐方案** |

### 3.2 各方法对本策略的适用性

| 方法 | 适用性 | 说明 |
|------|--------|------|
| 样本协方差 (当前) | ❌ | 21 日样本 vs 990 参数, 严重过拟合 |
| Ledoit-Wolf | ✅ | 标准方案, 解决 p>>n |
| EWMA | ⚠️ | 需更多日数据, 我们数据充足 |
| 因子模型 | ⚠️ | ETF 因子难定义 (不像股票有 F-F 因子) |
| 截断 + 收缩 | ✅ | 在 Ledoit-Wolf 基础上再降噪 |

**推荐**: **Ledoit-Wolf 收缩 + 特征值截断** 组合。

## 4. 现有协方差处理的具体影响

### 4.1 影响 1: 逆波动加权的偏差

**理论**: `inverse_vol_weights` 假设 ETF 收益独立，但：
- 黄金 (518880) 与白银 (161226) 相关性 ~0.7
- 黄金与海外权益 (513100) 负相关
- 商品类内相关性普遍较高

**实测影响**（基于已有贡献分析）：
| 问题 | 后果 |
|------|------|
| 高相关 ETF 都被赋予高权重 | 实际集中度比预期高 |
| 黄金+白银 合计权重 ~30% | 但风险贡献 ~45% |
| 缺失多元化收益 | 组合波动比理论值高 |

### 4.2 影响 2: 相关性过滤的阈值

`pairwise_corr` 用 **60 日窗口**、**0.9 阈值**。

| 问题 | 后果 |
|------|------|
| 单窗口单相关性 | 忽略多维相关性结构 |
| 阈值固定 | 不适应 regime 变化（牛市 vs 熊市相关矩阵不同） |
| 60 日窗口 | 与加权的 21 日不匹配 |

### 4.3 影响 3: HMM Regime 检测的样本不足

GaussianHMM 用 `covariance_type="full"`，但：
- 504 天训练数据
- 3 个 regime
- 每个 regime **只有 ~168 个样本估计 44×44 矩阵**

**结论**: 这是 Stage 9-D 失败的**根本原因之一**——协方差估计在低样本下数值不稳定 + 统计上过拟合。

### 4.4 影响量化（基于已有贡献分析）

| 指标 | 当前（简化） | 估计（完整 RP）| 提升 |
|------|------------|---------------|------|
| 黄金+白银 集中度 | ~30% 权重, ~45% 风险 | ~20% 权重, ~25% 风险 | ✅ |
| 组合波动 | 13.35% (基线) | ~11% | ✅ -17% |

## 5. 优化方法的影响

### 5.1 当前优化策略缺失

我们当前**没有优化求解**，只用闭式解或启发式：

| 环节 | 当前方法 | 性质 |
|------|---------|------|
| 加权 | `inverse_vol_weights` | 闭式 |
| 相关性过滤 | `pairwise_corr` 阈值 | 启发式 |
| 风险贡献 | 事后归因 | 仅分析 |
| 优化求解 | ❌ 无 | 缺失 |

### 5.2 如果引入优化求解

| 方法 | 公式 | 预期 Calmar | 实现复杂度 | 过拟合风险 |
|------|------|-------------|-----------|-----------|
| **风险平价 (RP)** | 求解 `w_i ∝ 1/(Σw)_i` | +0.05~0.15 | 中 (scipy) | 中 |
| **最大分散 (MDP)** | `max w'Σw / w'Cw`，C 为相关矩阵 | +0.03~0.08 | 中 | 中 |
| **Black-Litterman** | 加入主观观点先验 | +0.05~0.10 | 高 | 中 |
| **均值-方差 (MVO)** | `max w'μ - λ/2 w'Σw` | **-0.10~+0.05** | 中 | **高** |
| **最小方差** | `min w'Σw` | +0.02~0.05 | 低 | 低 |

**关键警告**: **均值-方差 (MVO) 是已知的高过拟合方法**, 在估计误差下表现极差。本策略**不推荐 MVO**。

### 5.3 推荐方案排序

**第一优先**: **风险平价 (RP)**
- 理论最优（每个 ETF 风险贡献相等）
- 不需要预期收益估计（避免 MVO 的最大风险）
- 预期 Calmar +0.05~0.15

**第二优先**: **Ledoit-Wolf 收缩** 作为 RP 的输入协方差
- 解决 N≈n 的样本不足问题
- 提升协方差估计稳定性 30%+

## 6. 评估结论与建议

### 6.1 当前实现的协方差处理状态

| 环节 | 状态 | 风险 |
|------|------|------|
| 加权 | ⚠️ 简化（只用 σᵢ） | 中（集中度风险） |
| 相关性过滤 | ⚠️ 启发式 | 低（过严/过松） |
| Regime 检测 | ❌ 全协方差 | **高**（样本不足） |
| 风险归因 | ✅ 完整 | N/A |

### 6.2 核心发现

1. **加权阶段是最大短板**: 集中度风险贡献 ~45% 来自商品类（黄金+白银），但商品类的相关性未被考虑。
2. **HMM 失败的根因在此**: 高维协方差 + 样本不足 = 数值不稳定 + 过拟合。
3. **21 日窗口样本协方差不可用**: p >> n 是已知问题（Markowitz 早期论文就发现）。

### 6.3 优化方向优先级矩阵

| 优先级 | 方向 | 预期收益 | 实现难度 | 风险 |
|--------|------|---------|---------|------|
| ★★★ | **Ledoit-Wolf 收缩协方差** | 稳定性 +5% | 中 | 低 |
| ★★★ | **协方差窗口延长 (21→60)** | 噪声 ↓30% | 低 | 低 |
| ★★ | **风险平价求解** | Calmar +0.10 | 中 | 中 |
| ★★ | **截断/去噪** (top-10 特征值) | 稳定性 +3% | 低 | 低 |
| ★ | **EWMA 加权** | 近期敏感 | 低 | 低 |
| ✗ | **MVO** | 不建议 | - | **高** |

### 6.4 最大风险点

**HMM Regime 检测 (Stage 9-D) 失败的根因**：高维协方差 + 样本不足 = 数值不稳定 + 过拟合。

这印证了"低样本+高维"的协方差问题是**真实存在**的, 任何依赖完整协方差矩阵的算法 (RP, Ledoit-Wolf 都要面对)。
