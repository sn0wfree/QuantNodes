## 测试说明

TV-PR 权重 tvpr_weight ∈ [0, 1] 含义:
- **0.0**: Layer 1 仅用熵权法 (5 宏观因子 z-score)
- **1.0**: Layer 1 仅用 TV-PR 时变β
- **0.5**: TV-PR 50% + 熵权 50% (默认)

其他 v10.0 配置保持默认值:
- rebal_freq: W/M
- Top-K=10, candidate_pool=50%
- Jump Model: 启用, bear_prob × 0.5 调整仓位
- 动态仓位: pos = (0.7 - 0.5z).clip(0.2, 1.0)

## ★ 推荐配置

**`tvpr_weight = 0.5`** (跨窗口平均 Sharpe 最高)

理由:
1. **跨窗口平均 Sharpe 0.873**, 在所有权重中最高
2. **v9 (W) 窗口 Sharpe 1.030**, 与 v9 银河方案 (1.23) 接近
3. **v9 (M) 窗口 Sharpe 0.767**
4. **完整窗口 Sharpe 0.823** (略低于 0.0 但跨窗口最优)
5. TV-PR 与熵权互补, 50/50 混合最稳定

## 关键发现

1. **tvpr_weight = 0.5 (50/50 混合) 是跨窗口最优**
2. **完整窗口最优 = 0.0 (纯熵权)**: Sharpe 0.847, 而 tvpr_weight=0.5 是 0.823 (-2.4%)
3. **v9 窗口最优 = 0.5 (混合)**: Sharpe 1.030 (W), 0.767 (M)
4. **解释**: 完整窗口包含 2018-2021 熊市, TV-PR 在下行市场信号噪声大; v9 窗口是上行市场, TV-PR 帮助捕捉结构性变化
5. **避免 tvpr_weight > 0.7**: 拖累明显 (跨窗口平均 Sharpe < 0.86)
6. **最优区间 0.4-0.6**: 平均 Sharpe 都在 0.85+, 差异 < 0.02, 调参敏感度较低

## 应用建议

### 推荐: 保持默认 0.5

v10 默认 `MacroLayerConfig.tvpr_weight = 0.5` 已被验证为**跨窗口最优**, **无需修改**.

### 备选: 纯熵权 (tvpr_weight=0.0)

如果希望节省计算时间 (TV-PR 计算较慢), 可设 `use_tvpr=False` 关闭 TV-PR:

```python
cfg = V10Config()
cfg.macro.use_tvpr = False  # 完全跳过 TV-PR, Layer 1 只用熵权
```

Sharpe 损失: 跨窗口从 0.873 → 0.858 (-1.7%), 计算时间减少约 30%

### 不推荐: tvpr_weight > 0.7

纯 TV-PR (1.0) 跨窗口平均 Sharpe 仅 0.825, 比最优低 5.5%, 不建议使用

## 配置代码

当前 v10 默认配置 (`QuantNodes/strategy/momentum_etf_rotation/v10/config_v10.py`):

```python
@dataclass
class MacroLayerConfig:

    tvpr_min_history: int = 104
```
